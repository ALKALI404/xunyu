## 三、查东西的姿势

```powershell
node scripts\find.mjs <关键词>     # 只给路径，不读内容
node scripts\find.mjs --all         # 整张地图
node scripts\peek.mjs --run "<命令>" --grep "<正则>" --head N   # 大输出落盘+切片
```

**先地图、后锚点、最后才读内容；禁止通篇浏览。**
