# 工单 D8 · workdesk：本地工作台（只读服务 + 网页，零 DSH token）

> 派单 2026-10-28 16:55 本体｜主人定：**利用 app 自动跟踪，通知不能占 DSH token**
> 关键事实：读 DSH 本地 RPC 的投影**不消耗模型 token**；只有 `session/prompt`（让 agent 起一轮）才花钱。

## 一、硬红线（违反即算失败）

- **禁止调用 `session/prompt`**（任何形式：prompt / say / 敲话），一条都不许。
- 不写任何 DSH 会话、不改任何现有模块、不新增依赖。
- 只读 DSH 的 `sessions/list` 投影 + 本地文件。

## 二、要做什么

### 1. `<工作区>\scripts\workdesk-server.mjs`（新，监听 127.0.0.1:9340）

| 接口 | 返回 |
|---|---|
| `GET /api/agents` | 每个会话：`id / 标题 / running / 正在干什么（workingActivity.line）/ phase / 空闲时长 / 最近一轮 prompt 摘要` |
| `GET /api/tasks` | 未完成的活：`state\tasks\*.md` 里**没有**对应 `records\交付\*` 的条目（标题/派单时间/目标工号/票号） |
| `GET /api/mail` | 邮件池（`<Xunyu根>\memory\mail\mailbox.jsonl`）最近 50 条 + 各 agent 未读数 |
| `GET /api/push` | **只生成不发送**：`{task, target, reason:"任务未完成且该工号空闲 > 10 分钟", suggested:"桌面通知/窗口气泡"}` |
| `GET /` | 一个自包含 HTML 工作台页（不引外部 CDN） |

- 采样节流：`/api/agents` 结果缓存 3 秒，别把 DSH 打爆；
- 一律 `Cache-Control: no-store`，前端每 5 秒拉一次。

### 2. 页面（`GET /`，单文件）

三栏 + 顶部标签：
- 左：**工作组状态**（谁空闲 / 谁在干活 / 正在干什么，按 running 排序）；
- 中：**未完成的活**（票号 + 目标工号 + 派单时间）；
- 右：**邮件池**（未读高亮）；
- 顶部标签：`工作组` / `鲟鱼(QQ)` / `DSH`（后两个先占位，等 03 的窗口历史分目录就绪再接）。

### 3. 推送（本单只做「生成 + 冒泡」，不做外部通知）

- `/api/push` 只算不推；页面里用一条横幅显示「有 N 条可催」；
- **真推送**（桌面通知 / 窗口气泡）留给 D9，别在本单跨过去。

## 三、验收

1. `curl http://127.0.0.1:9340/api/agents` 返回真数据（贴一条，能看到「正在干什么」）；
2. 浏览器打开 `http://127.0.0.1:9340/` 能看到三栏；贴截图或 HTML 前 20 行；
3. **零 prompt 证据**：跑 10 分钟后，`bridge.out.log` 或 DSH 会话里**没有任何你引发的回合**（说明只读确实没喊话）；
4. 交付 `records\交付\04-20261028-D8.md`，路径报 01。

## 四、边界

- 不做鉴权（只监听 127.0.0.1）；不暴露到局域网。
- 不实现「自动催办」，只生成候选。
- 页面不引外网资源，断网也能开。
