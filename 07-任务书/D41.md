把 workdesk（9340）从现在的深色换成 **暖白 + 浅灰 + 蓝**，并按规格落实结构：

1. **配色全量替换**：底 `#FAF7F2`、卡片 `#FFF`、次级 `#F3EFE8`、边线 `#E4DED4`、主蓝 `#2F6BFF`（悬停 `#1F55DB`、浅底 `#EAF0FF`）、文字 `#1F2328`/`#5C6470`、成功/警告/危险按规格；
2. **状态色固定映射**：queued 灰边 / doing 蓝 / submitted 琥珀 / planned 紫 / done 绿 / rejected 红 / blocked 虚线灰；
