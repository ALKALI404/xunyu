# 工单 D46 · 对话框历史分页：默认 200 条，点一次多加载 100 条（派 06）

> 派单 2026-10-28 19:35 本体｜主人：本地上下文默认加载 200 条，多的点「加载历史消息」，每次多 100 条

## 1. 做什么

新壳对话框的历史加载改成**分页**：

1. **首次打开**：从 `E:\DeepFish\History\window\<会话>\<日期>.jsonl` **只加载最近 200 条**渲染（不给全部，防卡）；
2. **历史入口**：消息区顶部显示一行按钮 **`加载更早的消息（+100）`**，并常驻显示「已加载 N 条 / 共 M 条」；
3. **点一次**：往前再取 **100 条**，插到列表顶部，**保持当前滚动位置不跳**（记 scrollHeight 差）；
4. **跨天**：取到当天文件头时，自动继续读前一天文件（同分页逻辑）；
5. 全部加载完 → 按钮变灰显示「没有更早的消息了」。

## 2. 什么算过

- 冷启动只渲染 200 条（贴 `已加载 200 / 共 N` 截图或 DOM 计数）；
- 点一次变 300，两次 400，滚动位置不跳（录两张截图对比位置）；
- 加载完按钮置灰；
- 跨天能取到前一天（造一条昨天的测试记录验证，验完删掉）；
- 改前/改后各一张图。

## 3. 边界

- 只改 `E:\DeepFish\avatar\window\web\`（HTML/CSS/JS）；
- 不改历史文件格式（`{t, target, from, text}` 与分目录结构不动）、不改 relay、不碰工作台。

## 4. 回滚

- 改前把 `web\` 打包 `backup\window-web-<日期>.zip`；解压回去即回滚。
