# 工单 D50 · 窗口换头像图标（透明底，嵌入 exe）（派 06）

> 派单 2026-10-28 19:40 本体｜主人给了头像，要求：任务栏图标换成它，背景透明、只留主体

## 1. 现成素材（本体已做好，直接用，不要重做）

| 文件 | 用途 |
|---|---|
| `<工作区>\assets\icon\icon-512.png` | 512×512 透明底 PNG（边缘已羽化，四角 alpha=0，34% 全透明） |
| `<工作区>\assets\icon\xunyu.ico` | 多尺寸 ICO（256/128/64/48/32/16），给 exe 与窗口用 |
| `<工作区>\assets\icon\raw.jpg` | 原图，留档 |

## 2. 做什么

1. **编进 exe**：编译新壳时加 `/win32icon:<工作区>\assets\icon\xunyu.ico`，让**资源管理器里的 exe 图标**就是它；
2. **窗口/任务栏图标**：窗体构造时 `this.Icon = new System.Drawing.Icon(ico路径)`（或从嵌入资源读），保证**任务栏、Alt-Tab、标题栏**三处都是这张脸；
3. **ICO 随包**：把 `xunyu.ico` 复制进窗口程序目录（如 `avatar\window\web\` 或 exe 同级），路径写相对 exe，别写死绝对路径；
4. 若 ICO 读不到 → **降级用系统默认图标并写日志**，不许崩。

## 3. 什么算过

- 编译命令贴出来（含 `/win32icon:` 参数）与退出码 0；
- `Get-Process XunyuWebWindow | Select MainWindowTitle` 之外，贴**任务栏截图**（能看到新图标）与**exe 在资源管理器里的图标截图**；
- Alt-Tab 截图或说明；
- 关闭重开两次，图标仍在（防只改运行时没写进 exe）。

## 4. 边界

- 只改新壳的编译命令/窗体初始化 + 复制 ico；
- **不改** web 目录里的 HTML/CSS/JS 页面逻辑，不动 relay/bridge/工作台。

## 5. 回滚

- 编译命令去掉 `/win32icon:`、窗体去掉 `this.Icon` 一行，重编译即回滚；ico 文件留着不影响。
