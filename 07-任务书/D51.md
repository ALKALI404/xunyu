## 2. 做什么

1. **编进 exe**：编译新壳时加 `/win32icon:<工作区>\assets\icon\xunyu.ico`，资源管理器里的 exe 图标即换；
2. **窗口/任务栏图标**：窗体构造 `this.Icon = new System.Drawing.Icon(相对路径)`，任务栏 / Alt-Tab / 标题栏三处一致；
3. **ICO 随包**：复制 `xunyu.ico` 到 exe 同级，路径写相对，别写死绝对路径；
4. **降级**：读不到 ico → 用默认图标 + 写日志，**不许崩**；
5. **单实例**（顺带）：同一 exe 重复启动时激活已有窗口，不再开第二个（主人已抱怨过"窗口开了两份"）。

- 重复双击 exe → 只有一个窗口（贴进程数）；
- 关掉重开两次，图标仍在。
