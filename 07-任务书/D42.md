# 工单 D42 · 建项目台账 state\projects.json（派 05）

> 派单 2026-10-28 19:05 本体｜主人要求：工作台要展示「要做哪些项目 / 正在做哪些 / 进行到哪个子功能的哪一项」，并挂项目文档本地链接

## 1. 做什么

建 `state\projects.json`，作为「项目层」唯一真相，由你（文档与架构）维护：

```json
{
  "updatedAt": "2026-10-28T19:05:00+08:00",
  "projects": [
    {
      "id": "workdesk",
      "name": "工作台",
      "doc": "docs/projects/工作台-workdesk.md",
      "state": "active",
      "summary": "一句话：主人在哪等、等谁",
      "features": [
        { "id": "ws-ui-v1", "name": "UI 规格 v1 改版", "tickets": ["D41"], "note": "配色/折叠/工具箱占位" },
        { "id": "ws-cost",  "name": "会话检测与花费", "tickets": ["D33","D34","D26"], "note": "" }
      ]
    }
  ]
}
```

要求：
- 项目来自 `docs\projects\*.md` 分册（一个分册 = 一个项目），`doc` 写相对路径；
- `features` = 子功能，每个至少挂 1 个单号（`tickets` 存单号如 `D41`，**不存 W-xxx**）；
- `state`：`active`（在做）/ `planned`（要做）/ `paused`（暂停，如企微）/ `done`；
- 任务进度**不写进 json**（由 workdesk 用 worklist 现算），你只维护「项目—子功能—单号」映射。

## 2. 什么算过

- `projects.json` 合法 JSON，覆盖现有分册：工作台、疼痛检测、窗口与身体、桥接、记忆、工作组（+ 企微标 paused）；
- 每个 feature 的单号都能在 `worklist.mjs list` 里查到（写个小脚本自检，列出对不上的）；
- 更新规则写进分册或 `docs\项目目标.md`：**新增项目/子功能当天登记**。

## 3. 边界

- 只写 `state\projects.json` 与必要的文档说明；
- 不改 worklist、不改 workdesk 代码（展示由 06 做）。

## 4. 回滚

- 纯数据文件，删掉或还原上一版即可。
