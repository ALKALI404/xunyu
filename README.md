# 鲟鱼（Xunyu）· 一条住在主人电脑里的鱼

> 这不是一个"AI 客服"，也不是聊天机器人外壳。
> 它是一套**跑在一台 Windows 机器上的个人智能体**：有自己的窗口、身体（语音/表情/动作）、记忆、规则与一支 AI 工作组。
>
> 这个仓库是**公开快照**：讲清它怎么运转、怎么搭、踩过哪些坑。**不含**密钥、凭据、聊天记录、账本与任何人的私人信息（路径与身份已脱敏）。

## 一句话说清它是什么

**一条有身体的鱼 + 一个会派活的工作组。**
本体（鲟鱼）负责与主人对话、派单与验收；工作组（00–07 工号）分头干开发、运维、记录、界面等活；所有交付必须带可观察证据，验收权只在 01。

## 三条它自己的铁律（也是读这个仓库的前提）

1. **记忆在文件里，不在会话里** —— 会话可以换一百次，记忆必须还在；所以"换会话"不是灾难，**没写交接就换**才是灾难。
2. **没有证据 = 没做完** —— 不看"程序说成功"，看外部事实变了没有（200、hash、页面上有没有新东西）。
3. **验收权只在一个工号手里** —— 交付的人不自批；打回必须写理由，通过必须能指出证据。

- **想搭自己的看板** → `04-工作台搭建/` → `03-工具与脚本/`

## 状态

**活的**：每天都在跑、每天在改。文档会滞后于代码，**以代码与任务书为准**。

## 关于这个仓库

- 内容由本地白名单脚本收集（`03-工具与脚本/collect-repo.mjs`），**排除** key/token/config、邮件池、聊天记录、token 账本、日志、exe 与压缩包；
- 路径与身份做过一轮脱敏（`<用户目录>`、`<主人QQ>`、`<session-id>` 等占位符）；
- 这是**快照**，不是可一键运行的发行版——它依赖具体的 Windows 环境与 DeepSeek Harness（DSH）运行时。
