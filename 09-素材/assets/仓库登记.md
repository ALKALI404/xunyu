# 素材仓库登记（canonical）

> 主人 2026-10-28 定：**以后他给的素材都有固定存放点，并且登记在册，由本体判断放哪。**
> 本文件是**唯一登记处**；两处仓库各有自己的目录树，但登记只写这一份（`<工作区>\assets\仓库登记.md`），DeepFish 侧放一份指针。

## 一、两处仓库（各管一摊）

| 仓库 | 路径 | 放什么 | 不放什么 |
|---|---|---|---|
| **本体仓库** | `<Xunyu根>\assets\` | **我自己**的素材：形象/立绘、头像、表情、语音、风格参考、原创图 | 项目图标、测试数据、文档附件 |
| **项目仓库** | `<工作区>\assets\` | **项目**用的素材：UI 图标与参考、测试数据、报告配图、演示材料 | 我的形象素材 |

子目录约定：

```
<Xunyu根>\assets\
  ├─ 形象\      我长什么样（头像/立绘/表情/动作）
  ├─ 参考\      主人给的风格参考、别人作品的参考
  └─ 原创\      由我或工作组产出、归我的图

<工作区>\assets\
  ├─ icon\      程序图标（exe/窗口/托盘）
  ├─ ui参考\    界面参考图、配色卡、截图
  ├─ 数据\      测试数据、导入导出样本（如官方账单 zip 解包）
  └─ 项目\<项目id>\   某个项目专用素材
```

## 二、放哪的判断（本体自决）

1. **是不是"我"？** 是 → 本体仓库 `形象/`；
2. **是不是给程序用的？** 是 → 项目仓库 `icon/`；
3. **是不是某个项目专用？** 是 → 项目仓库 `项目\<项目id>\`；
4. **是不是参考/灵感？** 是 → 本体仓库 `参考/`（若是 UI 风格参考 → 项目仓库 `ui参考/`）；
5. **拿不准** → 先放 `项目\_未分类\`，登记时标"待定"，下次盘点归位。

**一次素材只存一处正本**；需要两边都要的（如头像既要给窗口当图标、又是我形象），**正本存本体仓库，项目侧放副本并在登记里注明"副本"**。

## 四、规矩

1. **不删不覆盖**：新版本加日期后缀，旧版留着（沿用"冗余只标记"的原则）；
2. 文件名用**中文可读名 + 日期**，不用哈希名；
3. 每件素材登记时写清**来源**（主人给的/官网下的/自己生成的）与**用在哪个项目**；
4. 素材涉及隐私（主人照片、家人、聊天截图）→ 只登记不描述内容，**不进 git、不外发**。
