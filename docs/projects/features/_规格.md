# 功能域「六件套」规格（UG-008，v1 只强制四件）

> 一个功能域不是 `projects.json` 里的一行，而是**一块有边界、有记忆、有归属的地**。
> 缺件就只是"一次性对话"——下次谁来接手都得从头问一遍。检查入口：`node scripts\module-doctor.mjs`。

## 一、六件（v1 强制前四件）

| # | 件 | 落点 | v1 |
|---|---|---|---|
| ① | **README**：做什么 / 不做什么 / 边界 | `docs\projects\features\<域id>.md` 的「做什么」一节 | **强制** |
| ② | **私有记忆**：当前状态与卡点（≤2KB） | 同文件「当前状态」一节 | **强制** |
| ③ | **归属与改动权**：谁能改、改前问谁 | 同文件「谁说了算」一节 | **强制** |
| ④ | **归档目录**：只进不改 | `docs\projects\features\_archive\<域id>\` | **强制**（可为空目录） |
| ⑤ | 专属脚本 / 面板（可空但声明） | 同文件「实现」一节 | 建议 |
| ⑥ | 验收要点：这域怎么算过 | 同文件「怎么算过」一节 | 建议 |

`projects.json` 每个 feature 必须有 `doc` 字段指向 ①。

## 二、为什么强制这四件

- **① 没有 README** = 没人知道边界，两个工号会同时改同一处（`wecom-relay` 与 `wecom-send` 今天就模糊过）；
- **② 没有私有记忆** = 卡点散在会话里，换人或换代就丢；
- **③ 没有归属** = 改前不知道问谁，越界与返工都从这里来；
- **④ 没有归档** = 做完的旧稿挤在文档区，越堆越不敢删（与「冗余只标记不删」配套）。

## 三、检查怎么算过（module-doctor）

- 逐个 feature 读 `doc` → 文件存在 + 三个小节（`## 做什么` / `## 当前状态` / `## 谁说了算`）+ 归档目录存在；
- **缺任何一件 ⇒ ⚠ 并列出缺哪件**（不影响模块 transport 结论，exit 仍只在真失败时为 1）；
- 没登记 `doc` 的域进「待补清单」，不报错但计数可见。

## 四、怎么补一个域（三步）

1. 复制任一现有域文件当骨架，改「做什么 / 当前状态 / 谁说了算」；
2. 建 `_archive\<域id>\`（空目录也行）；
3. 在 `projects.json` 该 feature 加 `"doc": "docs/projects/features/<域id>.md"`，然后跑 doctor 直到 ⚠ 消失。
