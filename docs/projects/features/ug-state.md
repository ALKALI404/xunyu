# ug-state · 目录与资产治理

> 项目：upgrade ｜ 负责人：**00** ｜ 归档：`_archive/ug-state/`

## 做什么

**让"东西在哪、谁在动、旧的去哪"永远答得上来**：

- `state\` 清场与索引：台账、名册、配置各有归属，不混放；
- 冗余资产**只标记不删**：`state\redundancy.md` 一行一条（类别/路径/体积/正本/副本/状态），副本目录放 `_重复副本_勿用.md`；
- 换代"看画面"验证（UG-006 在做）：交接后必须有新会话截图（标题/工作区在画面里）+ 复述引证交付稿文件名；
- 归档：只进不改；旧会话按 `scan-stale-bindings` 检查后才许归档。

**不做什么**：
- **不删资产**——删要主人批准（规则 §十三）；不移动/重命名别人的目录；
- 不动业务代码、不改规则判定（那是 05）。

## 当前状态

- 冗余标记机制在跑（`state\redundancy.md`）；`backup\` 下已有多次规范性备份（`rules-20261028\`、`rules-20261029\`、`taxonomy-20261028\`、`projects-*.bak-*`）；
- UG-006（换代看画面）在干：截图证据 + 同前缀告警；
- **已知缺口**：①`backup\` 不入 git（红线），历史备份被清后只能靠判例页摘要；②`state\` 没有自动索引脚本，靠人记；③"只进不改"的归档目录没有写入守护（只能靠约定）。

## 谁说了算

- **00 主责**名册、台账改派、归档与资产盘点；**删文件一律要主人批准**；
- 备份/清理策略变更要通知 03（守护侧）与 05（文档口径）；
- 05 只维护"文档与规范的写法"，不动实际文件。

## 实现

- `state\redundancy.md`（冗余登记）、`state\roster.json` + `records\ROSTER.md`（名册）

- `backup\`（各类改前备份）

## 怎么算过

1. 换代必须带**截图证据**，缺图 = 交接未完成（01 打回）；
2. 冗余"只标不删"能被验证：`redundancy.md` 有登记、正本还在、副本目录有 `_重复副本_勿用.md`；
3. 归档前后集合计数一致（归档 N 条、集合从 X 到 X+N），有日志可查。
