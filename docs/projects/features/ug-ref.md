## 做什么

**把别人踩过的路变成我们的选择，而不是我们的体量**：

- 研读外部工作台（淋雨家）→ 出《研读报告》（哪些值得借、哪些是短板）；
- 出《可行性报告》做**四类分拣**：A 可照搬 / B 要魔改（写清改哪一侧）/ C 只参考 / D 不碰，每条带工作量与怎么验；
- 维护《升级指南》：P0/P1/P2 优先级 + 明确不做清单；
- 分拣结果转工单时，必须回链报告编号（B1→UG-00x）。

**不做什么**：
- **不照搬对方源码与体量**（21MB / 700+ 占位符 / 190KB 规矩）；
- 不引入其 Electron / PowerShell 强绑依赖；不替换我们"01 唯一验收人 + 硬证据"的强项；
- 不做技术实现（归 04/06/03）。

## 怎么算过

1. 每条借鉴都能定位到「A/B/C/D 哪一类 + 工作量 + 怎么验 + 落到哪个文件/节」；
2. B 类必须写清**改对方哪一处 / 改我方哪一处**，只写"要改"不算过；
3. 落地的工单回链报告编号；报告里"一句话结论"（三个最大价值 / 三个最大坑）必须存在。
