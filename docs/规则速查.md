# 规则速查（一页版 · 注入层）

> **做事只读这一页。** 细则/判例翻 `规则-开发与维护.md`，历史事故翻 `规则-判例归档.md`。
> 维护：05｜**版本 `v2026-11-05`**（2026-11-05 增补四份新规，全文与技能清单见 `规则-开发与维护.md` 文末「附」）｜回执末尾写 `已读规则 v2026-11-05`。
> 标记：`[闸]` 有脚本/闸门拦 ｜ `[查]` 有体检或命令能查 ｜ `[文]` 仅文字（靠人记）
1. **负载闸**：目标 ≥65 万（handoff−5万）**硬拒、--force 也拒**；63 万以上需 `--force` 且进审计；auto-relay 同闸。[闸]

## 建单（4 条）
1. **单号必须给且唯一**（`--ticket`，新票用 `<前缀>-三位号`）——没单号建不出来、撞号被拒。[闸]
2. **必须带 `--project` + `--feature`**，否则项目视图里等于没登记。[闸]
3. **测试夹具用 `--test`**（`T-` 前缀），永不派给真人。[闸]
4. **四要素齐全才许派**：做什么 / 什么算过 / 边界 / 回滚（`state\tasks\<单号>.md`）。[闸]

## 派单（4 条）
5. **一个工号同时只有 1 张 doing**；目标在跑 → 409，不许硬塞。[闸]
6. **有前置写 `blockedBy`**，前置没 done 不许派；完成后自动解锁并邮件。[闸]
7. **要动手=派单（必须唤醒）；只是知道=公告（不唤醒不回执）**——拿不准问"不做会卡住谁"。[文]
8. **本体只调度不执行**（代码/配置/素材都归工号）；越界自己记账。[查]

## 交付（5 条）
9. 文件名 `records\交付\<工号>-<YYYYMMDD>-<单号>.md`；**不符或放错目录=视同未交**。[查]
10. **第一行写类型**：`方案 / 实现 / 修复 / 文档`。[闸]
11. 四段式：做到哪 / 改了什么 / 怎么验的（命令+输出+退出码）/ 卡在哪；第 5 段「效果与证据」可选。[闸]
12. **交付前自查预检三项**：类型行 / 四段齐 / 修复类带命令块+exit —— 不合格的票会卡在 doing。[查]
13. 回执末尾写 `已读规则 v<版本>`，01 验收核这行。[查]

## 验收（5 条，01 执行）
14. **只认可观察证据**（命令输出/端口在听/日志一行/mtime/截图），不认"已完成"三个字。[文]
15. **三条通用判据**：程序说成功≠成功；看起来像≠指向对；做了改动≠生效。[文]
16. **方案型 ≠ 做完**：通过记 `planned` 并派生 `-impl`；票全 done 也不等于功能完成，要 01 签 `feature-approved`。[闸]
17. **失职线**：`submitted ≥7 条未处理` 或任一条超 2 小时未动 → 报警；页面显示 `待验收 N/7`。[查]
18. **校验类工具必须能证明会失败**（带应当失败的反例 + 差异集合），只给"全过"= 假证。[文]

## 状态与红线（4 条）
19. **台账不许说谎**：`reject` 回 `queued`；多张 doing 标 ⚠；收工前必跑 `list --state submitted`，非空不许说收工。[闸]
20. **门不许比验收线更严**：硬性 FAIL（无类型行/无四段/名字目录错）vs 软性 WARN（缺 exit 码，**仍进待验收**）；可 `precheck.enabled=false` 旁路。[闸]
21. **冗余只标记不删**；**仓库永不入库密钥/聊天/账本**；改常驻服务（workdesk 等）**要重启才生效**。[闸]
22. **危险动作先问主人**（删非 tmp/装卸载/提权/网络暴露/凭据/对外推送/花钱）→ 走申请单；无批准就动手 = 事故。[文]
23. **三套术语别混**（规则 §二十九）：**任务书=五要素**（做什么/预期结果/可验方式/边界/回滚，模板 `state\tasks\_模板.md`）｜**派单消息=四件套**｜**交付回执=五段式**（结论/证据/改了什么/落点/风险与没做的）——**交付不许再叫"四段式"**。[闸]

## 三条最容易被忘的
- **被驳回的补正单插队做**（会卡下游依赖）。
- **长文本用 `--note-file`**，别塞 `--note`（会被 shell 吃掉）。
- **花费口径只有一个** `cost-core.mjs`，改口径必须升版本号。
