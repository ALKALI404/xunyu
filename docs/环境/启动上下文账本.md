## 三、拆账：77k 里各占多少

| 来源 | ≈token | 依据 | 是否必需（工作组） |
|---|---|---|---|
| 6 个 MCP 工具 schema | **17.4k** | 实测（§一） | 只留 web-search-safe（0.3k） |
| CUA driver 原生工具（`cua_*` 一大堆） | **未测（估 15–25k）** | 无法静态测：工具清单由 `@trycua/cua-driver` SDK 运行时 `ToolCatalog` 注入，aset 里只有 6KB 插件壳。数量级来自当前会话里能数到的 60+ 个 `cua_*` 工具、每个都带长描述 | ❌ 工作组不需要，**这是第二大块** |
| engram 工具（`engram_*`） | **未测（估 6–10k）** | 插件 `@kenz1117/dsh-engram`，约 32 个工具 | 可选（工作组可用 `engram_search` 但不必常驻） |
| 内置工具（read/write/edit/glob/grep/pwsh/job/schedule/skill/subagent/workflow/present…） | 未测（估 8–12k） | 无独立 schema 文件（在 app.asar 里随包分发），按当前会话可见工具数量估 | ✅ 必需 |
| 系统提示 + 状态栏 + 工具使用规范 | 未测（估 3–5k） | 每次会话固定注入 | ✅ 必需 |
| 技能目录（`available_skills` 摘要） | <1k | 目录里只放 name+description | 可精简 |
| 记忆注入（engram profile + recall） | <1k | `injectProfile: true` + 3 条 | ✅ 必需（可减条数） |

**结论（也是这单最重要的发现）**：
> **把 6 个 MCP 全砍光，只省 17.4k —— 77k 变 59k，离 25k 还差一大截。**
> 真正的大头是 **CUA driver 的工具面**（60+ 个 `cua_*` 工具）和 **engram 的 32 个工具**。要压到 25k，必须同时把这两块也对工作组关掉，光做"MCP 分级"不够。

## 五、没做的 / 没测的（别当已完成）

1. **CUA 与 engram 的精确 token 没测到**：CUA 工具由 SDK 运行时注入、engram 的 schema 没导出清单；要么在真会话里 `--dump-config`，要么用今天的账本 + 逐项关掉再测差。
2. **② 要求的"改后新会话 ≤25k 实测"没做**：03 没有启动新会话的手段（GUI 是主人的；`dst run` 需要官方 DSH CLI `--dsh-bin`，机器上找不到可执行的 dsh bin，`dst` 直接报 `ADAPTER_UNAVAILABLE`）。

4. 账本里的估算区间（CUA 15–25k 等）是**数量级**，不能当精确值引用。
