# 配色规范 · 鲟鱼（白 / 浅灰 / 浅蓝）— 2026-11-07

> 主人原话：「我要的是浅灰，浅蓝和白色（不要暖白了）现在蓝白有，另外一个部分像屎黄色，参考鲨鱼或者 vtb gura 的配色和比例来吧」

## 一、问题

现状基调是**暖白米色**（`#EFEAE1` / `#FBF8F3`）——**主人说像屎黄色，要去掉全部暖色。**

## 二、新色板（Gura / 鲨鱼系：白 + 浅蓝 + 冷灰）

**只允许这三族 + 一个深墨水色**，**不许出现任何 R>G>B 的暖色**（米黄、暖白、米灰全禁）。

| 令牌 | 值 | 用途 | 占比 |
|---|---|---|---|
| `--bg` | `#F7F9FB` | 页面底（**冷白偏灰**，不是米白） | **45%** |
| `--surface` | `#FFFFFF` | 卡片/面板 | **30%** |
| `--surface-2` | `#EDF2F7` | 次级面（页栏、输入框底） | **12%** |
| `--line` | `#DCE4EC` | 描边/分割（冷灰） | 3% |
| `--ink` | `#1B2733` | 主文字（**冷墨蓝黑**，不用纯黑） | 6% |
| `--ink-dim` | `#5A6B7B` | 次文字 | 2% |
| `--accent` | `#4C9BE8` | 主色（Gura 蓝） | **1.5%** |
| `--accent-strong` | `#2E6FB0` | hover/按下/链接 | 0.5% |
| `--accent-soft` | `#E3F0FB` | 选中态背景、标签底 | — |
| `--ok` | `#3E9C7A` | 通过 | — |
| `--warn` | `#C98A2E` | 半对（**注意：这是唯一的暖色，只用于状态字，不做背景**） | — |
| `--bad` | `#C25B52` | 不过 | — |

**深墨模式**（保留）：`--bg:#141A21` `--surface:#1B232C` `--surface-2:#222C36` `--line:#2C3946` `--ink:#E8EEF4` `--ink-dim:#9AAAAF` `--accent:#5FA8E8`，**对比度全部 ≥4.5:1**。

## 三、比例纪律（Gura 那种"很白很干净"的观感靠这个）

```
白/冷白底 75% ＋ 浅蓝点缀 ≤8% ＋ 墨色文字 ≈15% ＋ 状态色 <2%
```

**三条禁令**：
1. **不许大面积铺蓝**（蓝只做点缀：按钮、选中、进度条）；
2. **不许用暖白/米色做底**（连"纸感"都不行）；
3. **不许超过 2 种蓝**（主蓝 + hover 深蓝，够了）。
