# 学习区 · 学科树倒推规则（v1，2026-11-06）

> 用途：给定"我想读懂 X"，从 `E:\DeepFish\study\学科\_tree.json` 倒推出**一条能照着走的路径**。
> 配套：`脚本\tree-validate.mjs` 负责"边有没有 why+source"这类**静态合法性**；本文负责**动态走法**。

## 一、输入 / 输出

| | |
|---|---|
| 输入 | 目标节点 id（如 `phil-problems`）+ 当前树（`_tree.json`） |
| 输出 | `{ stages: [{order:[nodeId…], gate:{id,name,pass}}], skipped:[{id,reason}], total }` |
| 失败 | 目标不存在 → `E_TARGET`；图里有环 → `E_CYCLE`；目标已被判 `mastered` → 空路径 + "已读完" |

## 二、算法（伪代码）

```text
倒推(target):
  # 1) 反向 BFS：把 target 的所有前置（递归）收进集合
  seen = {target}; queue = [target]; skipped = []
  while queue not empty:
     cur = queue.pop()
     for p in prereqsOf(cur):                     # 只看 type=prerequisite 的边
        if status(p) == "mastered":
           skipped.add({p, reason:"status=mastered"})   # 跳过，但要留下理由
           continue
        if p not in seen: seen.add(p); queue.push(p)

  # 2) 拓扑排序（前置在前），同层按 level 升序
  order = topoSort(seen, key=level)

  # 3) 阶段拆分（>8 个节点必须拆，否则"下一步读什么"看不清）
  stages = splitByLevelBands(order)      # 1–2 / 3–4 / 5–6 / 7–9
  if any stage.size > 8: stages = splitEvenly(stage)

  # 4) 每阶段必须挂一个 gate（阶段门），否则不算闭环
  for i in 0..stages.len-1:
     nextFirst = stages[i+1].first or target
     gate = findGate(unlocks contains nextFirst)
     if gate == null: error "E_NO_GATE: 阶段 i 没有门槛"
```

## 三、规则细则

1. **只沿 `prerequisite` 边倒推**；`strength` 只影响展示（`must` 必读、`should` 建议读），不影响是否进路径。
2. **`mastered` 一律跳过**，但必须输出 `skipped` 并在页面写一句"已跳过：<理由>"——不许悄悄少一个节点。
3. **阶段拆分**：先按 level 分带（1–2 / 3–4 / 5–6 / 7–9）；某一带 >8 个节点时按拓扑序对半再拆。**≤8 个节点不拆**（一条直线看完更清楚）。
4. **每阶段末必须有一个 gate 组**（主人 2026-11-06 22:32 定）：先 `mode:"oral"`（口试，追问 3 个概念，`sequence:1`），过了再 `mode:"written-untimed"`（书面不限时，`sequence:2`）；两道都过才算放行。gate 的 `unlocks` 含下一阶段首节点（最后一阶段含目标节点）。缺 → `E_NO_GATE`。
5. **`effortHours` 的口径**：按「2 小时 ≈ 40–60 页学术书」估——即 `effortHours ≈ 页数 ÷ 50 × 2`。不是拍脑袋的"感觉要读多久"。
6. **门槛与节点是"考过才放行"的关系**：没过 gate 的节点保持 `locked`；过了才变 `available`。状态由 `gate.pass` 与实测得分决定，不由人工点"我懂了"。
7. **路径上的每个节点都要能答"为什么需要它"**：展示时把边的 `why` 原文挂在箭头下面，`source` 折叠（点开可看）。
8. **`far-future`（远期目标，主人 2026-11-06 22:40 定）**：
   - 倒推**默认跳过** `status:"far-future"` 的节点——它不参与"下一步读什么"的路径计算；
   - 卡片只显示一句固定文案：**「远期目标 · 需先补数理逻辑 + 集合论（预估 3–6 个月）」**，并附「展开看看」按钮（**不自动展开**）；
   - **不做进度条、不进每日计划**（不排番茄钟、不占当天 goal）；
   - 主人**手动展开**时才展示它的前置链与门槛——展开是只读预览，不改任何 `status`；
   - 档次：`near`（近程，可与其他线并行）/ `mid`（中程，主线读完再起）/ `far`（远期，只在卡片上挂着）。当前：**《哲学问题》= near；尼采三本/《逻辑哲学论》= mid；《数学原理》= far-future + far**。

9. **`current`（默认视图的唯一入口，主人 2026-11-06 22:50 定）**：
   - `_tree.json` 里**必须有且只有一个** `"current": true` 的节点，代表"现在该学什么"；0 个或 2 个都算数据错误（`E_CURRENT_COUNT`）；
   - `current` 节点的 `status` 只能是 `learning` 或 `available`（`locked`/`far-future`/`mastered` 不许当 current，`E_CURRENT_STATUS`）；
   - **首页/助手默认只认 current 节点**：其余节点（尤其 `locked`、`far-future`）**不许出现在默认视图**；现在的 current = **`logic-intro`（逻辑学导论，在学）**；
   - **每个 `locked` 节点必须写 `unlockBy:"<gate-id>"`**，且该 gate 的 `unlocks` 里必须含这个节点；缺 = `E_NO_UNLOCK_BY`，指向不存在 = `E_BAD_UNLOCK_BY`，门槛不解锁它 = `E_UNLOCK_MISMATCH`；
   - 为什么：现在树里 `wittgenstein-tlp` 是 `locked`，如果默认视图把它顶出来，看起来就像"系统自动跳到逻辑哲学论"——**默认视图只该有一个"下一步"**。

## 五、学科层与地图画法（主人 2026-11-07 00:00 定）

**顶层不是"目标"，是"学科"**：数学 / 逻辑学 / 哲学 / 物理 / 化学 / 生物 / 计算机科学。每个学科内部才是「书/专题节点 + 依赖 + 门槛」。

```jsonc
"subjects": [
  { "id": "physics", "name": "物理学", "level": 3.5,
    "status": "needs-patch", "note": "机制懂、定义松",
    "patch": ["能量定义卡", "熵定义卡", "守恒的用处"],
    "nodes": ["phys-mechanics"],          // 本学科节点（必须与 node.subject 一致）
    "crossDeps": ["math-calculus"] }      // 跨学科依赖：渲染成灰虚线，不进 edges

```

**硬规则**：

1. **每个 node 必须属于且仅属于一个学科**（`node.subject`），并且必须出现在该学科 `subjects[].nodes` 里——三处不一致就是数据错误：`E_NODE_SUBJECT_MISSING` / `E_NODE_SUBJECT_UNKNOWN` / `E_NODE_NOT_LISTED` / `E_SUBJECT_NODE_SHARED`。
2. **跨学科依赖只放 `subjects[].crossDeps`**，不写进 `edges`；渲染时画灰虚线，一眼区分"本学科内（实线）"和"跨学科（虚线）"。指向本学科节点 = `E_CROSS_SAME_SUBJECT`，指向不存在 = `E_CROSS_UNKNOWN`。
3. **学科档位来自摸底结论**（`学识档案\2026-11-06-基础摸底.md`），`status` 只取：`mastered-basics`（可跳）/ `needs-patch`（补一节或几张卡，必须带 `patch[]`）/ `gap`（真空白，要加前置节点）/ `learning`（在学）/ `not-assessed`（还没摸）。
4. **地图画三层**：
   - **首页 = 学科分区卡片**（7 张，每张带档位 + 进度 + 待办数）；
   - **点进学科 = 路径链（竖线）**：该学科内节点按 level 排；
   - **跨学科 = 只画"当前学科指向别的学科"的那几条虚线**（如"物理 ← 微积分"）。
5. **不做全学科一屏大图**（节点一多就糊）；**`mastered-basics` 学科的节点默认折叠**，卡片上写"可跳"。

## 六、边界与失败

| 情况 | 行为 |
|---|---|
| 目标被 `mastered` | 返回空路径 + `{done:true}`，页面写"这本书你已标为读完" |
| 前置边缺 `why`/`source` | **校验脚本先拦**（`tree-validate.mjs`），倒推器不接烂树 |
| 图有环（A 是 B 的前置，B 又是 A 的前置） | 报 `E_CYCLE` 并打印环上节点；**不静默截断** |
| 阶段找不到 gate | 报 `E_NO_GATE`，并在页面提示"这一步缺门槛，先补题库" |
| `skipped` 为空 | 正常，不显示"已跳过"区块 |
