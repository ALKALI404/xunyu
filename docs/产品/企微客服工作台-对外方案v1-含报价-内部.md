## 一、这套系统是什么

**一句话**：把企业微信里与**外部客户**的聊天，收进一个装在您自己服务器上的网页工作台——客服在那里统一看、统一回、统一分配，聊天记录自动留档。

**适用场景**：
- 多个客服共用**一个**企业微信对外账号与客户聊天；
- 客户咨询散在几台电脑、几个人手里，谁回过、谁没回说不清；
- 需要留档（争议、追责、复盘），但没有精力自己搭系统。

**不是**：不是"微信客服"那种平台托管通道，也不是私域营销群发工具；我们解决的是**日常一对一客服接待**。

## 二、系统怎么跑

```
        企业微信（客户的账号）
                  ↕
┌─────────────────────────────────────────┐
│  客户自有 Windows 服务器（4 核 8G 起）        │
│                                           │
│   ① 会话接入服务   ② 客户端助手   ③ 客服工作台 │
│      （读消息）      （发消息）     （网页）     │
│                                           │
└─────────────────────────────────────────┘
                  ↕
            客服的浏览器（内网即可）
```

- 三个组件都跑在**客户自己的服务器**上，聊天数据**不出内网**（如启用智能回复，仅对话文本会送去第三方 AI 服务）；
- 客服只用浏览器打开工作台，不用装客户端；
- 发消息采用**队列投递**：工作台写入 → 客户端助手按序发出 → 回执回到工作台（避免多客服同时抢发、失败无感知）。

## 三、客户需要准备什么

| 项 | 要求 | 谁负责 |
|---|---|---|
| 企业微信账号 | 管理员权限，能添加/授权外部联系人；仅限**一个**对外接待账号（多账号另议） | 客户 |
| **会话内容存档** | 需开通（企微官方按年收费，**约 900 元/年，由客户自行购买**）；不开通则**只能发、不能自动收** | 客户开通，我们指导 |
| 服务器 | Windows Server（建议 2016 及以上），**4 核 8G / 100G 盘起**，内网可访问，能长期开机 | 客户 |
| 网络 | 服务器可访问企业微信服务；不需要公网 IP、不需要域名备案 | 客户 |
| 常驻登录 | 服务器上需保持企业微信客户端登录（首次扫码；建议配自动登录） | 客户配合，我们给配置清单 |
| 安装部署 | 首次由我们远程部署并演示 | 我们 |

> 关于"远程桌面断开后自动化失灵"：Windows 服务器在**远程桌面断开**时会锁屏/降分辨率，会影响客户端自动操作。我们会按标准做法配好（保持会话/自动登录），**这部分配置需要客户给我们管理员权限并接受**；客户自行改回默认设置导致失效的，属环境问题。

## 四、我们提供什么（买断交付物清单）

1. **客服工作台**（网页）：会话列表 / 聊天窗口 / 客户资料 / 分配与转接 / 常用语 / 消息搜索；
2. **会话接入服务**：把外部客户消息实时汇入工作台（依赖会话内容存档）；
3. **客户端助手**：在工作台点击发送时，按队列在企业微信客户端里完成发送并回传结果；
4. **部署文档 + 配置清单**：一台新机器从零装起来的完整步骤；
5. **首次远程部署**：1 个工作日内完成，并做一次演示验收；
6. **交付后 30 天内的缺陷修复**（不含新增需求）。

不含：会话存档费、服务器与网络、第三方 AI 服务费、定制开发（另议）。

**不买年度维护会怎样**：软件仍可继续用；但企微客户端/接口变更导致失效时，恢复需要按次付费（另议），响应也不保证时效。

## 六、风险与责任划分

| 情况 | 责任方 | 说明 |
|---|---|---|
| 软件自身缺陷、我们交付的功能不按文档工作 | **我们** | 维护期内免费修 |
| 企微客户端升级、官方接口/策略变化导致功能失效 | 维护期内**我们适配** | 超出维护期按次或按年续费 |
| 会话内容存档未开通 / 欠费 / 权限不足 | 客户 | 导致"收不到消息"，非软件缺陷 |
| 服务器关机、断网、磁盘满、远程桌面配置被改回 | 客户 | 我们提供检查清单与远程协助（维护期内） |
| 客户在服务器上手工操作企微账号（改密码、退出登录、多端挤下线） | 客户 | 会导致发送队列堆积，恢复需重新登录 |
| 企微官方明令禁止的用法（如群发骚扰、非本人账号） | 客户 | 我们不承接此类用法，也不承担由此产生的封号风险 |

**我们能承诺的边界**：在客户环境符合第三节清单、且企微未发生策略级变更的前提下，系统按第七节验收标准工作。

## 七、验收标准（上线时逐条演示）

1. **能收**：客户从一个外部联系人发消息，工作台 10 秒内出现，内容完整（含图片/文件提示）；
2. **能发**：工作台发出的消息，10 秒内在企微客户端送达客户，工作台显示"已发送/失败原因"；
3. **能看**：两个客服账号同时打开同一会话，看到相同历史；新客服能翻到接入前的留档（存档从开通日起）；
4. **断线重连**：重启服务器或客户端掉线后，系统自动恢复接收；发送队列不丢消息（失败有回执，可重发）；
5. **文档齐全**：部署文档按步骤能在新机器复现一次；交付时当面演示一遍。

## 八、多久能上线

标准环境（第三节清单齐备、会话内容存档已开通）**3–5 个工作日**：
第 1–2 天 部署与联调 → 第 3 天 收发与留档验收 → 第 4–5 天 客服试用与问题修复。
若存档开通尚在审批，可先上线"只发不收"模式（能发消息，历史留档等开通后补）。
