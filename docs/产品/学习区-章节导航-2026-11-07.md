# 学习区 · 答题页按「科目 → 课本 → 章节 → 子章节」改造 — 2026-11-07

> 主人原话：「去答题进去还是逻辑哲学论那几道，应该换成分科目作为页栏，里面装着课本，显示现在学到哪个章节了，可以做当前章节测验和过往章节习题，然后未来章节预览。但是灰色未解锁状态，根据目录定。每个子章节都要设置习题，比如逻辑学入门的1.1,1.2,1.3这种。」

---

## 一、页面结构（三层，不是一屏）

```
答题页（?view=quiz）
├─ 第一层：科目页栏（横向 pills）
│    数学 · 逻辑学 · 哲学 · 物理 · 化学 · 生物学 · 计算机
│
├─ 第二层：该科目的课本卡片
│    逻辑学 → 《逻辑学导论（第15版）》  进度 1/14 章
│
└─ 第三层：章节目录（关键）
     第1章 逻辑学的基本概念  ✅ 已完成（1.1 / 1.2 / 1.3 全过）
     第2章 论证的分析        🔵 正在学（可做本章测验）
     第3章 语言与定义        🔒 未解锁（灰，点不开，显示"需先完成第2章"）
```

**规则（按主人要求）**：
- **当前章**：可以做**本章测验**；
- **过往章**：可以做**练习/重做**（错题优先）；
- **未来章**：**灰色未解锁**，**只给"预览"**（能看目录与知识点名，**不能答题**）；
- **解锁依据**：**按目录顺序**（第 N 章解锁 = 第 N−1 章"读完 + 本章测验 ≥80%"）。

## 二、每个子章节都要有题（关键新增）

```
第1章 逻辑学的基本概念
├─ 1.1 什么是逻辑 / 1.2 命题与陈述 / 1.3 论证·前提·结论 …
   每个子章节 = 一个 quizzes 小节，**至少 2 题**（1 判断边界 + 1 费曼讲清）
```

**子章节号从哪来**：**`目录.md` 里只有章级（第1章 p13、第2章 p61…）**。
**子章节需要单独建一份 `章目录.json`**：

```json
{
  "book": "逻辑学导论",
  "chapters": [
    { "no": 1, "title": "逻辑学的基本概念", "page": 13, "status": "done",
      "sections": [
        { "no": "1.1", "title": "什么是逻辑", "page": 13, "questions": 3 },
        { "no": "1.2", "title": "命题与陈述", "page": 20, "questions": 2 }
      ] }
  ]
}
```

**来源纪律**：**子章节标题与页码必须从书的目录页抄**（PDF 第 3–4 页的细目），**不许自己编**。编不出来就写 `title:"待补"` 并标 `needsToc:true`。

## 三、题库结构扩展

现有 `题库\<书>.json` 是 `chapters:{"1":{questions:[]}}`——**加一层 sections**：

```json
chapters: {
  "1": { "title": "逻辑学的基本概念", "sections": {
      "1.1": { "title": "什么是逻辑", "questions": [ ... ] },
      "1.2": { "title": "命题与陈述", "questions": [ ... ] }
  }}
}
```

**兼容规则**：`chapters["1"].questions`（老结构）**仍然有效**，视为"章级混合题"；新题优先放 `sections`。

## 四、接口

```
GET /quiz/outline?bookId=逻辑学导论
  → { bookId, chapters:[{ no, title, page, status:"done|learning|locked",
        progress:{answered,total}, sections:[{no,title,page,questions,status}] }] }

GET /quiz?bookId=&chapter=2&section=2.3
  → 取该小节题（section 省略=整章）
```

**`status` 判定**（写死）：
- `done`：本章测验 ≥80% 且错题清零或已复盘；
- `learning`：本章有作答记录但未达标，**或**上一章 done；
- `locked`：上一章未 done。
