## 二、为什么这么分（三条原则）

1. **一份内容只放一处**：章节的产出（讨论/练习/错题/分析）**都挂在章下面**，不另建"讨论库/错题库"顶层目录——**顶层只放索引**。
2. **跨章的东西往上挂**：薄弱点、测试、复习**按学科或课本挂**，因为它们天生跨章。
3. **页面只读索引**：`索引\*.jsonl` 是页面唯一数据源，**扫盘留给后台任务**。

## 三、主页只留两块（主人定）

```
┌───────────────────────────────────────────────┐
│ 学习区                            [管理员助手] │
├──────────────────┬────────────────────────────┤
│ 学科抽屉           │                            │
│ ┌──────────────┐  │   今日：逻辑学导论 第2章     │
│ │ 逻辑学  第1章 │  │   待办：答 3 题 / 1 场讨论   │
│ │ 进度 12%      │  │                            │
│ ├──────────────┤  │                            │
│ │ + 新学科      │  │                            │
│ └──────────────┘  │                            │
└──────────────────┴────────────────────────────┘
```

- **左：学科抽屉**（一个学科一张卡：名字 / 当前课本 / 进度 / 待办数）；
- **右：学习区管理员助手**（就是 S01 书童）：**今天读什么、有几道错题、要不要开一场讨论**，一句话说清；
- **不在主页堆功能**：所有二级内容（章、讨论、错题、测试、复习）**点进去才有**。

## 四、点进学科之后（二级页）

```
逻辑学
├ 课本：逻辑学导论（在读，第 2/14 章）
├ 章节列表：第1章 ✅ / 第2章 🔵 / 第3章 ⚪ …
├ 薄弱点：3 条（有效vs可靠、判据、词源）
├ 测试：期中（未考）期末（未考）
└ 复习：11 月复习计划（8 章待复查）
```

**点某个章 → 章页**：正文 / 笔记 / 知识点分析 / 讨论（几场）/ 练习（几题）/ 错题（几条）/ 掌握度。
