# 学习区 · 出题规则（2026-11-06 主人定）

> 主人原话：「以后出题的时候可以去知乎做调研」

---

## 一、调研用在哪（只用三处）

| 用途 | 怎么用 | 不许用来干什么 |
|---|---|---|
| **① 找常见误解** | 搜「为什么 X 总是学不会 / X 的理解误区」，把**高频错误**提炼成题目要考的点 | ❌ 不许当判定标准 |
| **② 校准难度** | 看同类问题下**答主的水平分布**，判断这道题对"毕业生"算难还是算浅 | ❌ 不许抄题目原文 |
| **③ 找"边界问题"** | 高赞回答里最有价值的往往是**"什么时候这个说法不成立"**，这正是边界题的好素材 | ❌ 不许拿回答当标准答案 |

**一句话**：**调研是为了知道"人会怎么错"，不是为了知道"什么是对的"。**

## 二、判定标准从哪来（不许松）

| 顺序 | 来源 |
|---|---|
| 1 | **教材原文**（有页码） |
| 2 | **课程大纲 / 权威百科**（学科词典、Stanford Encyclopedia 这类） |
| 3 | **公开课讲义**（名校课程） |
| **禁用** | **知乎/小红书/公众号的"个人观点"**——**只能当"常见误解"的线索，不能当判据** |

## 三、每条题目的来源要写清

```json
{
  "id": "math-q3-probability",
  "stem": "有人说'要么发生要么不发生，所以概率 50%'，这话错在哪？",
  "keyPoints": [...],
  "source": {
    "judgeBy": "教材：《概率论与数理统计》第1章（基线/样本空间）",
    "misconceptionFrom": "知乎问题「为什么很多人误以为概率只有 50%？」高赞答（2026-11 检索）",
    "researchAt": "2026-11-06"
  }
}
```

**硬规矩**：
- **`judgeBy` 必须写**（判据来源），**没有就不许出题**；
- `misconceptionFrom` 是**加分项**（有它，题目更"抓人"）；
- **调研要记日期**（知识会过期，尤其技术类）。

## 四、调研的边界（防止跑偏）

1. **每个知识点最多查 3 个来源**——查多了会陷入"哪个说法对"的泥潭；
2. **不采信"某某老师说的"**（无出处）；
3. **发现知乎与教材冲突时，以教材为准**，并把冲突记进题目的 `conflicts[]`（**这本身是很好的考点**）；
4. **不许把知乎回答直接贴进题目**（版权 + 质量）。

## 五、什么时候调研

| 场景 | 要不要调研 |
|---|---|
| 新学科的第一套摸底卷 | **要**（先知道这门课"难在哪"） |
| 常规章节练习 | **可选**（有教材就够了） |
| 边界题 / 易混题 | **要**（这类题最需要"常见误解"素材） |
| 费曼题 | **不必**（费曼题考的是"能不能讲清"，不考偏门） |
