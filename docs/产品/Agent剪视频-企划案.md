## 一、职责边界（先说清，省得白干）

| 我负责 | 你负责 |
|---|---|
| 切分素材、去废段、去静音、场景切分 | **审美判断**：哪条好用、节奏快慢 |
| 转码/压缩/改规格（1080p、9:16、竖版裁切） | 选封面、定标题 |
| 自动字幕（ASR）+ 打轴 + 烧字幕/导出 srt | 改错别字（ASR 一定会错几个） |
| 按规则批量出候选（前 3 秒钩子、15/30/60 秒版本） | 拍板定稿 |
| 导出**剪映草稿**（你打开就能改）或直接出 mp4 | 特效用剪映做 |

**核心原则**：**能机器判定的都自动化，凡是"好不好看"的留给你。**

---

## 二、架构（五层，每层只依赖下一层）

```
① 素材层      素材\*.mp4  →  索引（时长/分辨率/码率/帧率）
② 理解层      ASR 转写 + 场景切分 + 静音检测 + 人脸/主体跟踪
③ 决策层      LLM 读转写+切点 → 选出"能用的片段"与顺序（这就是 Agent 的部分）
④ 执行层      ffmpeg 剪切/拼接/转码/烧字幕；Remotion 做动效（可选）
⑤ 交付层      直接 mp4  ／ 剪映草稿 .draft（你在剪映里精修）
```

**为什么这么分**：②③④ 每层都能单独验收；**任何一层坏掉不会连坐**。

## 五、分三期落地

### 一期（1–2 天，不装新东西就能跑）

- **素材索引 + 批量转码 + 去静音段 + 抽封面候选**；
- 交付：你给 5 条原片，我出 **1080p 精简版 + 3 个封面候选 + 一份"废段清单"**；
- 判据：**处理 10 分钟素材 ≤ 3 分钟**，体积下降 ≥ 40%，**画面不糊**。

### 二期（3–5 天，装 whisper）

- **自动字幕**（中文）+ 可选烧字幕；
- 交付：带字幕成片 + `srt`（可导入剪映继续改）；
- 判据：**字幕错字率 ≤ 5%**（抽样 50 句），时间轴偏差 ≤ 0.3 秒。

### 三期（1 周，接剪映草稿）

- **导出剪映工程**，你在剪映里继续做转场/特效；
- 交付：`.draft` 目录可直接被剪映打开；
- 判据：剪映打开无报错、分层正确（视频轨/字幕轨/音频轨分开）。
