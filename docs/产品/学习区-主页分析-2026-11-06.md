# 学习区主页 · 分析模块（2026-11-06 主人定）

> 主人原话：「主页应该加一个分析模块，对于各个学科的掌握进度，若属于职业技能的话当前行业水平，学科知识理解程度和随机知识库闪卡判断题」

## 一、主页分析模块（四块，从粗到细）

```
┌ 学科掌握 ────────────────────────────────────┐
│ 逻辑学     学了 1/14 章 · 掌握 34%   ▓▓░░░░░  │
│ 保险实务   学了 0/? 章 · 掌握 —      ░░░░░░░  │
└──────────────────────────────────────────────┘

┌ 职业技能水平（仅 type=skill 的学科）──────────┐
│ 保险实务   自评档位：入门 → 目标：中级         │
│ 行业线：能独立核保/理赔基础件（依据：…）        │
│ ⚠ 这是自评档位，不是职业认证                    │
└──────────────────────────────────────────────┘

┌ 理解程度（按学科，5 档）──────────────────────┐
│ 逻辑学   ████░  4/5   依据：讨论通过 1 · 错题 3 │
└──────────────────────────────────────────────┘

┌ 随机闪卡 ────────────────────────────────────┐
│ 「有效性适用于单个命题吗？」                    │
│ [ 适用 ]  [ 不适用 ]        ← 点完立刻判        │
└──────────────────────────────────────────────┘
```

## 二、四个指标怎么算（**必须可解释，不许拍脑袋**）

### 2.1 掌握进度（两个维度，别混成一个数）

| 维度 | 算法 | 说明 |
|---|---|---|
| **学了多少** | `已读完章数 / 总章数` | 只数"读完"（摘录≥5 + 感想 + 审核过） |
| **掌握多少** | `章节掌握度均值` | 每章掌握度见 2.3 |

**展示必须两个都露**：**只给一个数会误导**（读了 10 章全半懂 vs 读了 3 章全懂）。

### 2.2 理解程度（5 档，按学科）

```
章理解度 = 0.4×讨论判定分 + 0.3×(1 - 错题率) + 0.3×笔记完整度
  讨论判定：pass=1、half=0.5、fail=0、没讨论=null（不计）
  错题率  ：本章错题数 / 本章作答数
  笔记完整度：摘录≥5 且 感想≥80字 = 1，缺一样 0.5
学科理解度 = 有数据章节的加权均值 → 映射到 1–5 档
```

**没数据的科目显示「暂无数据」，不许显示 0**（0 和"没学"是两回事）。

### 2.3 职业技能水平（**最容易造假的一块，必须设门槛**）

**学科需在 `索引\subjects.jsonl` 标 `type:"skill"`**，并配 `benchmark`：

```json
{
  "id": "insurance",
  "type": "skill",
  "benchmark": {
    "levels": ["入门", "初级", "中级", "高级", "专家"],
    "current": "入门",
    "target": "中级",
    "basis": "能独立处理录单/保全/基础理赔；依据：保险从业资格考纲 2026 + 彭艳日常工单范围",
    "verifiedAt": "2026-11-06",
    "by": "本体人工设定"
  }
}
```

**硬规矩**：
- **行业线必须写 `basis`（依据什么判断的）**，**没依据就写「未设定基准」，不许编**；
- **必须标「自评档位，不是职业认证」**；
- **只有本体/主人能改档位**，程序不许自动调（避免"自我感觉良好"）；
- 档位变更留审计（`索引\benchmark-log.jsonl`）。

### 2.4 随机闪卡判断题（主页底部一条）

- **从哪些题抽**：`题库\*\*.json` 里的**判断题/边界题**（`kind:"boundary"|"judge"`），**加上** `卡片\` 里的闪卡；
- **抽题规则**：**优先抽到期的**（间隔重复 1/3/7/15 天），**没到期就随机**；
- **只出一条**，答完立刻判，**显示**：对/错 + 一句解释 + 「明天再来」；
- **答错自动进错题集**（跟章页错题同一本）。

## 三、接口（沿用 9351）

```
GET  /analysis/overview        → {subjects:[{id,name,type,learned,total,mastery,understanding,benchmark?}]}
GET  /analysis/subject?id=     → {chapters:[{no,title,status,understanding,wrongCount,discussions}]}
GET  /analysis/flashcard?due=  → {card:{id,front,back,kind,source}, dueAt}
POST /analysis/flashcard/answer {cardId, correct} → {ok, nextDue, streak}
```

**错误码**：400/404；**没有数据时返回空数组 + `note:"暂无数据"`**，不许返回假数。

## 四、验收

- ① 主页四块都出现（截图），**"暂无数据"的科目显示为「暂无数据」而不是 0**；
- ② 逻辑学显示 `学了 1/14 · 掌握 X%`，并解释 X 怎么来的（点「?」能看到公式）；
- ③ `type:skill` 的学科显示档位 + 目标 + **依据** + "非职业认证"提示；
- ④ 闪卡：点选项立刻判对错，答错进错题集（截图 + 错题文件新增一行）。
