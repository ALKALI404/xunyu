# 学习区 · 费曼讨论（气泡对话）规格 — 2026-11-06

> 主人原话：「费曼的论述题做成气泡对话框的形式，因为存在追问和讨论的可能，直接每次完成之前拉一个专员起来读相关知识点然后分裂成评判考官和小白，讨论完成后归档记录保存在本地可以随时查阅」

---

## 一、为什么费曼题不能做成"填空题"

**知识点题 / 边界题**：一次判断就能给分，**单轮足够**。
**费曼题**：要的是"能不能讲明白"，**必须允许追问**——
**小白听懂了没有，只能靠继续问才知道。**

**所以费曼题 = 一场对话，不是一次提交。**

- **顶栏两颗按钮**：`暂停`（下次接着聊）、`结束并判定`。

## 三、每道费曼题的会话编排（关键）

**开始一道费曼题时，系统自动做到四件事**：

```
① 拉一个「专员」会话（学习区工作区里新建，用完归档）
        ↓  任务：读这道题涉及的 keyPoints + 原文段落
② 专员读完后「分裂」成两个角色（同一会话内，不同人设）
        ├─ 🐣 小白：知道前提、没学过这个知识点；只问不评判
        └─ ⚖️ 考官：不参与追问，只在两处出现——
              · 每轮悄悄看你的回答有没有跑偏（不打断）
              · 结束时给判定 + 卡在哪
③ 你和小白来回（≤8 轮，避免无限聊）
④ 小白说「我能复述了」或你说「结束」→ 考官判定 → 归档
```

**硬规矩**：
- **小白不许给答案**（它只能问、只能复述，**复述走样就是没过**）；
- **考官不许在对话中插话打断**（只在侧栏记批注，结束时出结论）；
- **轮次上限 8 轮**，到 8 轮直接进判定，**不许无限拖**；
- **每轮都要落盘**（聊到一半崩了，能接着聊）。

## 四、结束时的判定（三条）

| 判据 | 说明 |
|---|---|
| **① 术语配了人话** | 用了术语没关系，但**每用一次得解释一次** |
| **② 追问两轮不倒** | 小白连问两次都答得上 |
| **③ 小白能复述且不走样** | 小白用自己的话说一遍，**含义没偏** |

**三条全中 → `pass`；中两条 → `half`；≤1 → `fail`。**

**同时**：结论摘要（≤200 字）同步进 `memory\long-term.md` 的「读过的书」段 + QQ 记忆（**跟章笔记一样的规矩**）。

## 六、接口（沿用 9351）

```
POST /feynman/start  {bookId, questionId}   → {discussionId, bubbles:[{role:"narrator",text:"题面"}], knowledgePoints:[]}
POST /feynman/say    {discussionId, text}   → {bubbles:[{role:"xiaobai"|"examiner",text}], round, done:false}
POST /feynman/end    {discussionId}         → {verdict, missing[], archivePath, summary}
GET  /feynman/history?bookId=               → {items:[{id,title,date,verdict,path}]}
GET  /feynman/get?discussionId=             → {bubbles, meta}   （接着聊/回看）
```

**错误码**：400 参数错 / 404 讨论不存在 / 409 已结束 / 504 专员超时（超时保留已聊内容）。
