# 学习区 · 摸底题规格（v1，2026-11-06）

> 用途：主人在读目标书之前，先判断**前置段**有没有空白——有空白才补课，没空白就别浪费时间。
> 关联：`学科\_tree.json` 的 `gates[]` 与 `题库\`；一条路径上的门槛，就是这份规格的出题范围。

## 一、先 grill，再出题（每道目标先问 3 个问题）

| # | 问题 | 答案怎么影响出题 |
|---|---|---|
| 1 | **想读哪本**（哪一版/哪个译本）？ | 决定目标节点与它的前置闭包；同名不同版能差出一整个前置学科 |
| 2 | **读到什么程度**（翻翻 / 读懂论证 / 能复述给外行）？ | 决定停在目标书还是继续往后；「读懂论证」= 本规格默认口径 |
| 3 | **现在什么水平**（读过哪些、有无相关课程/书）？ | 决定哪些节点直接标 `mastered` 跳过；答"没读过"不等于零基础——**主人是毕业生，语数英在线，不假设零基础** |

**规矩**：这三问答完才出题；答不出（比如"我也不知道读没读过"）就先给**一页前置书单摘要**让主人认，认完再出题。

## 二、出题范围：只考前置段，不考目标书

- 只考**目标节点之前**（倒推路径上除 target 外的节点）的核心概念；
- **绝不考目标书内容**（没读过凭什么考）；
- **导论（牛津通识读本 / Very Short Introductions）与名校公开课都算前置**（学术出版社 / 大学课程），可以进书单；
- **大众科普与休闲读物仍排除**（"一本书读懂哲学"这类不算）；
- 每个前置节点 2–4 题，合计 **8–12 题**；
- 题目形态：**判断对错 + 一句解释**（不许只给选项；解释错了也算错）。

## 三、判分与跳过

| 规则 | 值 |
|---|---|
| 及格线 | **答对 ≥80%**（8 题对 7、10 题对 8、12 题对 10） |
| 及格后 | 该前置节点可标 `mastered`，**但必须主人点一次确认**（不自动跳） |
| **<50%** | **加前置学科节点**（真空白：这个学科要从头补），并挂到倒推路径上 |
| **50–80%** | **补一节**（不新加学科，只补那个薄弱小节/章节） |
| **>80%** | 可跳，**需主人点确认** |
| 记录 | `学科\<学科>\摸底-<YYYYMMDD>.json`：题目、答案、判分、结论（加前置 / 补一节 / 跳） |


**为什么要求点确认**：摸底是抽样，不是证明。人判一次"我确实会"比系统替他说"你会"可靠。

## 三·五、番茄钟节奏（主人 2026-11-06 22:32 定）

- 每天 **2 小时阅读 + 2 小时测验**；
- **当天目标默认"读完当前章节"**，计划别按"每天 1 章"死排（章有长有短，按页数/难度走）；
- `effortHours` 按 **2 小时 ≈ 40–60 页学术书**估（同一口径写在倒推规则 §三.5）；
- **`far-future` 节点不进每日计划**（不排番茄钟、不占当天 goal，也不显示进度条）：目前只有《数学原理》是这个档位，卡片上挂一句「远期目标 · 需先补数理逻辑 + 集合论（预估 3–6 个月）」，想看时手动展开（见倒推规则 §三.8）。

## 四、示例题（罗素《哲学问题》的前置段：逻辑 + 认识论）

> 每题：先判断对错，再用一句话解释（解释是评分主体）。

**Q1（命题逻辑）**「一个论证的前提全真、结论也真，就说明这个论证是有效的。」判断对错，并说明理由。
　判：**错**。有效性看的是"前提真时结论**必然**真"（形式），不是碰巧这次都为真；前提真结论真也可能只是巧合。
　评分点：提到"必然/形式"给分；只说"结论对"不给分。

**Q2（归纳问题）**「我们见过的天鹅都是白的，所以所有天鹅都是白的——这个推理是演绎有效的。」判断对错并解释。
　判：**错**。这是归纳，前提真推不出结论必然真（黑天鹅）；演绎有效要求前提真结论不可能假。
　评分点：区分归纳/演绎 + 指出"可能被反例推翻"。

**Q3（认识论）**「只要一个人的信念是真的，他就'知道'这件事。」判断对错并解释。
　判：**错**。知识通常要求"真 + 有辩护（justified）"，碰巧为真不算知道（盖提尔问题就是拿这个开刀）。
　评分点：出现"辩护/理由/证据"任一即算；只说"真"不给分。

## 五、与门槛（gate）的关系

- `_tree.json` 里每个 `gate` 指向一个题库文件（`题库\*.json`）；摸底题就是题库里的题；
- **门槛的 `pass` 是硬线**（0.75–0.8），摸底不及格就不解锁后续节点；
- 题库目前只有 `题库\逻辑学导论.json` 是真的，其余 5 个是 `TODO-*` 占位——**校验脚本会给 W_BANK_MISSING 警告**，不算失败，但要在页面上写"这一步的题还没出"。
