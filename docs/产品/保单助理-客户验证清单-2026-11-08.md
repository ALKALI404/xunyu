## 五、明早演示的 5 分钟脚本

```
① 打开 http://127.9.1.1:9343  →  保单列表（20 张）
② 点开「单-0001」 → 第二条 投保范围
③ 念给他听：
   原文：本合同接受的被保险人的投保年龄为出生满60天至70周岁
   人话：这份合同对投保年龄有要求：出生满60天到70周岁之间才在范围内
   边界：句末"1"是脚注、脚注正文没给 → 60天/70周岁算不算当天、怎么截止，光看这段无法确定
④ 划出 flags：ambiguous / needs-insurer-confirm / version-unconfirmed
⑤ 切到「家庭」→ 展示他家有几张保单、谁是被保人
⑥ 收尾一句：没核实的条款我们只给原文，不给解读（示范一次 unverified）
```

**客户最可能问的三句，答案准备好**：
- **「它会不会瞎编？」** → **没核实就只给原文**，有 `unverified` 状态卡着，这是设计出来的硬门；
- **「数据在哪？」** → **全在本机**，不出这台机器，不走公网；
- **「能微信问吗？」** → **能，但这周故意关着**，先用小号验证，不碰真实客户。
