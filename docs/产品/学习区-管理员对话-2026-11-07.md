# 学习区 · 管理员助手（内嵌对话）规格 — 2026-11-07

> 主人原话：「管理员助手做成类似窗口的对话框吧，它可以给超链接直接进对应的测试、读书笔记、思维导图和调用知识回答问题这些功能，内嵌在网页」

---

## 一、形态

**网页内嵌的对话窗**（右下角悬浮，可展开/收起），**不是跳新页面**。

```
┌ 学习区                                        ┐
│  学科卡 ×7            ┌──────────────────┐  │
│                       │ 🐟 管理员 S01     │  │
│                       │ 今天读第2章；     │  │
│                       │ 3 道错题待复盘    │  │
│                       │ [去答题] [看错题] │  │
│                       │ 我说：想复习熵…   │  │
│                       │ 给你：定义卡 + 讨论│  │
│                       │ [打开]           │  │
│                       └──────────────────┘  │
└──────────────────────────────────────────────┘
```

- **悬浮球 → 展开成对话**；默认**收起**（不挡学科卡）；
- 每条回复可带 **1–3 个"链接卡"**（不是裸 URL）；
- **回车发送**，**Shift+回车换行**；
- 支持**语音输入**（可选，第二轮再做）。

## 二、链接卡的四种类型（统一成同一种卡片样式）

| 类型 | 图标 | 点开去哪 | URL 约定 |
|---|---|---|---|
| **测试** | 📝 | 答题页并定位到该卷 | `/?view=quiz&book=<卷名>` |
| **读书笔记** | 📄 | 文件预览页（markdown 渲染） | `/file?path=<相对 study 的路径>` |
| **思维导图/知识点分析** | 🗺 | 同上（md 渲染，图由 mermaid 渲染） | `/file?path=...` |
| **讨论记录** | 💬 | 该场费曼对话回看 | `/?view=feynman&id=<discussionId>` |

**卡片内容**：`{type, label, sub, url}`，`sub` 写一句"这是什么"（例："第1章 12 条摘录 / 判定：半对"）。

## 三、助手能做什么（工具集，第一批只做四个）

| 工具 | 输入 | 输出 | 谁实现 |
|---|---|---|---|
| **① 找资源** | 关键词（"熵"/"第2章"/"错题"） | 1–3 张链接卡（测试/笔记/导图/讨论） | 04（检索索引 + 目录） |
| **② 报今天** | 无 | "今天读第X章 + 错题N道 + 待复盘N场" + 两个快捷按钮 | 04（读索引/进度） |
| **③ 调知识回答** | 问题 | 先查 `memory\library\knowledge\**` 与笔记摘要，**有据才答**；**没词条就说"我没写过这个词条，只知道个大概"** | 04 |
| **④ 开一场费曼** | "考考我 <知识点>" | 直接调 `/feynman/start`，返回"已开好，[进入讨论]" | 04 |

**红线**：
- **不许编链接**（链接必须是文件真实存在或接口真实可用的，**打不开就要报错给我，不许给死链**）；
- **不许拿训练数据当知识回答**（没词条就承认，按《知识边界》那条走）；
- **回复 ≤120 字**（对话框，不是文章）。

## 四、接口

```
POST /assistant/chat   { text, context?:{bookId?, questionId?} }
  → { reply, links:[{type,label,sub,url}], actions?:[{"label":"去答题","url":"..."}] }

GET  /file?path=<相对 study 的路径>     → 渲染后的 HTML（markdown→html，mermaid→代码块保留）
```

**错误码**：400 参数 / 404 文件不存在 / 501 助手会话不可用（**诚实报错，不许假装回答**）。

**实现方式**：`/assistant/chat` **转给 S01 会话**（`session-62f53ecd-…`），S01 用工具产出答案 + 链接；**服务端只做转发与校验**。

## 五、验收

- ① 网页右下角有悬浮球，点开是对话框（截图）；
- ② 问「想复习熵」→ 返回**定义卡链接 + 讨论记录链接**（截图，点开能打开）；
- ③ 问「今天做什么」→ 返回进度 + 两个快捷按钮（截图）；
- ④ 问一个**没词条**的问题 → 回答「我没写过这个词条」（截图，证明不编）；
- ⑤ 点一个笔记链接 → **能预览 markdown**（截图）；
- ⑥ 给一个**不存在的资源** → **明确说没有**，不给死链（截图）。
