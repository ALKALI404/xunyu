## 三、数据契约

### 3.1 `复习\cards.jsonl` —— 一行一卡（UTF-8，无 BOM，`\n` 结尾）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `cardId` | string | ✅ | 稳定 id，`fc-<subject>-<slug>-<n>`；**建了就不改**（旧库 `id` 迁移时改名到此） |
| `kind` | `judge` \| `definition` \| `feynman` | ✅ | 判断题 / 定义卡 / 费曼题 |
| `front` | string | ✅ | 问题面，1–200 字 |
| `back` | string | ✅ | 答案面（md），≤ 2,000 字；空串合法但 UI 要显示占位 |
| `answer` | boolean | judge 必填 | 判断题的标准答案；其它 kind 不写 |
| `subjectId` | string | ✅ | `logic` / `physics` / … |
| `chapter` | number \| null | | 章号（`1` = 第01章）；定义卡可 null |
| `source` | string | ✅（可为 `""`） | 出处，指回 md 的某节，如 `学科\物理\定义地图\力功能量动量.md §一` |
| `wrongFile` | string \| null | | 答错时写哪个错题集（相对 STUDY，越界拒写） |
| `by` / `createdAt` | string | ✅ | 谁建的 / ISO 时间 |
| `due` | ISO string | ✅ | 下次到期（FSRS 产出；新卡 = 当天） |
| `stability` / `difficulty` | number | ✅ | FSRS 状态（新卡 0 / 初始值由 `init` 给） |
| `reps` / `lapses` | number | ✅ | 复习次数 / 忘了几次 |
| `lastReview` | ISO \| null | | 上次复习时间 |
| `state` | `0`\|`1`\|`2`\|`3` | ✅ | **存 ts-fsrs 原义数字**（New/Learning/Review/Relearning），接口层再翻成文案；不存中文，免得算法侧要反查 |
| `scheduledDays` / `learningSteps` | number | ✅ | ts-fsrs 续跑必需（新卡两次 Good 之间是 10 分钟学习步，只靠 `due/stability` 复现不出来） |
| `stateLabel` | string | 仅接口层 | `新卡/学习中/复习/重学`，由 `state` 派生，**不写进 jsonl** |
| `lastRating` | 1–4 \| null | | 上次评分（1 Again / 2 Hard / 3 Good / 4 Easy） |

**坏行策略**：解析失败的行**原样保留**（不要静默丢），启动时统计 `badLines` 并在 `/cards/due` 的响应里带 `badLines`。

### 3.2 迁移规则（`卡片\` → `复习\`，一次性，可重跑）

```
对每张卡 c（旧库字段是 id）：
  输出行 cardId = c.id，其余内容字段原样搬
  row = 旧 _schedule.jsonl 里 cardId=c.id 的行
  无 row           → state=new, due=今天, reps=0, lapses=0
  row.lastResult=right → 从 row.lastAt 起按 Good(3) 连打 min(row.streak,4) 次
                          → state=review, reps=streak, lapses=0
  row.lastResult=wrong → 从 row.lastAt 起打一次 Again(1)
                          → state=relearning, reps=max(streak,1), lapses=1
  最后：若产出的 due 早于"今天"且是空卡，保留产出值（不做二次校正）
```
- 迁移脚本必须**幂等**（按 id 覆盖，不追加重复行）；
- 迁移后跑一次 `due`，断言 4 张卡的 `due` 都是合法 ISO 且 `reps>=1`；
- 旧文件：`卡片\_legacy\cards.jsonl` / `卡片\_legacy\_schedule.jsonl`，只读保留。

### 3.3 对外「卡片视图」（HTTP 与前端唯一形状）

```json
{ "cardId":"fc-logic-sound-1", "kind":"judge", "subjectId":"logic", "chapter":1,
  "front":"一个论证有效，就一定可靠。", "back":"不对。可靠=有效+全部前提为真…",
  "answer":false, "source":"学科\\逻辑学\\…\\笔记.md · p55",
  "due":"2026-11-08", "state":2, "stateLabel":"复习", "reps":1, "lapses":0, "overdueDays":0 }
```
> `due` 在**接口层截到日期**（`YYYY-MM-DD`），内部存完整 ISO；`overdueDays` = 今天 − due 的天数（最小 0）。理由：页面只按天说话，别把时区问题带到 UI。

## 四、模块契约（`复习\scheduler.mjs`，纯函数）

```js
init(card, now = new Date())            → record        // 新卡：due=now、state=0、reps/lapses=0
review(card, rating, now = new Date())  → record        // 返回新记录，**不改入参**；rating ∈ 1..4 或 Again/Hard/Good/Easy
due(now = new Date(), limit = Infinity, file = CARDS_FILE) → card[]   // 读库、按 due 升序（同 due 按 cardId 稳定）
loadCards(file?) / saveCards(cards, file?) / upsertCard(card, file?)  // 唯一的 I/O 三件套
normalizeRating(rating)                 → 1..4          // 非法 → RangeError
```

**硬约束**
1. `init` / `review` / `due` / `normalizeRating` **不写盘**（`due` 可读，`file` 参数只给测试覆盖用）；写盘只在 `loadCards/saveCards/upsertCard`；
2. `rating` 不在 1–4（含 `0/5/3.5/"meh"/null`）→ **抛 `RangeError`**，不静默当 Good；
3. `review` 传未 `init` 的记录（无 `stability`）→ **抛错**，消息点名卡；
4. `saveCards` 必须**原子写**（临时文件 + rename），坏行不静默丢；
5. ts-fsrs 从 `vendor\ts-fsrs` 引，**零改动**；字段映射（`toFsrsCard`/`toRecord`）写在一处；
6. `due` 的"今天"由调用方给 `now`，模块不自己取系统时钟（ST-122 的"今天要复习几张"按调用方口径算）。

**验法**：`node --test 复习\scheduler.test.mjs` —— ST-121 已交付 **12/12**（含 5 条反例），本契约追加 **2 例**：① 迁移后 4 张卡 `reps>=1` 且 `due` 合法；② 迁移脚本重跑两次结果一致（幂等）。

**I/O 契约（就在 `scheduler.mjs` 里，不另建 store 文件）**：`loadCards(file?)` / `saveCards(cards, file?)` / `upsertCard(card, file?)`；一行一卡、原子写（tmp + rename）、写前当天首次备份 `.bak-<YYYYMMDD>`。
**迁移**：单独一个一次性脚本 `复习\migrate-legacy.mjs`（可重跑，幂等；跑完打印 4 行迁移报告 + 新旧 due 对照）。**只有它读 `卡片\_legacy\`**。

## 五、HTTP 契约（引擎 9351；9350 反代白名单必须同步加）

> **坑（04 交接里点名过）**：`脚本\study-web.mjs:39` 是**硬编码前缀白名单**（`/quiz`、`/book/`、`/analysis/`、`/assistant/`…）。新路由如果只在 9351 上，`9350` 会直接 404。**加 `/cards/` 与 `/note`两个前缀，并写进反代表的同一行注释。**

### 5.1 卡片

| 方法/路径 | 请求 | 成功 | 失败 |
|---|---|---|---|
| `GET /cards/due?limit=20&subjectId=` | — | `200 {ok, today, count, badLines, cards:[卡片视图]}` | — |
| `POST /cards/review` | `{cardId, rating?\|correct?, now?}` | `200 {ok, card, next:{due,stability,difficulty,reps,lapses,state}}` | `400` 缺 cardId/rating 非法；`404` 没有这张卡 |
| `POST /cards/create` | `{front, back, kind?, answer?, subjectId, chapter?, source?}` | `201 {ok, card}` | `400` front 空 / judge 缺 answer / back>2000；`409` id 已存在 |
| `PATCH /cards/:cardId` | `{front?, back?, answer?}` | `200 {ok, card}` | `400` 同上；`404` |
| `GET /cards/draw?n=5` | — | `200 {ok, cards:[卡片视图]}`（**只读，不改调度**） | `200` 空库 → `{ok, cards:[], note:"还没卡可抽"}` |

- `correct` 与 `rating` **二选一**：`correct=true → 3(Good)`、`false → 1(Again)`（兼容老页面）；
- **别名**：`GET /api/review/due?limit=N` 与 `GET /cards/due` 同一个处理函数（ST-122 票面写的是前者）——先别删，标 `deprecated`，一个版本后只留一个名字；
- 答错 → 复用现有 「写 `wrongFile`」逻辑（`analysis.mjs:appendWrongCard`），**不另写一套**；
- `GET /analysis/flashcard?due=1`、`POST /analysis/flashcard/answer` **保持不变**（内部改调 scheduler），主页零改动。

### 5.2 笔记

| 方法/路径 | 请求 | 成功 | 失败 |
|---|---|---|---|
| `GET /note?bookId=&chapter=` | — | `200 {ok, path, md, mtimeMs, bytes}` | `404 {error:"no-book"\|"no-chapter"}` |
| `POST /note/save` | `{bookId, chapter, md, baseMtimeMs}` | `200 {ok, mtimeMs, bytes}` | `409 {error:"conflict", currentMtimeMs}`；`400` md>2MB / 参数缺；`404` |

**路径解析（唯一规则）**
```
索引\books.jsonl → book.path（如 学科\逻辑学\课本\逻辑学导论）
+ 章节\ 下以 `第{NN}章` 开头的目录（NN 两位补零）→ 该目录\笔记.md
```
- 章目录不存在 → `404 no-chapter`，**不自动建目录**（建章是另一件事）；
- 解析结果必须 `path.resolve` 后仍在 `STUDY` 内，否则 400（防穿越）；
- `path` 只在**本机接口**返回；对外展示只用 `bookId + chapter`。

## 六、卡片界面契约（ST-124 / 125 / 126）

### 6.1 状态机（一个组件，三处复用：复习页 / 主页「来一张卡」/ 抽问）

```
loading → front ──Space/Enter/点击──→ back ──1..4──→ rated(300ms) → 下一张
   │         │                            │
   │         └─ Esc ─→ 退出                └─ 无背 → 显示「（这张卡还没背面）」，仍可评分
   └─ 失败 → error（「读不到卡片」+ 重试按钮，不白屏）
```
- `back` 用**现成的 md 渲染函数**（`web\index.html` 里已有），**不引第二套渲染器**；
- `back` 超过 12 行 → 折叠 + 「展开」；表格/代码块横向溢出 → 容器 `overflow-x:auto`；
- 卡头固定显示：`due` 相对文案（今天到期 / 逾期 N 天 / 新卡）+ `state` 中文（新卡/学习中/复习/重学）；
- 键盘：`Space`/`Enter` 翻面；`1–4` 评分；`Esc` 退出；**焦点必须在卡片容器上**（`tabindex=0`），否则手机端空格会滚页；
- **不靠 hover** 出答案，触屏也要能用；
- 空态（0 张到期）：`今天没有到期的` + [抽问] 按钮（ST-126）；
- 抽问 = `GET /cards/draw?n=5`，**只读**；抽到的卡评分时仍走 `POST /cards/review`（照常记进度）。

### 6.2 建卡（ST-125）

- 入口：笔记/摘录里**选中文字** → 浮动「建卡」→ 表单预填：`front`=选中文本（可改，默认加"？"提示）、`back`=所在段原文、`source`=文件+节标题（自动带）；
- 表单校验同 §5.1 `create` 的 400 条件，**前端先挡一次**（别等 400 才发现 front 空）；
- 保存成功 → 卡片列表 +1、给出「去复习」链接；失败 → 显示服务端 `message` 原文，不吞。

## 七、笔记编辑器契约（ST-127 / 128 / 129）

### 7.1 落盘（改票面）

- **写回学科树里那份**：`学科\<学科>\课本\<书>\章节\第NN章-<章名>\笔记.md`；
- **不新建 `笔记\`**，不搬现有文件，不改 md 内容格式（不加 frontmatter、不改标题层级）；
- vendor：`vendor\vditor\`（v4.0.1，MIT，**必须留 LICENSE**；`cdn` 选项指向本地 `vendor\vditor\`，**不许联网取资源**，否则 ST-129 的离线要求直接废）。

### 7.2 自动保存状态机

```
idle ──编辑──→ dirty ──3s 防抖/失焦/页面隐藏──→ saving ──200──→ saved
                  ↑                                  │
                  └────────── 400/网络错误 ←─────────┘ error（顶栏红点「未保存」+ 重试）
409 conflict → 弹二选一：【用磁盘的】【用我的覆盖】，默认不选、不自动覆盖
```
- 顶栏三态固定文案：`已保存 / 保存中… / 未保存（点此重试）`；
- `baseMtimeMs` 必须是**打开时**拿到的那个值；保存成功用响应里的新 `mtimeMs` 更新；
- 页面隐藏（`visibilitychange`）必须 flush 一次，防关窗丢内容；
- 失败重试：退避 2s/5s/15s，最多 3 次，之后维持红点等手动。

### 7.3 降级（ST-129）

- Vditor 脚本加载失败（本地文件缺失/被拦）→ **自动降级** `<textarea>` 编辑 md 原文，保存走**同一** `POST /note/save`；
- 顶栏加一条灰条「简易编辑模式（预览与工具栏不可用）」，**不弹错误、不白屏**；
- 降级后内容与正常模式**完全等价**（同一份 md），不许出现"简易模式存了但正常模式读不到"。
