## 九、peek 用法（本组通用）

```powershell
# 跑命令：输出整份落盘，只回命中行
node scripts\peek.mjs --run "node scripts\check-context-budget.mjs" --grep "警戒|换代" --head 8

# 看文件：不整读，只取切片
node scripts\peek.mjs --file records\工作日志.md --grep "^### " --head 3
```

规矩（与 C1/C2/C5 对齐）：

1. 预计输出 **> 40 行** 的命令，一律走 `peek`，不要直接 `Get-Content` / 整段 JSON；
2. 报告里写「全文 N 行 → 路径」，把路径当指针，别贴全文；
3. 压缩/二进制文件（`*.zstd`、`*.asar`）**不读**——要内容先解出来再 `peek`，否则既没信息又耗一步。
