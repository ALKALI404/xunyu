## 二、装它要四步（仓库 README 的口径）

```
① mod（游戏侧）：cd mod → dotnet build -c Release → .\deploy.ps1（或 ..\scripts\launch-game.ps1 -Deploy）
   装完 GET http://127.0.0.1:47821/health 应回 {"ok":true,"attached":true,"version":"0.3.1"}
② MCP 插件（plugin/）：link 到 DSH 能引的路径 → profile package.json 加依赖 →
   plugin_manager install_bundle <plugin 目录>（或把 plugin/cordis.patch.yml 并进 profile）
③ agent 预设（preset/sts2-player-preset）：plugin_manager install_bundle
④ skill：scripts\apply-skill-updates.ps1（拷到 ~/.dsh/skills/ 并幂等打补丁）
```

**关键坑（README 明说）**：
- **开新局只能用菜单语义协议**（`GET /request` → menu → main/mode/character/ascension）；**`POST /start` 会留幽灵局并封死菜单，只能重启游戏**；
- `mods\Sts2AgentBridge\` 里**只能有一份**同 id 的清单 json，多一份就加载失败；
- 工具 32 个（读局面/出牌/决策/路线/只读查询）；**改 cordis.patch.yml 后必须 remove_bundle → install_bundle**。

## 三、装它的前置动作（要主人点头）

1. **装 .NET SDK**（dotnet 8 桌面运行时不够，要 SDK 才能 `dotnet build`）——下载 PowerShell 脚本或 winget：`winget install Microsoft.DotNet.SDK.8`；

3. **确认 DSH 侧允许装 MCP 插件与预设**（会改 profile 的 `cordis.patch.yml`，**要备份**）。
