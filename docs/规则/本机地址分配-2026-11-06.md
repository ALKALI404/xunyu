## 三、命名规则（怎么加新的）

1. **鲟鱼自己的东西** → `127.1.x.y`：
   - `127.1.0.x` = 本体与工作组
   - `127.1.1.x` = 对外页面（工作台 / 学习区 / 看板 / 后续面板）
   - `127.1.2.x` 起 = 顺延，**同段用完再换第三段**；
2. **桥接类**（QQ 桥、邮件、外部通道）→ `127.2.1.x`，**`.1` 起顺延**；
3. **外包/独立项目**（保险、以后别的）→ `127.9.P.S`：
   - `P` = 项目号（`1` 保险、`2` 下一个项目…）
   - `S` = 子网页（`1` 主页面、`2` 子页…）
4. **不占 `.0`**：`127.1.1.0`、`127.9.1.0` 这类**不用**（留给将来做"段名"用途时不冲突）；
5. **同一项目所有服务用同一 IP、不同端口**——**IP 表示"哪个项目"，端口表示"项目里的哪个服务"**。

## 四、加新服务前要做的三件事

1. **查这张表**，挑一个没被占的地址；
2. **写进本表**（先登记，再启动）；
3. **启动后 `curl`/`Invoke-WebRequest` 验一次**，通了才继续。

## 五、迁移顺序（低风险优先）

```
① 保险 9343       127.0.0.1 → 127.9.1.1     （改 server.mjs 的 HOST）
② 学习区 9351     127.0.0.1 → 127.1.1.3
③ 工作台 9340     127.0.0.1 → 127.1.1.2
④ QQ 桥 3100      127.0.0.1 → 127.2.1.1
⑤ DSH 55900       127.0.0.1 → 127.1.0.1     （最后做，要改 bridge 配置 + 重启）
```

**每一步都可回滚**：代码里 `HOST` 常量改回 `127.0.0.1` 即可。

## 六、为什么要这么分

- **一眼看出是谁的**：看到 `127.9.*` 就知道是外包项目，`127.1.*` 是自己人；
- **崩一个不连累别的**：IP + 端口都不同，不会互相抢；
- **以后加项目不用翻代码**：照表登记，规则在那儿。
