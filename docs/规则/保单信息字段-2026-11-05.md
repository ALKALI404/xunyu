## 一、`policies.jsonl` 新增 4 组字段

```json
{
  "payCard": {
    "bank": "招商银行",
    "acctMasked": "6214****7712",
    "holder": "陈凤",
    "note": "首期从这张卡扣；续期是否换卡待确认"
  },
  "contact": {
    "phone": "189****4699",
    "address": "重庆市渝中区…（省市区+门牌）",
    "email": null,
    "emailValid": null,          // true / false / null（未知）
    "phoneValid": null,
    "addressValid": null,
    "lastCheckedAt": null        // 上次核实时间（"是否失效"必须有时间戳）
  },
  "cashValue": {
    "amount": 296900,
    "currency": "CNY",
    "asOf": "2026-04-09",        // 对应保单年度末
    "policyYear": 10,
    "source": "保单价值表（第10年）",
    "guaranteed": true
  },
  "cashValueHistory": [
    { "policyYear": 1, "amount": 50000 },
    { "policyYear": 5, "amount": 279800 }
  ]
}
```

**规则**：
| 字段 | 硬要求 |
|---|---|
| `payCard` | **账号必须脱敏**（只留前4后4）；银行名要写全 |
| `contact.address` | 写"省市区+门牌"，**不许只写城市** |
| `contact.email/phoneValid` | **三态**：`true`（已核实有效）/ `false`（已失效）/ `null`（未核实）；**核实就要写 `lastCheckedAt`** |
| `cashValue` | 必须带 **`asOf` + `policyYear` + `source`**；**非保证部分不许混进 `guaranteed:true`** |
| `cashValueHistory` | 保单价值表里的历年值，**能填多少填多少**（后面画曲线用） |

## 四、重复保单号检查（2026-11-05 主人补）

**判定键 = 保险公司 + 保单号**（不同公司的号格式不同，不能只比号码）。

| 时机 | 行为 |
|---|---|
| **建草稿时** | 先查一遍：发现已存在 → **立刻提示**「这张单已经录过（单-0001，投保人陈凤）」，**草稿仍可建**（可能就是要补字段） |
| **确认入档时** | **硬拦**：同号已存在 → 409，提示已有那张单，给两个选项：**「去补那张」/「确认是另一张（force）」**；force 必须写审计 |
| **补录/批量导入** | 同号 → 跳过并记日志，**不许静默覆盖** |
| **同一保单的批单/续期** | **不算重复**：挂到同一 Policy 下做 Document，kind 写 endorsement/notice |

**比对前先规范化**：去空格、字母转大写、去掉公司前缀（若用户手填了）。

## 五、现金价值：动态索引（2026-11-05 主人定）

**主人原话**：「现金价值设计成动态索引，当前年份+对应价值的形式。」

### 5.1 怎么算当前保单年度

```
起算日 = policy.effectiveAt（生效日）
今年周年日 = 生效日的月日 + 今年
若 今天 >= 今年周年日 → 保单年度 = 今年 - 生效年 + 1
否则              → 保单年度 = 今年 - 生效年
```

**例**：生效 2016-04-09，今天 2026-11-05 → 已过 2026-04-09 → **第 11 年**（`2026-2016+1`）。

### 5.2 显示什么（三档，别只给一个数）

| 项 | 例 |
|---|---|
| **当前年度价值** | 第 10 年（2025-04-09 起）**296,900 元** |
| **上一档** | 第 9 年 293,900 元 |
| **下一档** | 第 11 年（表里没有 → 写「表未列」） |

**必须带口径**：`截至 2026-04-09（第10保单年度末）`，**不许只写"现值 296,900"**。

### 5.3 数据怎么存

- 只存 `cashValueHistory`（年度 → 金额，来自保单价值表）+ `effectiveAt`；
- **`cashValue` 不手填**，由服务端按上面公式**算出来**（避免过一年就过期）；
- 若表里没有该年度 → 显示「表未列」，**不许插值、不许外推**。
### 5.4 超出表末年度怎么算（2026-11-05 23:55 主人定）

**主人原话**：「现金价值在到达表单最大年限后按照最后一年计算。」

取值优先级（**逐条**）：

| 情形 | 取哪个值 | 标签（必须显示） |
|---|---|---|
| 表里有这一年 | `history[year]` | `第{year}年` |
| **year > 表末年** | **`history[表末年]`** | **`按表末第{表末年}年计（已超出表列年度）`** |
| year 在表内但该年缺（照片没拍到） | `history[最近的下一年档]` | `按第{该年}年值（表内缺第{year}年）` |
| 表里根本没有可用值 | `null` | `暂无相关信息` |

**例（太平单，表末第 21 年 311,300）**：
- 今天算到第 11 年，表里缺第 11–14 年 → 用第 10 年 296,900，标「按第10年值（表内缺第11年）」；
- 若算到第 25 年（>21）→ 用第 21 年 311,300，标「按表末第21年计（已超出表列年度）」。
### 5.5 卡片上必须有「当前年份现金价值」（2026-11-05 00:00 主人定）

**每张保单卡片固定显示一行**：

```
当前现金价值：296,900 元（第10年，按表内第10年值 —— 表内缺第11年）
```

- 字段名统一 `currentCashValue: { amount, currency, policyYear, asOf, label, clamped, listed }`；
- **必须带三个信息**：金额、第几年、这句 label（表未列/表末沿用/正常年份）；
- **没有可用值** → `amount:null`，显示「暂无相关信息」；
- 服务端每次请求实时算（**不许前端硬编码、不许缓存跨天**）。
