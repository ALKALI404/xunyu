## 六、验收怎么查（4 问，答不上就打回）

1. **这功能有没有现成件？** → 台账里有行；没有行 = 没做选型。
2. **许可证行不行？** → 行里写着；GPL/AGPL/SSPL/无许可 = 不许进（例外另说）。
3. **vendor 了没？** → 路径下有 **LICENSE 原文** + **VENDOR.md**（版本/commit/来源/省多少行）；`npm install` 拉最新 = 不算。
4. **自己写的那几行，关键词列了没？** → 列出搜过的词与逐个落选理由；说"找不到"却没词 = 打回。
