# 规矩：本体不下场（2026-11-05 主人定）

> 一句话：**本体只对接 01、只汇报进度；写代码、改项目文件、验收，都不是本体的活。**

## 一、什么算“下场”

| 算 | 不算 |
|---|---|
| 直接写项目里的代码/页面/数据文件 | 写任务书、写派单消息 |
| 直接跑项目脚本去产出结果 | 跑体检脚本看系统状态 |
| 自己给自己的产物盖“通过” | 让 01 验、自己只转述 |
| 用“最小验证/救火”当理由顺手做完 | **先报备、拿到批号再做**（见三） |

## 二、判定口径（程序按这个查）

**项目目录里的文件被改动，且同一时段没有“活儿在跑”（没有票处于 doing/submitted），就算一次下场。**

- “项目目录”：`E:\DSH-WeChat\PengYan_Assistant` 下的 `窗口\`、`脚本\`、`档案\`、`索引\`
- “活儿在跑”：`state\worklist.jsonl` 里该项目任一票，在改动时间 ±30 分钟内出现过 `state→doing` / `submitted` / `done` / `accepted`
- 例外：`--intent` 登记过（见三），且在有效期内

## 三、例外：救火要先报备

```bash
node scripts\self-work-guard.mjs --intent "修 9343 端口起不来" --minutes 30
```
登记后 30 分钟内对该目录的改动不算违规；**每次只能登记一件、必须写清做什么**。
**登记不等于免责**：事后要在 `state\current-task.md` 写一行“为什么下场”，由 01 复核。

## 四、谁来管

| 谁 | 职责 |
|---|---|
| **01** | 所有验收归它；发现违规先记账，再报本体 |
| **本体** | 只对接 01、只汇报；不写代码、不验收 |
| **程序** | `self-work-guard.mjs` 每 5 分钟扫一次，违规写 `state\self-work-violations.jsonl`；`health-3sat` 的 `P13_本体未下场` 会因此变红 |

## 五、为什么写这么死

**主人原话**：「你又在自己干活」。
**问题不在于我干得好不好，而在于**：我自己能做完，工作组就没活干；工作组没活干，就永远练不出来；最后系统里只剩一条鱼，和一堆没人用的工号。

## 六、定稿补充（2026-11-05 晚，第二版）

### 6.1 按改动量分三级（主人已确认）

| 级别 | 判定 | 处置 |
|---|---|---|
| **不算** | 只读、看一眼、跑体检 | 不记 |
| **轻** | 改 1 个文件且 ≤5 行 | **记一行留痕**，不报 |
| **重** | 改 ≥2 个文件，或单文件 ≥50 行 | **立刻报主人** |

### 6.2 历史违规（16 条）处置

**写进错题本，不补票。** 理由：**票是给"要做的活"用的，那些活已经做完了；但不记下来等于没发生。**

### 6.3 救火报备

- 报备开启后**一直有效**，直到 `--done` 结束（**改为"修完即失效"**，不再按 30 分钟硬切）；
- **每 10 分钟在日志里写一行"还在报备中"**；
- 提醒**只写日志 + 体检页显示**，不发 QQ（报备是痕迹，不是通知）。

### 6.4 谁判

**程序初判 + 01 复核（必做一步）**，复核结论写进 `records\验收\insurance\` 的验收记录。

### 6.5 也管工号

**同一条规矩管工号**：没票改文件也记一次，**只记不拦**（工号偶发顺手修属正常）。
**月底 01 出一次汇总表**：工号 / 次数 / 涉及文件 / 是否有票。不单独建系统，靠现有记录聚合。

### 6.6 程序改造

`self-work-guard` 目前只判"有无票"，**没有"改了几行"**——需加**改动量统计**（按 diff 行数/文件数分级），**排在 BR-001 之后做**。

## 七、验收口径（2026-11-05 21:30 主人原话修正）

**主人原话**：「01 验收本来就只用看证据，验证是工作中工号自己的事情，每次验收一张票是规矩。」

| 谁 | 干什么 |
|---|---|
| **工号** | 干活时**自己跑判据、自己贴证据**（命令 + 关键输出）。**没证据 = 没干完。** |
| **01** | **只看证据**：证据是否成立、是否对得上判据；对不上就打回。**不替工号复跑。** |
| **一次一票** | 验收**一次只收一张**，不许"三张依次收口"。 |
| **交付文档** | 只贴**命令 + 关键输出摘录**，**不许全文粘贴**（上下文会被撑爆）。 |

**为什么**：复跑会让 01 每张票都等命令；一次多票会把上下文顶到 200k+；两者叠加，验收从"几分钟"变成"十几分钟"。
