## 一、配对与归户（Q1/Q2）

| 情形 | 规则 |
|---|---|
| **A 有配偶 B** | A **归入 B 的家庭**（不单独建「A家」）——**彭艳 → 许驰家**，不建「彭艳家」 |
| **两家原本各有卡**（都无配偶） | **合并成一张**；**户主优先男方**；性别未知/同性 → 保单多的一方 → 建档早的一方，标「户主按规则推定，可手动改」 |
| **合并时成员怎么并** | **子女并入新家庭卡**；**父母不计入子女家庭卡**（父母留在自己的卡里，不受影响） |
| **子女信息** | **在双方家庭都显示**；家庭卡只装「与本家一致的投保人/被保人关系」；**各自关于子女的保单，分别在各自家庭里只算各自的** |

## 二、保单归属（Q3）

- **保单挂在个人名下**（`policies.holders/insured` 记人，不记家庭）；
- **未失效保单跟保险人走**（谁是被保险人，保单就在谁名下、在谁的家庭视图里统计）；
- **被保险人身故**：**默认按法定继承人处理，跟法律走**，**不默认归前妻/前夫**；
- 家庭视图只是**聚合**，不是所有权。

## 三、解除关系（Q5/Q6）

**解除关系 → 子菜单三项**：

| 选项 | 后果 |
|---|---|
| **离婚** | **解耦**：撤销 spouse 双向关系；两人**各自单独建家庭卡**；子女跟随其 `primaryHouseholdId`，不确定就标「抚养归属待确认」 |
| **亡故** | **不解耦**（配偶关系保留为历史）；个人信息改 `status:"deceased"`；**家庭卡不删除**；**备注写「原户主已亡故」**；**户主自动迁移为配偶** |
| **录入错误（撤销）** | 记错了人/关系 → **撤销这次录入**（带审计，软删标记，不物理删） |

**为什么要有第三项**：不给撤销，人就会用"离婚"去凑，把数据搞脏。

## 四、现有家庭卡要重算（迁移）

新算法生效后，**现有家庭卡按新规则重新整理**：
1. 以「配偶 + 子女」重算每人的 `primaryHouseholdId`；
2. 两家并一家的，**保留较早那张卡的 id**，另一张标 `mergedInto`（不删）；
3. **保单按人重新归集**（不搬保单，只搬"统计口径"）；
4. 全流程**写审计**，可回滚（`state\household-migration-<日期>.json` 存迁移前快照）。

## 五、抽屉（L1 升级，优先）

**主人原话**：「需要做专门的抽屉按照首字母排序装个人信息卡片，个人信息卡片和相关保单信息是保单整理的基础单元，其次才是按照家庭进行整理。」

- **抽屉 = 全部个人卡片的总入口**，**按姓名首字母分组**（A/B/C…、中文按拼音首字母）；
- 点一个人 → **他的信息卡 + 他名下保单**（这才是"基础单元"）；
- **家庭视图是第二层**（有了人和保单，才有家庭聚合）；
- **抽屉要能搜**（`lqh` / `许驰` 都能到）；
- 排序：**首字母 → 同字母按姓名全拼 → 再按建档时间**。

## 八、顶栏与分页（2026-11-06 17:20 主人定）

**主人原话**：「个人和家庭卡片分页面放，可切换页面抽屉更换家庭还是客户的卡片展示页面，以及切换和搜索选项做成顶栏。」

### 8.1 页面分两个

| 页面 | 内容 | 地址 |
|---|---|---|
| **个人（抽屉）** | 全部个人卡，按拼音首字母分组 | ?view=people |
| **家庭** | 全部家庭卡（户主/配偶/子女/保单数） | ?view=households |

**默认进「个人」**（个人卡+保单是基础单元）。

### 8.2 顶栏（固定在最上面）

```
┌──────────────────────────────────────────────┐
│ [个人] [家庭]        🔍 搜索姓名/拼音/保单号   │
└──────────────────────────────────────────────┘
```
- **左侧**：两个切换标签（当前页高亮）；
- **右侧**：搜索框（两页共用，**切页保留关键词**）；
- **不做返回按钮**（切页靠顶栏，不靠浏览器后退）；
- 点个人卡 → 个人详情页（?person=<id>），**顶栏仍在**，多一个「← 回列表」。

### 8.3 搜索在顶栏的行为

| 当前页 | 搜什么 |
|---|---|
| 个人 | 姓名 / 拼音 / 首字母 |
| 家庭 | 家名（如「陈凤家」）/ 成员姓名 |

**切页时关键词保留**：个人页搜「许」，切到家庭页应直接看到「许驰家」。
