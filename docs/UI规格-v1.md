# UI 规格 v1（2026-10-28 本体拍板，长期有效）

> 主人定调：**暖白 + 浅灰 + 蓝**。以后工作台、窗口、任何新 UI 都按这份走；要改先改这份，不许各处各调。

## 1. 色板（浅色主题为主）

| 用途 | 值 | 说明 |
|---|---|---|
| 页面底色 | `#FAF7F2` | 暖白，不是纯白（纯白刺眼） |
| 卡片/面板 | `#FFFFFF` | 内容承载面 |
| 次级面/表头 | `#F3EFE8` | 暖浅灰 |
| 分割线/边框 | `#E4DED4` | 低对比，不抢视线 |
| 主色（蓝） | `#2F6BFF` | 主按钮、选中、链接、进度 |
| 主色悬停 | `#1F55DB` | — |
| 主色浅底 | `#EAF0FF` | 选中行背景、标签底 |
| 主文字 | `#1F2328` | 不用纯黑 |
| 次文字 | `#5C6470` | 说明、时间戳 |
| 弱文字 | `#8A929C` | 占位、禁用 |
| 成功 | `#15803D` | 通过、完成 |
| 警告 | `#B45309` | 卡住、待处理 |
| 危险 | `#B91C1C` | 驳回、失败、删除 |

**状态映射（固定，不许自创）**：
`queued` 灰边 `#E4DED4` ｜ `doing` 蓝 `#2F6BFF` ｜ `submitted` 琥珀 `#B45309` ｜ `planned` 紫 `#6D28D9` ｜ `done` 绿 `#15803D` ｜ `rejected` 红 `#B91C1C` ｜ `blocked` 虚线灰。

## 2. 间距与圆角

- 间距阶梯：**4 / 8 / 12 / 16 / 24 / 32**（只用这几个，不许 5、10、15 这种）
- 圆角：卡片/面板 **10px**，按钮/输入 **6px**，标签/徽标 **999px**（胶囊）
- 边框：1px `#E4DED4`；选中态用 2px 主色外描边，不用阴影堆叠

## 3. 字体

- 字族：系统栈 `"Segoe UI", "Microsoft YaHei", system-ui, sans-serif`（不引外网字体）
- 字号：**12**（辅助）/ **13**（正文默认）/ **14**（强调）/ **16**（小标题）/ **20**（区块标题）
- 行高 1.5；中文不加字间距；数字用 `font-variant-numeric: tabular-nums`（金额/时间对齐）

## 4. 布局与层级

- 三栏：左列表 **260–300px**（可拖）｜中内容自适应｜右信息栏 **280–320px**（可收起）
- 层级只靠**底面色差 + 1px 边线**，不用大面积阴影；唯一允许的阴影给浮层/命令面板
- 暗色主题**暂不做**（以后要做，令牌另起一份，不许混改）

## 5. 会话列表与折叠（主人 2026-10-28 定）

- **默认只展开两个**：`鲟鱼`（本体/QQ）与 `DSH`（DSH 会话）；
- 其余分组**默认折叠**：`工作组（00–06）`、`QQ 通道（群/企微）`、`其他`；
- 折叠态显示：组名 + `在干 N / 空闲 M` + 最该看的一条（卡住优先）；
- 展开状态**记住**（localStorage 或配置文件），刷新不回弹。

## 6. 工具箱预留位（主人 2026-10-28 定）

窗口**右侧栏底部**预留一块 **`工具箱`**：

- 折叠态：一行 `🧰 工具箱`（文字 + 计数徽标），点开展开；
- 展开态：**网格按钮区**（3×N），每个按钮 = 一个工具入口，先放两个占位：`待接入`、`待接入`；
- 预留接口：`toolbox.register({id, label, icon, onClick})`，后续插件按这个注册，**不许各自往页面上乱塞按钮**；
- 现在只做**空壳 + 占位**，不做实际工具。

## 7. 一句话验收

看到界面第一眼：**底色是暖的、边框是软的、蓝色只在"要点这里"时出现**。做不到就是没按规格。

## v1.1 补充（2026-10-28 19:10 本体裁定，解决 W1 与规格的色值冲突）

主人原话是「暖白 + 浅灰 + 蓝」，没有指定色号。因此**两个蓝都保留，但分工固定**：

| 令牌 | 值 | 用在哪 | 不许用在哪 |
|---|---|---|---|
| `--blue`（主蓝） | `#2F6BFF` | 主按钮、链接、选中态外描边、进度条填充、可点击文字 | 大面积铺底 |
| `--blue-soft`（浅蓝） | `#7FA7F0` | 大面积高亮块、消息气泡自身底色、选中行背景、图表填充 | 按钮底、文字、描边 |

- **边框统一 `#E4DED4`**（W1 的 `#e6e0d5` 并入此令牌，不再单独存在）；
- 次级面 `#F3EFE8`；"浅灰"就是这个，不再新增灰阶；
- **所有页面只许引用令牌名，不许写死 hex**；发现写死 hex 的提交，验收直接拒。

这样：U1 自创的五个色（`#5aa9e6/#7ee0c0/#3ecf8e/#e3b341/#f06a6a`）全部作废——状态色仍按 §1 的映射（成功 `#15803D`、警告 `#B45309`、危险 `#B91C1C`）；W1 的 `#7fa7f0` 保留为 `--blue-soft`。

## v1.2 补充（2026-10-28 19:45 主人定）：工作区模块取代「工具箱」

窗口顶层只有**三个模块**：`聊天` / `工作台` / **`工作区`**。原来的「工具箱」并入工作区，不再单独存在。

**工作区结构（两层 + 返回）**：

1. **母菜单（分类页）**：工具按分类平铺成卡片（建议分类：`监控` / `数据` / `开发` / `运维` / `其他`），每张卡显示 `分类名 + 工具数`；
2. **子菜单（工具列表）**：点分类进入，列出该分类下的工具：`图标 + 名称 + 一句话说明 + 启动按钮`；
3. **返回母菜单**：子菜单顶部固定一个 **`← 返回`** 按钮 + 面包屑（`工作区 / 监控`）；按 `Esc` 也返回；
4. **启动方式**（后续本地可视化工具都从这里起）：
   - `本地 exe / 脚本`：由宿主壳启动（如 `node xxx.mjs`、`xxx.exe`），**启动前二次确认**；
   - `本地页面`：内嵌 iframe 指向 `http://127.0.0.1:<port>/`（例如工作台 9340、未来的可视化端口）；
   - 不允许从工作区直接跑任意命令行——**只认注册表里的白名单入口**。
5. **注册接口**（供后续工具接入，禁止各自改页面）：
   ```js
   workspace.register({
     category: '数据',            // 分类
     id: 'token-dashboard',
     label: '花费看板',
     desc: '今日花费与命中率',
     launch: { kind: 'url', url: 'http://127.0.0.1:9340/' }  // 或 {kind:'exe', path:'...', args:[]}
   })
   ```
6. **现在的实现范围**：只做 **空壳 + 分类页 + 子菜单 + 返回 + 注册接口**，没有工具的分类显示「暂无工具」；**先注册 1 个真实入口**（`工作台` 分类下的「花费看板」指向 9340）用来验证链路。

## v1.4 补充（2026-10-29 19:35 本体裁定）：面板机制三条铁律 + 浏览器可独立运行

> 起因：主人问"未来需求增加怎么办"，并明确"页面简洁、愿意打开才是真的"。

### 1. 能力不设上限，布局默认极简（两件不同的事）
- **注册表不设上限**：新增功能 = 注册一个面板类型（一个函数）+ 场景 json 里加一行，**不改壳、不改 HTML 结构**；
- **默认布局必须少**：一屏**同时可见面板 ≤ 3**；超出的收进顶栏 tab / "更多"，默认折叠；
- **判据**：新加功能时，先问"能不能塞进已有面板"，塞不进去再新增类型；**类型数量增长要慢于功能数量**。

### 2. 网页模式是主形态，壳只是外壳
- 页面必须能在**浏览器直接打开**（`http://127.0.0.1:<端口>/`）完整使用；
- **不许依赖壳专有 API**（`window.chrome.webview` 之类）做核心功能；壳只提供"窗口/图标/常驻"这些外壳能力；
- 判据：把壳关掉、只用 Edge 打开，功能不减。

### 3. 面板只通过 HTTP 取数（为"上云"留路）
- 面板**不许直接读本地文件/进程**，一律调后端 HTTP 接口；
- 后端地址可配（`web\config.json` 的 `apiBase`），默认 `http://127.0.0.1:<端口>`；
- 目的：**将来某个功能挂到云服务器，只改 `apiBase` 指向，不用重写面板**；
- 判据：把 `apiBase` 指向一台远端服务，面板仍能工作（可用 mock 验证）。

### 4. 验收口径（补进第 7 节）
- **"打开的欲望"是验收标准**：首页必须一眼看到"现在要处理什么"，不是"能看的东西最多"；
- 面板多于 3 个且无折叠 ⇒ **打回**；
- 关掉壳用浏览器打开功能缺 ⇒ **打回**；
- 面板里有本地路径硬编码 ⇒ **打回**。
