## 接口契约

- 在 `?person=<id>` 打开某人页时，点「← 回到首页」，**必须回到家庭列表**。
- 两种入口都正常：
  1. `http://127.0.0.1:9343/?person=人-0001` → 点返回 → 显示列表
  2. `http://127.0.0.1:9343/#/人/人-0001` → 点返回 → 显示列表
- 不许拿“整页刷新”当唯一修复（可以刷新，但必须真的回列表）。

## 0.5 预期结果

点「回到首页」就真回到首页，不用手动删地址栏的 `?person=`。

## 1. 根因（已定位，供你验证）

`窗口\index.html` 路由同时看 hash 与 query：

```js
const m = location.hash.match(/^#\/人\/(.+)$/);
const q = new URLSearchParams(location.search).get('person');
const id = m ? decodeURIComponent(m[1]) : (q ? decodeURIComponent(q) : null);
```

返回链接是 `href="#/"` —— **hash 变了，但 `?person=` 还在地址栏**，`q` 仍有值 → 继续渲染那个人，**看起来“没反应”**。

## 2. 做什么（选一种）

- **改法 A（推荐）**：返回时把 query 一起清掉
  ```js
  history.replaceState(null, '', location.pathname);
  location.hash = '';
  route();
  ```
- **改法 B**：路由里 hash 优先——hash 为 `#/` 或空时忽略 `?person=`。

## 3. 可验方式

- ① 打开 `?person=人-0001` → 点返回 → **截图**（应见陈凤家庭卡片）；
- ② 贴改动 diff（≤10 行）；
- ③ 打开 `#/人/人-0001` → 点返回 → 同样贴结果。
