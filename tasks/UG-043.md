## 0.5 预期结果
1. **每次聊天（收到消息时）自动把会话标题改成**：私聊 `鲟鱼QQ（<昵称> <QQ号>）`、群聊 `群聊·<群名>（<群号>）`；
2. 对方**改昵称/改群名**时，下一次聊天自动跟着变（不重复改、不抖动）；
3. **同一个 QQ 会话永远复用同一个 DSH 会话 id**（除非主人手动 `/new`），不再每次重启新建。

## 接口契约
- `pickSessionTitle({kind:'private'|'group', peerId, peerName, groupName}) -> string`
  - 私聊：`鲟鱼QQ（${peerName} ${peerId}）`；群聊：`群聊·${groupName}（${peerId}）`
  - 名字取不到时退化为 `鲟鱼QQ（${peerId}）` / `群聊（${peerId}）`
- `ensureTitle(sessionId, title) -> {changed:boolean, title}`
  - **只有与当前标题不同才调 `sessions.rename`**（避免每轮都发 RPC）；
  - 改名成功后写 `state\session-titles.jsonl`（`{ts, sessionId, from, to, reason}`）。
- `resolveSession(key) -> sessionId`
  - `sessions.json` 里已有且**未归档** → 直接复用；不存在/已归档 → 新建并落盘；**不许每次新建**。

## 2. 做什么
1. 在 `src\bridge.js` 的消息入口（收到消息、唤醒前）调 `ensureTitle`；
2. 会话解析改成 `resolveSession`，加**单实例锁**避免并发建两个；
3. 群名/昵称来源：OneBot 事件里的 `sender.card || sender.nickname`、`group_name`（取不到再用缓存）；
4. 提供 `node scripts\fix-session-titles.mjs --once`：**把现有乱名批量修正**（含重复会话，保留最新、其余标 `dup-of` 注释）。

## 3. 验收与判据
- ① 私聊发一句 → 会话标题变成 `鲟鱼QQ（<昵称> <号>）`（贴 API 查到的 title + 日志行）；
- ② 对方改昵称后再发一句 → 标题跟着变（贴两条 title）；
- ③ **重启桥**后同一会话**仍是同一个 sessionId**（贴前后 id）；
- ④ 重复执行不产生多余 rename（贴 `session-titles.jsonl` 只有 1 行/次）。

## 4. 边界
- 只改桥的会话命名/解析逻辑 + 新增修名脚本；**不改 preset、不改消息路由**。
