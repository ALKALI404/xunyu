## 1. 做什么

**A. 四级排序（先实现这个，立刻可用）**
```
① 主人指定（--owner-asked 建单）      → 最高，插队
② 有下游等着的（dependents>0）        → 其次
③ 同工号/同功能域有过驳回的            → 再次（系统性问题优先堵）
④ 其余                                → 进池先后 FIFO
```
- 新增 `worklist.mjs next [--worker 04]`：按上述规则列出"下一该派谁"，每条输出命中规则（`P0` / `等它的是 W-xxx` / `返工优先` / `FIFO`）；
- 自动接力改用它来挑票（同级 FIFO）；
- `add` 增加 `--owner-asked` 标记位。

**B. 三条埋点（为将来分钟制准备）**
1. 建单校验：有下游的票必须写 `blockedBy`（已支持），并在 `list` 里显示 `→ 挡着 N 张`；
2. 工时：状态机在 `doing` 与 `submitted` 时各记一个时间戳（`startedAt` / `submittedAt`），`list --detail` 显示耗时；
3. 驳回原因：`reject --reason <枚举>`（`missing-type` / `weak-evidence` / `gate-too-strict` / `wrong-formula` / `doc-mismatch` / `other`），写进事件；`list --rework-stats` 输出各类型计数。
