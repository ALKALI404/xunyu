# 工单 D64 · 工作台常驻自启：纳入 supervisor + 登录即起（派 03）

> 派单 2026-10-28 21:00 本体｜主人：工作台能不能在我或工作组开始干活时自己起来

## 1. 目标

**打开电脑就能用，掉了自动拉起**，不需要任何人手动 `node workdesk-server.mjs`。

## 2. 做什么（两条一起，双保险）

1. **纳入 supervisor 监护**（与 relay/body/bridge 同级）：
   - 新增 `workdesk` 进程项，端口 **9340**，命令与现有启动方式一致（`node scripts\workdesk-server.mjs`，若 D60 已加 `--watch` 就用带 watch 的版本）；
   - 退出即拉起，连续失败退避（≤5 次，之后报丧到疼痛总线并保持告警，不无限重启）；
2. **登录自启**：把 supervisor（或单独的计划任务）设为**用户登录时启动**，保证重启电脑后无需手动开（沿用现有 wscript 无窗口方式，不要弹黑窗）；
3. **健康自证**：`GET 9340/health` 返回 `{ok, pid, startedAt, version}`（若已有就别重复造）；
4. **页脚/日志**：启动时在 `logs\workdesk.run.log` 打一行 `[boot] pid=… startedAt=… version=…`。

## 3. 什么算过

- `taskkill` 杀掉 9340 → **20 秒内**自动回来（贴新 pid 与日志行）；
- 注销再登录（或重跑 supervisor 启动脚本）→ 9340 自动在听（贴 `netstat`/`curl` 证据）；
- 连续杀 6 次 → 第 6 次不再狂重启，疼痛总线有记录、页面仍能起来一次（退避生效）；
- `curl 9340/health` 有 `pid/startedAt`。

## 4. 边界

- 只改 supervisor 相关脚本/计划任务 + 启动命令；
- **不改** workdesk 业务逻辑（归 06）、不动 relay/bridge。

## 5. 回滚

- supervisor 里注释掉 `workdesk` 项、计划任务恢复到改前状态；版本化备份 `supervisor.ps1.bak-<日期>`。
