## 接口契约

**① 无题小节：显示「本节暂无题」+ 允许「标记已读」**

```
POST /quiz/section/read   { bookId, chapter, section }
  → { ok, readAt }
GET  /quiz/outline?...    → 每个 section 增加：
     { questions:0, noQuestion:true, read:true|false, status:"learning|done" }
```

**规则**：
- `noQuestion:true` 且 `read:true` → **status 视为 `done`**（可解锁下一节）；
- `noQuestion:true` 且 `read:false` → 仍 `learning`，**但页面必须显示按钮「标记已读」**；
- **有题的小节不许用"标记已读"跳过**（必须答题）。

**② 已读记录落盘**
`学科\<学科>\课本\<书>\章节\<章>\分析\已读.jsonl`（一行一节：`{section, at}`）。
