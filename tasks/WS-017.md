## 一、要什么

**工作台里加一个「调度台」页签**，一屏看清：
```
┌ 服务红绿灯 ─────────────────────────────┐
│ ● 工作台 9340    ● 学习区 9350          │
│ ● 引擎  9351    ● 桥 3100   ● relay 9334│
│ ○ 临时考场 9352（未启动）  [全部重启]    │
└─────────────────────────────────────────┘
┌ 票与工人 ───────────────────────────────┐
│ 04 代码    doing ST-121   压力 62k      │
│ 05 文档    idle           压力 61k      │
│ 待验收 4 张 · 排队 26 张                 │
└─────────────────────────────────────────┘
┌ 最近事件（20 条）────────────────────────┐
│ 15:03  9351 挂了 → 已拉起（2.1s）        │
│ 14:40  墙钟超限，停止重启（1 小时内 5 次）│
└─────────────────────────────────────────┘
```

## 接口契约

```
GET  /api/supervisor              服务状态（红绿灯）
GET  /api/supervisor/events?limit=20  最近事件
POST /api/supervisor/restart {id}     单个重启
GET  /api/worklist                票队列（已有）
GET  /api/agents                  工人状态（已有）
```

**交互要求**：
1. **红绿灯**：绿=在跑、红=挂了、灰=未启用；**鼠标悬停看端口与最近一次动作**；
2. **点灯 → 弹「重启 / 看日志」两个按钮**（重启要二次确认）；
3. **事件流自动刷新**（15 秒），**不许整页闪**（局部替换）；
4. **没数据写「暂无」**，**不许空框**。

## 0.5 预期结果

打开工作台「调度台」：**一屏看到谁活着、谁挂了、票堆在哪、最近发生了什么**；点红掉的灯能重启。
