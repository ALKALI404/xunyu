## 接口契约

- `node scripts\rotate.mjs --worker <工号> [--dry-run] [--resume]`：十步 checklist，退出码 0=全绿 / 1=某步失败（打印步号）/ 2=锁占用。
- 锁文件 `state\rotate.lock`（含 pid + 起始时间）；`--resume` 从 `state\rotate-state.json` 继续。

## 1. 做什么（十步 checklist，每步 = 执行 + 校验）

| # | 步骤 | 自动校验（不过就停） |
|---|---|---|
| 1 | 触发判定 | 上下文 ≥ 阈值；**且目标没有 doing 票在跑**（有则等或报"在制品"） |
| 2 | 写交接稿 | 六字段齐 + 含"已完成/未完成/关键路径/坑"四块；文件存在且 >500B |
| 3 | 建新会话 | 只传 workspaceId；返回 sessionId |
| 4 | 改名 | 标题与名册 namingPattern 一致 |
| 5 | 投接班包 | 投递返回 accepted；10 分钟内收到复述 |
| 6 | 校验复述 | **必须引用交付稿文件名**（正则匹配 `records\\交付\\`） |
| 7 | 名册三处同步 | `check-roster-consistency` 输出 0 处不一致 |
| 8 | 截图证据 | 文件存在且 >50KB |
| 9 | 归档旧会话 | 先 `scan-stale-bindings` exit=0；归档后集合计数 +1 |
| 10 | 报告 | 输出新 id / 旧 id / 归档数 / 耗时 |

**硬约束**：
- **单实例锁**（`state\rotate.lock`）——今天撞车的根因就是并发；
- **每步幂等**：重复执行同一步不产生重复会话/重复归档；
- **失败不回滚已完成步骤**，但**必须写清"下一步从哪继续"**（可 `--resume`）。
