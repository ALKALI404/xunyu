## 接口契约

**① 自检（8 项，一次跑完，带耗时）**
```
GET /api/console/selftest → { ok, checks:[{name, ok, detail, ms}] }
```
| # | 检查 | 判据 |
|---|---|---|
| 1 | 六个服务端口可连 | 端口能连上（不是只看进程） |
| 2 | 桥 agent 接口可用 | **判 `ok` 字段，不判 HTTP 状态码** |
| 3 | relay 绑定 | `/health` 的 `bindings.ok === true` |
| 4 | 引擎复核 | `/health` 的 `recheck.ok === true` |
| 5 | 模型 Key | 存在即通过（**只回掩码**） |
| 6 | 索引 jsonl 合法 | 逐行 `JSON.parse` 全通过（**吸取今晚教训**） |
| 7 | 磁盘空间 | 剩余 > 5 GB |
| 8 | QQ 文件通道 | 收件箱可写 + outbox 可读 |

**② 日志尾巴（三源，支持过滤）**
```
GET /api/logs/tail?src=kernel|bridge|services&lines=500&onlyError=1&q=<关键字>
  → { ok, lines:[{at, level, text}], truncated }
```
- `kernel` = DSH 侧（`logs\*.log` 里最近写的那个）
- `bridge` = `qq-bridge\state\logs\errors.jsonl` + 桥 stdout
- `services` = supervisor 的 `logs\supervisor.jsonl` + 各服务 out/err
**要求**：**尾部读，不整文件加载**；单行 ≤ 500 字符截断；**按时间升序返回**。

**③ 设置（读掩码、写增量）**
```
GET  /api/settings
  → { model:{provider,baseUrl,name,keyMasked}, sampling:{temperature,maxTokens,freqPenalty,presPenalty,timeoutMs,deepThink},
      bridge:{url,tokenMasked}, persona:{path,mtime,chars} }

POST /api/settings { model?, sampling?, bridge? }
  → { ok, applied:[...] }
```
**红线**：**`key`/`token` 传空字符串 = 不改**；返回**永远只有掩码**（`sk-…abcd`）；**日志里也不许出现明文**。

**④ SnowLuma 编排（启动 + 登录态 + 重连）**
```
GET  /api/snowluma/status   → { ok, running, loggedIn, qrWindowVisible, lastCheckAt }
POST /api/snowluma/start    → 启动（含把登录窗调到前台）
POST /api/snowluma/reconnect→ 断线重连
```
- **令牌从本机配置文件读**（`state\snowluma-token`，**不进代码、不进票、不回显**）；
- **登录是扫码**：接口只报「窗口是否可见 / 是否已登录」，**不模拟扫码**；
- 登录成功 → **自动把 QQ 桥拉起来**（`/api/bridge/start`）。

## 6. 追加（主人 2026-11-07 14:20）：桥接控制台接口

```
GET  /api/bridge/status     → { ok, up, lastHeartbeatAgoMs, sessionBound, queueDepth, errorCount,
                                window:{visible}, lastError:{at,text} }
GET  /api/bridge/logs?src=all|errors&after=<seq>&lines=200
                            → { ok, lines:[{seq, at, level, text}], nextSeq }
POST /api/bridge/toggle     { key:"sendDelayMs"|"ackMessage"|"questionTimeoutMs"|"allow"|"deny", value }
                            → { ok, applied, restartNeeded:boolean }
POST /api/bridge/restart    → **必须委托给 supervisor**（WS-016 的 `/api/supervisor/restart {id:"qqbridge"}`）
POST /api/bridge/refresh-token → 重读桥的新 agentToken/consoleToken（返回 ok，不返回令牌）
```

**红线**：
1. **只允许改白名单字段**（上面五个）；**其他配置字段一律 403**；
2. **`POST /api/bridge/restart` 不许自己 kill 进程**——**必须走 supervisor**（否则守护会以为它自己挂的，触发重复重启）；
3. `logs` 用 **`after` 序号增量**（别每次全量）；
4. **令牌刷新只回 ok**，不返回任何令牌内容。

**验收追加**：
- ⑦ `GET /api/bridge/status` 三态（起/停/断线）各贴一次；
- ⑧ `POST /api/bridge/toggle` 改白名单字段成功、改 `consoleToken` 返回 403（贴两条）；
- ⑨ `POST /api/bridge/restart` → **supervisor 日志里出现该动作**（贴行）；
- ⑩ `logs?after=` 连续两次，第二次只回增量（贴行数）。
