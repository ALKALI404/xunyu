## 接口契约

```
POST /feynman/start  {bookId, questionId}  → {discussionId, bubbles[], knowledgePoints[]}
POST /feynman/say    {discussionId, text}  → {bubbles[], round, done:boolean}
POST /feynman/end    {discussionId}        → {verdict, missing[], archivePath, summary}
GET  /feynman/history?bookId=              → {items:[{id,title,date,verdict,path}]}
GET  /feynman/get?discussionId=            → {bubbles, meta}
```

**会话编排（核心）**：
1. `start` 时**新建一个专员会话**（学习区工作区 `118f6eae-…` 里），**指令它先读这道题的 keyPoints + 原文段落**，读完**复述一遍知识点**（证明读到了）；
2. 同一会话里**双角色**：`🐣 小白`（只问、只复述、不给答案）+ `⚖️ 考官`（不打断，只在侧栏记批注，结束出判定）；
3. **轮次上限 8**，到顶直接进判定；
4. **每轮落盘**（中途崩了能接着聊，`GET /feynman/get` 恢复）。

**判定（三条）**：①术语配人话 ②追问两轮不倒 ③小白复述不走样 → 全中 `pass`、中二 `half`、≤1 `fail`。

**归档**：

## 6. 追加（主人 2026-11-07 00:15）：小白/考官/定义地图 都归学习区管理员调度

**角色固定为三个，别再各起各的**：

| 角色 | 谁 | 干什么 | 不干什么 |
|---|---|---|---|
| **管理员 S01** | 学习区管理员（唯一对外入口） | 接你的话、排今天做什么、**为每场费曼新拉一个专员**、把结果汇总 | 不直接扮小白、不判分 |
| **费曼专员（每场新建）** | 一次性会话 | **先读该题 keyPoints + 原文**，读完复述一遍（证明读到），然后**分裂成两个角色** | 不跨场复用 |
| **🐣 小白 S04** | 专员内的角色 | 只问、只复述、**绝不给答案** | 不判分、不打断 |
| **⚖️ 考官 S03** | 专员内的角色 | 侧栏记批注、结束时判定 | 不在对话流里插话 |

**「定义地图」也挂到管理员**：
- 说到"这个定义我记不清"→ **管理员拉专员，用小白追问把定义问出来**；

- 管理员每周提醒一次："有 3 张粗卡该精修了"。

**硬要求**：
1. **每场费曼一个专员，用完归档**（不许复用旧会话，避免上下文污染）；
2. **专员必须先复述知识点**（复述不上来说明没读到，直接报错给管理员）；
