## 接口契约

```
GET /book/list                     → {books:[{id,title,path,pages,sizeMB,mtime}]}
GET /book/file?id=<bookId>         → PDF 二进制（Content-Type: application/pdf，支持 Range）
GET /book/page?id=<bookId>&n=61    → 302/HTML 跳转到 #page=61（可选便捷）
```

**安全（红线）**：
- **只允许白名单目录里的 `.pdf`**：`E:\DeepFish\study\书\` 与 `学科\**\课本\*.pdf`；
- **路径必须 resolve 后仍在白名单内**（挡 `..`、挡绝对路径、挡符号链接外跳）；
- **不返回真实绝对路径**（前端只拿 id 与标题）。
