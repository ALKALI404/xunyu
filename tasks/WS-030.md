**工作台里新增两页**（不在启动器里画 UI）：

```

  ├ 模型：provider、baseUrl、model、API Key（**只写不回显**，保存后显示掩码）

```

## 接口契约（数据都来自后端，页面只渲染）

```
GET  /api/console/selftest      → { ok, checks:[{name, ok, detail, ms}] }
GET  /api/logs/tail?src=kernel|bridge|services&lines=500&onlyError=1
                                → { ok, lines:[{at,level,text}], truncated }
GET  /api/settings              → { model:{provider,baseUrl,name,keyMasked}, sampling:{...}, bridge:{url,tokenMasked}, persona:{path,mtime,chars} }
POST /api/settings              → 保存（key 为空 = 不改）
POST /api/settings/test-model   → 试连接（只回 ok/错误，不回 key）
```

## 6. 追加（主人 2026-11-07 14:20）：加「桥接」页（QQ 桥控制台）

**主人原话**：「这个能不能和我们的守护进程集成也把页面做出来」（指着鲸鲸的「微信·桥接」页）

**要做成「QQ 桥控制台」一页**，信息结构照它那页，但数据换成我们自己的：

```
【桥接】QQ 桥
├ 顶栏状态：桥心跳（最后心跳距今）· DSH 会话已绑定 · 队列深度 · 错误数
├ 开关区（**映射到桥 config.json 的白名单字段**）
│   ☑ 自动重连      发送间隔 [300] ms      ☑ 托盘自动开窗
│   ☑ 引用回复      ☐ 仅私聊（关群）      ☑ 发送后回执
├ 权限/窗口：桥在线? · 会话已绑? · 收消息是否正常 · 最近一次错误
├ 日志面板（跟随 / 仅错误 / 暂停 / 清屏 / 复制 / 打开日志文件）
└ 动作：[重启桥]（走 supervisor，不是直接 kill）· [刷新令牌] · [看队列]
```

**要求**：
1. **状态来自 supervisor（WS-016）**——**重启桥必须走 supervisor 的 `/api/supervisor/restart`**，别自己 kill；
2. **开关只允许改白名单字段**（`sendDelayMs` / `allow` / `deny` / `ackMessage` / `questionTimeoutMs`），**其他字段一律只读**；
3. **日志真滚动**（2 秒轮询增量，不整块替换）；
4. **「仅错误」= 只看 `errors.jsonl`**，「分开」= 两源并列。

**验收追加**：
- ⑧ 桥接页全屏截图（四块齐全）；
- ⑨ 关掉桥 → 页面 5 秒内变红（截图）；
- ⑩ 点「重启桥」→ 走 supervisor（贴 `supervisor.jsonl` 那行）；
- ⑪ 改发送间隔 300→100 → `config.json` 变了（截图 + diff）。
