## 接口契约

用已实现的 `/api/clause/fetch` 对**现有 20 张保单**逐张跑一遍，产出一张覆盖率表：

```
GET /api/clause/coverage  → {
  total: 20,
  ok: N, missing: [{policyId, insurerCode, reason}], failed: [...],
  byCompany: [{insurerCode, total, ok, missing}]
}
```

**规则（主人已定）**：
- **中保**：不抓，直接 `missing/no-adapter`；
- **横琴**：**只试一次**，失败即 `missing`，**不重试**；
- 同一产品**只下载一次**（`reusedFrom` 命中）；
- 每份记 `sourceUrl / fetchedAt / sha256`；
- **所有结果 `needsReview:true`**（待人工校验，不入正式档案）。
