# 工单 D55 · 项目按功能域拆分（features 加 domain/负责人/并行标记）（派 05）

> 派单 2026-10-28 20:12 本体｜依据 `docs\规则-开发与维护.md` §十九之二（功能域拆分）

## 1. 做什么

给 `state\projects.json` 的每个 feature 补三个字段，让"能并行的活"一眼可派：

```json
{ "id": "win-web", "name": "窗口页面与交互", "domain": "window",
  "owner": "06", "parallel": true, "tickets": ["D46","D47","D52","D54"],
  "contract": "window.host.*", "blockedByDomain": [] }
```

- `domain`：功能域（例：`workdesk` / `window-shell` / `window-web` / `pain` / `docs` / `memory`）；
- `owner`：默认负责工号；
- `parallel`：能否与其他域**同时开工**（`true/false`）；
- `contract`：跨域契约名（有就写，没有留空）；
- `blockedByDomain`：依赖哪些域先完成。

并在 `docs\开发文档-运行逻辑.md` 或 `projects\_INDEX.md` 加一节「功能域清单」，写清**每个域归谁、契约是什么、哪些域可并行**。

## 2. 什么算过

- `projects.json` 合法，所有 feature 都有 `domain` 与 `owner`；
- 功能域数量 ≤ 10（**别切太碎**），每个域至少一个 feature；
- 能指出**当前可并行的一组**（例：`window-web`(06) + `pain`(04) + `docs`(05) 可同时干），并说明依据；
- 给一条自检脚本输出：域 → feature 数 → 涉及单数。

## 3. 边界

- 只改 `state\projects.json` 与文档；
- 不动 worklist、不改 workdesk 代码（展示由 06 后续接）。
