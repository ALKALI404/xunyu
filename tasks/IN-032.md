## 接口契约

1. `GET /api/clause?q=<关键词>&policyId=<可选>` 返回：
   ```json
   { "hits": [ { "source":"<hash>", "policyId":"单-0001", "no":"第三条",
                 "para":2, "page":12, "text":"……命中上下文 120 字……" } ],
     "total": 3, "truncated": false }
   ```
2. **上限 20 条**，按「条号升序 → 段号升序」；
3. **没有命中** → `{hits:[], total:0}`，**不许编**；
4. 页面：保单详情里加一块「查条款」输入框，结果**必须显示「第X条 第Y段」+ 原文片段**，点一下能看整段。

## 0.5 预期结果

在保单页搜「免责」，出来 2–3 条，每条标着「第五条第2段」并带原文；搜不存在的词就明确说「没找到」。

## 1. 做什么

1. `server.mjs` 加 `/api/clause`（读 `档案\条款\*.json`，简单子串匹配即可，**不做语义检索**）；
2. `index.html` 保单详情里加查询块（不新建页面）；
3. 结果里「条号/段号/页码」三者缺一不可显示（缺就写「页码未记录」）。

## 2. 可验方式

- ① `GET /api/clause?q=免责` 贴返回 JSON（含 no/para/text）；
- ② 搜一个肯定没有的词 → 贴 `{hits:[],total:0}`；
- ③ 页面截图：查询块 + 结果列表 + 点开整段；
- ④ 贴匹配代码片段（≤10 行）。
