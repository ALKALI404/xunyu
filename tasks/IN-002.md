## 接口契约

- `POST /api/upload`，`multipart/form-data`，字段名 `file`（可多个）。
- 落盘：`收件箱/<sha1前10><扩展名>`；**同哈希已存在则不重写**，返回 `dup:true`。
- 索引：向 `索引\files.jsonl` **追加一行**，字段与现有 schema 一致（at/hash/file/origin/ext/sizeKB/receivedAt/engine/pages/chars/textHead）。
- 提取：复用 `脚本\extract.py`（已存在），拿不到文字时把文件名写进 `待校对.txt`，**不编造字段**。
- 返回：`{ok, results:[{file, hash, dup, chars, engine}]}`。
- 服务端：改 `窗口\server.mjs`（现有 9343 端口那个），**不要另起服务**。

## 0.5 预期结果

你在页面上把一份 PDF 拖进去，`收件箱` 里多一个文件、`索引\files.jsonl` 多一行、同一份再拖一次不会重复。

## 1. 做什么

1. 在 `窗口\server.mjs` 加 `/api/upload` 路由（只收 pdf/docx/doc/jpg/png，限 50MB）；
2. 哈希去重 + 落盘 + 调 `extract.py` 提取；
3. 写索引与 `待校对.txt`；
4. 顺手修一个已知 bug：**现在 `ingest.mjs` 会把 `cache\WeAppIcon` 和 `favorite\temp` 的图当收件收**，上传接口不要复制这个错误（只收用户明确上传的文件）。

## 2. 可验方式

- ① 用 `curl` 或 PowerShell 传 `收件箱` 里一份真 PDF：贴出返回 JSON；
- ② `索引\files.jsonl` 行数 +1，贴最后一行；
- ③ 同一文件再传一次：返回 `dup:true`，索引行数不变（贴）；
- ④ 传一个 60MB 文件应被拒（贴状态码）。

## 3. 边界

只做上传与入库；**不解析保单字段、不改前端、不动 `档案\`**。

## 4. 回滚

`server.mjs` 改动前备份为 `server.mjs.bak-in002`；路由不生效时恢复即可，数据文件不受影响。
