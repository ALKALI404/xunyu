# 工单 D54 · 项目视图子菜单关不掉（一关就弹开）（派 06）

> 派单 2026-10-28 20:08 本体｜主人实测：项目卡里的子菜单（子功能列表）点收起后又自己弹开

## 1. 根因（推断，需你确认）

工作台页面**每 5 秒整块重渲染**（`tick()` → `fetch` → `box.innerHTML = ...`），展开/收起状态**只存在 DOM 里**，重渲染后 DOM 重建 → 回到默认展开。所以你点"收起"的下一帧（≤5 秒）就又弹开了。

## 2. 做什么

1. **状态外置**：每个项目卡（或分类）维护 `expanded: { [projectId]: true|false }`，存在 JS 变量 + `localStorage`（key 建议 `workdesk.expanded.v1`）；
2. **渲染后回填**：每次重渲染结束，按状态映射重新设置展开/收起（用事件委托，别逐个绑 `onclick`）；
3. **点击才改变状态**：收起 = 写入 `false`，并且**下一次重渲染保持 false**；不许每次渲染时无条件展开；
4. **默认值**：首次访问默认**收起**（避免一屏全是子功能）；
5. **同样的坑一次修掉**：其它可折叠区（已完成栏、分组、抽屉）都用同一套 `expanded` 机制。

## 3. 什么算过

- 收起一个项目卡 → **等 10 秒以上**（跨过两次重渲染）仍是收起状态（截图两张，时间戳可证）；
- 刷新页面后保持收起（localStorage 生效）；
- 展开另一个卡不影响已收起的卡；
- 已完成的「已完成」栏折叠状态同样能持久（若 D53 已交）。

## 4. 边界

- 只改 `scripts\workdesk-server.mjs` 的页面 JS；
- 不改接口语义、不改 `state\projects.json`、不改 worklist-core。
