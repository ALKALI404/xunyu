# 工单 TXR-001 · 夹具：返工印记与错题本（UG-036 验收用）

> `TXR-` 前缀夹具票，验收完即 drop。

## 接口契约

```
recordRework(task, { reason, category, by, evidence, fix }) -> { ok, record, attempt }
resolveRework(ticket, { by }) -> { ok, resolved, at }
```

- 输入：`reason` 必须是打回者原话（逐字入库）；`attempt` 由记录数派生
- 输出：`ok=true` 表示已追加 / 已标 resolved

## 1. 做什么

## 2. 预期结果

## 3. 可验方式

`node scripts\worklist.mjs reject <票号> --reason weak-evidence --note "…"` → 输出"错题本：…第 1 次返工"。

## 4. 边界

只做夹具，不改业务代码。

## 5. 回滚

`drop` 掉票 + 删本任务书。
