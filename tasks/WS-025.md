## 1. 做什么

**① 文件页（改造 `Views\StickerPage.*` → `Views\FilesPage.*`）**
- 两个页签：`发送` / `收件`；
- 发送：`选择文件…`（OpenFileDialog，**默认目录 `data\files\outbox\`**）→ 选中显示 名称/大小/类型 → `发送到 [聊天对象下拉]` → 列表显示状态；
- 状态四色但**必须带文字**：`排队中 / 发送中 / 已发送（确认） / 未确认（点开看原因） / 失败`；
- 每行操作：`取消`（排队中）、`重试`（失败/未确认）、`打开所在文件夹`；
- 收件：列表（时间 名称 大小 来源）→ 双击用系统默认程序打开。

**② 待办页（改造 `Views\ReminderPage.*` → `Views\TodoPage.*`）**
- 四组：`今天` / `本周` / `过期` / `已完成`（各组空则整组不显示，不显示空框）；
- 新建：标题 + 时间（日期+时分选择器）+ 重复（无/每天/每周）；
- 行操作：勾 `完成`、`取消`、`编辑`；
- 下方保留"提醒规则"区（每天最多 / 刚聊过跳过 / 主动搭话开关），文案沿用现有中文，不重写。

## 2. 预期结果

选文件 → 发出去 → 状态自己变（2 秒轮询，局部刷新不闪）；建待办 → 到点微信收到 → 页面上勾完成。

## 3. 可验方式

- ① 四张截图：发送中 / 已发送 / 收件列表 / 空态（"还没有文件"）；
- ② 待办页四组各一张 + 新建态一张；
- ③ 状态轮询：发一个 20 MB 文件，观察 `发送中 → 已发送` 两次状态都截到；
- **反例**：后端 503（手停桥）→ 列表显示"发送中（桥接不在线）"，**不转圈到死**；文件 50 MB 以上 → 前端先挡一次（提示大小），别等 400；
- **红绿灯/状态不许只靠颜色**（色盲友好）。
