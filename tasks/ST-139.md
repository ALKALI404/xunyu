# ST-139 · 书架区页面（按学科放课本 + 公开课 + 上传）

> 建单 2026-11-07 15:00｜目标 **06（界面与交互）**｜项目 study / feature st-shelf
> 主人原话：「做一个书架区按学科放课本，还有公开课的链接按学科和从简单到困难来……另外支持自助上传课本」
> 前置：ST-138 的 `/shelf`、`/shelf/upload`（04 在做）——**接口没好先用假数据搭结构，别等**

## 一、要什么样

**学习区加「书架」页签**（和 主页/答题/复习/错题/分析 并列）：

```
【书架】按学科分区，一本书一张卡
┌ 逻辑学 ────────────────────────────────┐
│ 《逻辑学导论（第15版）》  硬  中文  1222页  [打开] │
│ 《简明逻辑学》          入门 中文  ——      [未下载]│
│ 公开课：B站「逻辑学导论 精讲」 入门 12h  [去听]     │
├ 物理学 ────────────────────────────────┤
│ 《费曼物理学讲义 第1卷》 硬  中文  600页   [打开]   │
└────────────────────────────────────────┘
```

**版式要求**：
1. **按学科分区**，每区先课本（**难度从简单到硬**排序），再公开课（**同样简→难**）；
2. **每张卡有难度标签**：`入门`（浅蓝）/`进阶`（蓝）/`硬`（深蓝）——**别用红绿**（延续白/浅灰/浅蓝）；
3. **`未下载` 的书卡灰一点**，按钮写「未下载」，**点了只提示"还没这本书，可在下面上传"**，不报错；
4. **公开课卡**显示：来源（B站/YT）、UP 主、时长、难度、一句话说明，**点「去听」新标签页打开**；
5. **顶部右侧「＋ 上传课本」按钮** → 选学科、填书名、选 PDF → 传 → 成功后卡片出现在对应学科。

## 接口契约（用 ST-138 的）

```
GET  /shelf                     → subjects[{name, books[], courses[]}]
POST /shelf/upload  (multipart 或 base64) → { ok, id, path }
GET  /book/file?id=<bookId>     → PDF（新标签页打开）
```

**上传交互**：
- **文件选择框 `accept="application/pdf"`**；
- **上传中显示进度/置灰**，**成功后原地刷新该学科**（不整页重载）；
- **失败要说原因**（不是 PDF / 太大 / 重名 → 自动改名），**别说"失败"就完**。
