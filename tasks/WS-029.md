## 接口契约

只读 `GET /api/console`（3–5 秒缓存，15 秒轮询没问题）：

```
channels.qq     { state:"ok|unreachable", online, lastAt, sentToday, recvToday, detail }
channels.relay  { state:"ok|unreachable", bound, total:2, lastAt, detail }
channels.files  { state:"not-implemented", detail }              // 未接入，必须显式
brain.persona   { file, mtime, chars, hasFrontMatter }
brain.memory    { files, lines, bytes }
brain.model     { available:false, note:"经 DSH，无本地读数" }
```

> `/api/console` 顶层 `ok:true` 表示"这份报告拿到了"；**渠道不可用用 `state` 表达，不用 `ok:false`**（《开发规范》§四）。整页读不到（503/超时）才走"读不到总控台 + 重试"。

## 1. 做什么

在 WS-017 的调度台页面里**加两栏**（不要新建页面）：

**② 渠道（三行）**
- QQ：`● 在线 / ○ 离线` + 「最近 14:2x · 今发 3 / 收 5」；读不到 → 「读不到（原因）」；
- 窗口 relay：`绑定 2/2` + 最近一条；
- QQ 文件通道：**未接入时显示灰底 +「未接入（网关有能力，本地没实现）」**，**不许显示成"正常"或"离线"**。

**③ 脑子（四格）**
- 人设：`鲟鱼.md · 1,806 B · 14:0x`（没有 front-matter 就标"无参数段"）；
- 记忆：`1,240 条 / 38 MB`；
- 今日花费：复用④栏已有；
- 模型：固定一行灰字「经 DSH，无本地读数」。
