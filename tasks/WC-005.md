## 0.5 预期结果

VM 重启后**自动登录 + 企微自动启动 + 主窗口保持存在**（不落托盘/不被关闭），并能被外部任务枚举到；有一套健康检查能证明"窗口在、登录在"。

## 1. 做什么

1. **自动登录**：已配（`AutoAdminLogon=1`、空密码）→ 验证重启后真的免登录进桌面（重启一次 VM 实测）；
2. **企微自启 + 保活**：
   - 启动项/计划任务保证登录后 `WXWork.exe` 起来；
   - **防托盘销毁**：写一个每 60 秒的看护任务——`FindWindow` 找不到主窗口就重新激活/重启企微；顺手把窗口 `ShowWindow(SW_MAXIMIZE)` 保持可见；
3. **不锁屏/不睡眠**：电源策略已设，补一条"会话不被 RDP 断开影响"的说明（用 vmconnect 控制台，不用 RDP）；
4. **健康探针**：`scripts\wecom-vm-health.mjs` 输出 `{ssh:ok, wxwork:pid, window:hwnd, loggedIn:true/false}`；挂进 supervisor 或计划任务每 5 分钟一次；
5. **重启演练**：`Restart-VM` 一次，验证 3 分钟内自愈。

## 2. 验收与判据

- ① 重启 VM 后 3 分钟内：桌面免登录、企微 pid 有、**窗口 hwnd 可枚举**（贴前后对比）；
- ② 手动把企微"关闭到托盘" → **60 秒内看护任务把窗口拉回来**（贴时间戳）；
- ③ 健康探针连续 3 次输出 ok（贴三行）；
- ④ 演练记录：一次真实重启的时间线。

## 3. 边界

- 只动 VM 内启动项/计划任务 + 宿主 `scripts\wecom-vm-health.mjs`；
- 不改企微安装、不动宿主桌面。
