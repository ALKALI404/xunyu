# ST-137 · 学科书目 + 公开课调研（B站优先，难度从简到难）

> 建单 2026-11-07 15:00｜目标 **05（文档与架构）**｜项目 study / feature st-shelf
> 主人原话：「做一个书架区按学科放课本，还有公开课的链接按学科和从简单到困难来。物理学的课本就用费曼物理学讲义，你到网上和github上找难度合适的课本。公开课先上b站找能用的链接，没有再看ytb」

## 一、要交两份清单

**① 书目**：**每个学科 2–3 本，按难度排序（入门 → 进阶 → 硬）**

| 学科 | 要求 |
|---|---|
| **数学** | 入门（如《数学分析》入门类）/ 进阶 / 硬 |
| **逻辑学** | ✅ 已有《逻辑学导论（第15版）》 |
| **哲学** | 入门（如《大问题》）/ 进阶 |
| **物理** | **入门 + 主课本一律用《费曼物理学讲义》**（第1卷起） |
| **化学** | 入门（如《普通化学》）/ 进阶 |
| **生物学** | 入门（如《生物学》Campbell）/ 进阶 |
| **计算机科学** | 入门（如 SICP / CS50 配套）/ 进阶 |

**挑选标准**：
1. **中文版优先**（你在中文环境学）；没有中文版就标「英文」；
2. **公版/开源优先**（GitHub、OpenStax、arXiv、互联网档案馆）；
3. **必须给来源链接**（GitHub / 出版方 / 合法公开渠道）；
4. **不许给盗版网盘链接**；
5. **标出体积与页数**（估算即可），**便于以后决定要不要下**。

**② 公开课**：每个学科 **2–4 门**，按难度排序

```
优先级：B 站 → （没有才）YouTube
必须给：标题 / UP 主或频道 / 链接 / 大致时长或集数 / 难度（入门/进阶/硬）/ 一句话说明
```

**硬要求**：
- **链接必须是真实可访问的**（你要能说出来「我核过」的方式：例如抓了标题页）；**不许编**；
- **失效或转载混乱的不要**（宁缺毋滥，**每学科至少 2 门**）；
- **B 站优先中文**，YouTube 补英文经典（MIT OCW / 3Blue1Brown / CrashCourse 之类）。
