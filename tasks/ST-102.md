## 接口契约

```
POST /quiz/grade  {questionId, answer, usedHint}
  → {verdict:"pass"|"half"|"fail", hit:[], missing:[], confusedWith, feedback}
GET  /quiz/wrong?due=  → {items:[{id,book,chapter,kind,question,verdict,missing,nextDue,attempts}]}
GET  /quiz/stats?days=14 → {byType:{...}, byChapter:{...}, trend:[{date,firstTryRate}]}
```

**判定规则（写死，不许自由发挥）**：
1. 读题面里的 `keyPoints[]`（3–5 条核心点）；
2. **命中 ≥2/3 → pass；命中 1 条 → half；0 条或答非所问 → fail**；
3. **`usedHint:true` 一律不得判 pass**（最高 half）——**要过提示就算没独立答出来**；
4. **必须给 `missing[]`**：说清漏了哪条，**不许只给"不对"**；
5. **边界题**：`判据`缺失 → 最高 half（判据是这类题的核心）。

**错题集**：
- 入集条件：`fail` / `half` / `usedHint`；
- 间隔：**1 → 3 → 7 → 15 天**；**连过两次** → `retired:true`；
- 存 `E:\DeepFish\study\笔记\<书>\wrong.jsonl`。

**分析**：
- `byType`：按 `confusedWith`/`missing` 分类计数（例："有效vs可靠混淆"）；
- `byChapter`：每章 题数/过/半/错；
- `trend`：按天算**首次答对率**（同题重考不算）。
