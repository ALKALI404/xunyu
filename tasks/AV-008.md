## 1. 做什么（三级底色，逐层落地）

| 层 | 元素 | 规格 |
|---|---|---|
| **L0 背景** | 页面根 | 极淡渐变 `#F7F5F2 → #EFEDE9`，**不许纯色大块** |
| **L1 外壳** | 顶栏 / 左抽屉 / 右浮层 / 状态条 | `background: rgba(255,255,255,.72)` + `backdrop-filter: blur(24px) saturate(160%)` + 1px 边 `rgba(255,255,255,.65)` |
| **L2 正文卡** | 消息区 / 输入区 / 卡片 | **纯白 `#FFFFFF`** + 1px 边 `#E6E1D8` + 阴影 `0 8px 24px rgba(15,23,42,.06)` |

细节：
1. 圆角：外壳 **16**、正文卡 **12**、按钮/胶囊 **999**；
2. 动效 **200–260ms** `cubic-bezier(.22,.61,.36,1)`；hover 只提亮 + 上浮 1px，**不许缩放**；
3. **玻璃开关**（设置里）关闭时：L1 全部退回纯色 `#FFFFFF`、`backdrop-filter:none`，**文字对比度不许下降**；
4. **性能红线**：同屏模糊层 ≤3；列表滚动区域内部**不加** blur；首屏 <1.5s。
