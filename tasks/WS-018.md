## 三、接口契约

```
# 文件通道（替代表情包）
POST /api/files/send    { chatId, path }        → { ok, kind, bytes, sha256 }
POST /api/files/receive { chatId, kind }        → { ok, savedAs, bytes, sha256 }

# 待办与提醒（合并它的 reminder + care）
GET  /api/todo?due=1                            → { ok, items:[{id,title,dueAt,done}] }
POST /api/todo { title, dueAt }                 → { ok, id }
POST /api/todo/{id}/done                        → { ok }

# 守护与自检（合并 WS-016/017）
GET  /api/supervisor                            → 服务红绿灯（WS-016 已定义）
GET  /api/selftest                              → { ok, checks:[{name,ok,detail}] }
```

**红线**：
- **文件只能进出白名单目录**（`收件箱\` / `输出\`），**不许任意路径**；
- **不许对公网开任何口**（全部 127.x 本机）；
- **删掉更新检查后，程序不许再往 GitHub 发任何请求**（自检项里要有这一条）。
