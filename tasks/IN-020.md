## 6. 附加（主人 2026-11-05 23:40 定）：现金价值动态索引

- **不再要求手填 `cashValue`**；改为服务端按 `effectiveAt` + `cashValueHistory` **算出当前年度**：
  ```
  asOfAnniv = 生效日的月日 + 今天所在年
  policyYear = 今天 >= asOfAnniv ? (今年-生效年+1) : (今年-生效年)
  amount = history[policyYear] ?? null   // 没有就 null，不插值
  ```
- `GET /api/policies` 每人每单返回：`{policyYear, amount, asOf: "YYYY-MM-DD", prev:{year,amount}, next:{year,amount|null}, listed:boolean}`；
- **验证**：太平单（2016-04-09，今天 2026-11-05）→ `policyYear=11`，若表里没有第11年 → `amount:null, listed:false`；
  把"今天"临时改成 2026-03-01 → 应得 `policyYear=10, amount=296900`。
## 7. 追加（主人 2026-11-05 23:55）：超出表末年度按最后一年算

取值顺序：
1. `history[policyYear]` 有 → 直接用；
2. **`policyYear > 表末年` → 用 `history[表末年]`**，字段里带 `clamped:true` 与 `label:"按表末第N年计（已超出表列年度）"`；
3. 表内缺该年 → 用**最近的下一年档**，`clamped:true`、`label:"按第X年值（表内缺第Y年）"`；
4. 完全没有 → `amount:null`、`label:"暂无相关信息"`。

**验收**：把"今天"设成 2036-11-05（第 21 年后）→ 应得 `amount=311300, clamped=true`。
## 8. 追加（主人 2026-11-05 00:00）：返回 currentCashValue
