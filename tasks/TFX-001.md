# 工单 TFX-001 · 夹具：五要素齐 + 有「接口契约」小节

> UG-034 的正例夹具：和 TFX-002 只差一个接口契约小节。

## 接口契约

```
dispatch(taskId, { contractGate?: boolean }) -> { ok, status, code, detail }
checkContractGate(task) -> { ok:true, contract, project, feature, book } | { ok:false, code, detail, fix }
```

- 输入：`task`（台账回放出的票对象，含 ticket/project/feature/kind）
- 输出：`ok=true` 表示接口层齐了；否则 `code ∈ {no-contract-section, no-contract-field, no-projects}`

## 1. 做什么

正例：任务书带接口契约 → 接口闸放行。

## 2. 预期结果

`dispatch --dry-run` 不因接口闸被拒（能走到生成 prompt 那一步）。

## 3. 可验方式

`node scripts\worklist.mjs dispatch <票号> --dry-run --allow-out-of-project` → 打印 prompt，exit=0。

## 4. 边界

只做验收夹具。

## 5. 回滚

`drop` 掉票 + 删本任务书。
