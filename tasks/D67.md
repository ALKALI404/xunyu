# 工单 D67 · 功能域/项目签收事件与 CLI（派 04）

> 派单 2026-10-28 21:15 本体｜主人纠正：「完成」必须经 01 审核签收（规则二十之二）

## 1. 做什么

台账新增两种**签收事件**（不改票状态，只记"这块过了"）：

1. `worklist.mjs approve-feature --project <id> --feature <id> --note "验收结论"`：
   - 前置校验：该功能域所有票必须 `done`（有 dropped 的按 05 规则判），否则拒绝并列出未完成的票；
   - 写事件 `{op:'feature-approved', project, feature, by, note, t}`；
2. `worklist.mjs approve-project --project <id> --note "…"`：
   - 前置：所有功能域已签收；否则列出未签的域；
3. **撤销**：`--revoke` 写 `feature-revoked`/`project-revoked`（带 note），用于验收后发现有问题；
4. **查询**：`list --projects` 显示每个项目/功能域的 `票完成度 / 是否已签收（by, at）`。

## 2. 什么算过

- 对一个票未全 done 的功能域执行 `approve-feature` → 拒绝并列出缺哪几张（贴输出）；
- 票全 done 后执行 → 成功，`list --projects` 显示「已签收 by 01 at …」（贴）；
- `--revoke` 能撤销且留痕（贴）；
- 重复签收幂等（第二次要么拒绝要么无变化，说明策略）。

## 3. 边界

- 改 `worklist.mjs` / `worklist-core.mjs`（事件与回放）；
- **不改** `projects.json` 定义字段、不改页面（06 消费这些事件）。
