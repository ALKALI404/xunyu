**规则（按更正后的口径）**：

1. **两个 iframe 都活着**（不要求卸载）——**切走用 `display:none` 隐藏**，切回来**保留状态**（滚动位置、正在答的题）；
2. **同一时刻 `display:block` 的 iframe 有且只有一个**；
3. **记住上次选的是哪个**（`localStorage`），下次进来直接是它；
4. **iframe 撑满高度**，父容器 `display:flex`，**不许双层滚动条**；
5. 学习区/工作台若设 `X-Frame-Options: DENY`，**改成允许本机嵌入**（只放 `127.0.0.1` / `127.1.x`，不放开公网）。

## 6. 追加（主人 2026-11-07 02:02）：鲟鱼消息气泡改成「浅灰 → 白」渐变

**主人原话**：「对话栏的我的消息有渐变很好看，你的消息能做成浅灰色到白色的渐变吗」

**现状**：
- `.msg.me`（主人）已是渐变：`linear-gradient(160deg, var(--accent2), var(--accent))`——**保留不动**；
- `.msg.her`（鲟鱼）现在是**纯色** `background: var(--l2-bg)`——**要改成渐变**。

**改成**（照抄这行，别自己调色）：
```css
.msg.her{
  background:linear-gradient(160deg, #EDF2F7 0%, #FFFFFF 70%);
  border:1px solid var(--l2-line);
  border-bottom-left-radius:6px;box-shadow:var(--l2-shadow);
}
```

**要求**：
1. **角度与主人气泡一致**（160deg），**方向相反**（浅灰在上、白在下），**这样两个气泡看起来像一对**；
2. **文字对比度**：`--ink` 在 `#FFFFFF` 上必须 ≥7:1（深墨模式反着来：`linear-gradient(160deg,#222C36,#1B232C)`）；
3. **浅色渐变不许发黄**（只用 `#EDF2F7` 冷灰，**禁用任何米色**）；
4. 长消息气泡也要保持渐变（**别被 `background-attachment` 或分块打断**）；
5. **两个窗口副本一起改**。

**验收追加**：
- ⑦ 截图：主人气泡（蓝渐变）+ 鲟鱼气泡（灰白渐变）**同屏对照**；
- ⑧ 深墨模式同屏对照截图；
- ⑨ 贴实际用的两行 CSS（证明没发黄）。
