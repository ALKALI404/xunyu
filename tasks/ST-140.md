# ST-140 · 第 2–14 章的目录与题干（否则点不进去）

> 建单 2026-11-07 18:25｜目标 **05（文档与架构）**｜项目 study / feature st-quiz-nav
> 起因：本体验 ST-134 时发现——**章目录.json 有 14 章，但磁盘上只有第 1 章的目录**，所以 2.x 之后点进去全是 `404 no-chapter-dir`。

## 一、现状（我实测）

```
章目录.json：14 章都有（ch2 论证的分析 page=61 有 4 小节；ch3/ch4 小节=0）
磁盘：只有 第01章-逻辑学的基本概念\ 一个目录
结果：/quiz/section/read 对 ch2/2.1 → 404 no-chapter-dir
      答题页进第 2 章 → 章节三态是 locked，点不动
```

## 二、要什么

**给 14 章（至少第 2–6 章）建出目录与内容骨架**，让用户能真的往下走：

```
学科\逻辑学\课本\逻辑学导论\章节\第02章-论证的分析\
├ 笔记.md            （空模板：标题 + 读法 + 摘录区）
├ 练习\grade-log.jsonl（空文件）
└ 分析\已读.jsonl    （空文件）
```

**用 `章目录.json` 里已有的 `page` 与 `sections` 填写，不许瞎编章节名。**

## 接口契约

不需要新接口；**目标是让现有接口在 ch2+ 上不再 404**：
```
GET  /quiz/outline?bookId=logic-intro       → ch2..ch6 的 section 有 questions 或 noQuestion=true
POST /quiz/section/read {chapter:2,section:"2.1"} → 200（不再 404）
GET  /note?bookId=logic-intro&chapter=2     → 200（不再是"没找到"）
```

## 0.5 预期结果

**答题页能点进第 2 章、第 3 章**；`/quiz/section/read` 对无题小节返回 200；`/note` 对第 2 章返回空模板。

## 1. 做什么

1. 按 `章目录.json` 建目录（**第 2–6 章先做，7–14 可后补**）；
2. 每章写 `笔记.md` 模板（用该章标题与页码区间）；
3. 补 `练习\`、`分析\` 空文件；
4. **别动第 1 章已有的内容**（笔记 6 KB、86 行 grade-log）。

## 2. 可验方式

- ① `GET /quiz/outline`：ch2 的小节不再是"点不动"（贴 JSON）；
- ② `POST /quiz/section/read {chapter:2,section:"2.1"}` → **200**（贴）；
- ③ `GET /note?bookId=logic-intro&chapter=2` → 200 且返回模板（贴前 2 行）；
- ④ 目录截图（第2章目录结构）。

## 3. 边界

**只建目录与空模板，不写笔记正文、不补题**（补题是另一张票）。

## 4. 回滚

删掉新建的章节目录即可；第 1 章不动。

## 5. 附加要求

- **章节名必须来自 `章目录.json`**（别自己起名）；
- **页码区间写进笔记模板**（"本章 p61–109"），方便你以后读。
