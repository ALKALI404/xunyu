## 接口契约

1. **删掉「本人」那一栏**：页面不再渲染任何 `relation: "本人"` 的行（grep `本人` 应为 0 命中，注释除外）。
2. **`people.json` 增加 `relations`**（以人为中心）：

```json
"relations": {
  "spouse":   [{"personId":"人-0004","confirmed":true}],
  "parents":  [{"personId":"人-0001","kind":"mother","confirmed":true},
               {"personId":"人-0005","kind":"father","confirmed":false,"derived":true}],
  "children": [{"personId":"人-0006","kind":"child","confirmed":true}],
  "others":   []
}
```
   - `spouse` **最多 1 条**；替换时旧记录进 `spouseHistory`（**不删**）；
   - `parents`：`kind ∈ {father,mother,stepfather,stepmother,guardian,unspecified}`，**不限条数**；
   - `children`：**不限条数**。
3. **对称写入**：A 的 `parents` 有 B ⇒ B 的 `children` 自动补 A（标 `derived:true`）。
4. **接口**（`窗口\server.mjs`）：
   - `POST /api/relation` body `{personId, slot:"spouse"|"parents"|"children", action:"add"|"remove"|"confirm", personId2, kind?, force?}`
   - 返回该人更新后的 `relations`；
   - 删除只允许删 `derived` 或空槽；**已确认关系删除要 `force:true`**。
5. **界面**（`窗口\index.html`）：配偶一块（单格，✎编辑/✕清除）、父母一块（**默认两格** + 「＋添加」）、子女一块（列表 + 「＋添加」）。
6. **推定的人**：显示「（推定）」+「确认/更正」；**确认前不写 `confirmed:true`**。
