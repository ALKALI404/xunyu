# 工单 D56 · 子菜单仍自动弹开：改"点 summary 才改状态 + 页面禁缓存"（派 06）

> 派单 2026-10-28 20:15 本体｜D54 已交但主人实测仍弹开

## 1. 现状排查（我读了线上 HTML）

- `EXPANDED` + `localStorage('workdesk.expanded.v1')` + `isOpen()` 默认收起——**渲染逻辑是对的**（`<details ... open>` 只在 `isOpen()` 为真时加）；
- 但状态监听用的是 **`document.addEventListener('toggle', ..., true)`**。问题在这：**`toggle` 事件不只由用户点击触发**——5 秒重绘替换 DOM、`open` 属性程序化变化，也会触发 `toggle`，于是"浏览器/重绘导致的一次打开"会被记成用户意图 `true`，下一次重绘就保持打开 → 表现为「一关就弹开」；
- 叠加：页面没有禁缓存，主人可能一直看旧 HTML。

## 2. 做什么

1. **只认用户点击**：去掉 `toggle` 监听，改成在 `summary` 上绑 `click`（事件委托到 `#pj-list`，`e.preventDefault()` 自己控制 `details.open`），**只有真实点击才写 `EXPANDED`**；
2. **程序化改 open 不算状态**：渲染时若 `EXPANDED[key]` 未变，不许写 localStorage；
3. **禁缓存**：`GET /` 响应加 `Cache-Control: no-store, must-revalidate`，并在 `<script src>`/内联 JSON 处加 `?v=<启动时间戳>`（内联的话给 `/api/*` 加 no-store 即可）；
4. 底部 `已完成` 栏、分组卡同用这套；
5. 交付里**贴出"点击 → 5 秒后仍收起"的证据**（两张带时间截图）。

## 3. 什么算过

- 收起项目卡 → 等 ≥10 秒（跨两次重绘）仍收起；
- 刷新页面保持收起；
- 展开 B 卡不影响 A 卡；
- `grep 'addEventListener(.toggle'` 在页面里为 0（贴结果）；
- `/` 响应头有 `Cache-Control: no-store`（贴 `curl -I` 输出）。
