# 工单 D58 · 台账失真修复：一人一 doing + reject 回排队（派 04，P0）

> 派单 2026-10-28 20:25 本体｜主人：台账依赖链显示"正在做"但没人接手

## 1. 现状（实测）

- **04 一个工号挂着 4 张 `doing`**：W-047(D30)、W-060(D31)、W-074(D37)、W-083(D44)——一个人只有一双手，台账在说谎；
- `worklist.mjs state W-047 queued` → **`不允许 doing → queued`**：状态机**没有"退回排队"的路径**；
- 01 reject 后把票退回 `doing`，但**没人重派**，于是票永远挂"在做"；
- dispatch 也不检查"该工号已有 doing"，我刚派 D37 就叠成了第 3、4 张。

## 2. 做什么

1. **状态机加一条合法边**：`doing → queued`（备注必填，用于"打回/放弃当前轮/误派"）；
2. **reject 语义改为回 `queued`**（不是 doing），并把「重派」交给自动接力（空闲+queued 即派）；
3. **dispatch 守卫**：目标工号已有任意 `doing` → 返回 `409 worker-has-doing`，除非显式 `--force`（force 要写审计）；
4. **自动接力加固**：同一工号**最多派到 1 张 doing**，其余留在 queued；
5. **台账统计**：`list` 的「在干」按工号去重显示，超过 1 条时标注 `⚠ 多张在做`。

## 3. 什么算过

- 造 A/B 两单派给同一工号：第二张被 `409 worker-has-doing` 拒；
- 对一张 doing 执行退回 → 状态变 `queued` 且带理由（贴命令与输出）；
- reject 一张 submitted → 落 `queued` 而不是 `doing`（贴）；
- 清理当前 04 那 4 张：保留真在做的 1 张，其余 3 张退回 `queued`（贴清理前后 `list` 对比）；
- `list` 对多张 doing 显示 `⚠`。

## 4. 边界

- 改 `worklist-core.mjs`（状态机边 + reject 语义）、`worklist.mjs`（state/dispatch/list）、`dispatch-core.mjs`（守卫）；
- **不动**页面渲染（那是 06）、不动 `state\projects.json`（05）、不动 bridge。

## 5. 回滚

- 改前 copy 三个文件到 `backup\ledger-<日期>\`；复制回去即回滚（状态下沉不会丢，只是边变少）。
