## 接口契约

页面 `?view=quiz`、`?view=wrong`、`?view=analysis` 三个视图，调这四个接口（细节见规格第五节）：

```
GET  /quiz?bookId=&chapter=   → {questions:[{id,kind,stem,keyPoints,source}]}
POST /quiz/grade              → {verdict:"pass"|"half"|"fail", hit[], missing[], confusedWith, feedback}
GET  /quiz/wrong?due=         → {items:[{...nextDue}]}
GET  /quiz/stats?days=14      → {byType, byChapter, trend}
```

**页面数据结构**（本地草稿也要按这个存）：
```json
{ "questionId":"q-ch01-02", "answer":"…", "verdict":"half",
  "missing":["判据缺失"], "usedHint":true, "savedAt":"…" }
```

## 0.5 预期结果

打开答题页就能做题：**写答案 → 提交 → 看到"对/半/错 + 你漏了什么"**；答错的自动进错题集；分析页能看到"我最近最常犯的错"。

## 1. 做什么

1. 三个视图（quiz / wrong / analysis），顶栏与个人页共用；
2. 答题区：`textarea` + **每 5 秒自动存草稿**（localStorage 即可）+ 「提交批改」「我要提示」「跳过」；
3. 批改展示：**判定徽章 + 命中要点打勾 + 缺失项 + 混淆提示**（如"有效 ≠ 可靠"）；
4. 错题集：按到期排序，点进去重考，连过两次标「已掌握」；
5. 分析页：错误类型分布、章节掌握度、14 天首次答对率曲线 + **顶部一句话结论**（最高频错误类型）。

## 2. 可验方式

- ① 答对一题的截图（判定 + 命中要点）；
- ② 答半对一题的截图（"你漏了什么"）；
- ③ 错题进集 + 次日到期的截图 + `jsonl` 片段；
- ④ 分析页三块截图；
- ⑤ 草稿：填一半刷新页面，内容还在（截图）。
