## 接口契约

对 `档案\policies.jsonl` 里**所有已有 `cashValueHistory` 的保单**，补一个 `currentCashValue`：

```json
"currentCashValue": {
  "amount": 296900, "currency": "CNY", "policyYear": 11,
  "asOf": "2025-04-09",
  "label": "按第10年值（表内缺第11年）",
  "clamped": true, "listed": false
}
```

**算法（照抄，不许自己发挥）**：
1. `policyYear`：生效日的月日 + 今天所在年 = 今年周年日；今天 ≥ 周年日 → `今年-生效年+1`，否则 `今年-生效年`；
2. `amount`：
   - `history[policyYear]` 有 → 用它，`clamped:false, listed:true, label:"第N年"`；
   - `policyYear > 表末年` → 用 `history[表末年]`，`clamped:true, listed:false, label:"按表末第X年计（已超出表列年度）"`；
   - 表内缺该年 → 用**最近的下一年档**，`clamped:true, listed:false, label:"按第X年值（表内缺第Y年）"`；
   - 一条都没有 → `amount:null, label:"暂无相关信息"`；
3. `asOf`：取**所采用那一档对应的周年日**（例：用第10年 → 生效日+9年，写 `2025-04-09`）；
4. **没有 `cashValueHistory` 的保单**：加 `"currentCashValue": null` 并在 `pending` 里补 `"现金价值"`。

**基准日期**：本票按 `2026-11-05` 计算（写进 `computedAt` 字段，方便以后重算）。
