# 工单 D74 · 窗口消息时间戳：定义了却从没显示（派 06）

## 1. 实测证据

- `History\window\鲟鱼\2026-10-28.jsonl` 每行**有 `t`**（epoch ms）→ 存储 ✅；

4. `dsh` 与 `鲟鱼` 两个通道都生效；
5. 把 `clock` 用 `grep` 能查到调用点（≥2 处：消息渲染 + 日期分隔判断）。
