## 0.5 预期结果
- 票在**优先名单外** → 记一行 `parked`（不重试、不计数、不报警）；
- 票已 `dropped/done` → **立即放弃重试**；
- 只有"名单内、依赖已清、真的派不出去"才报警。

## 接口契约
- `classifyDispatchFailure(ticket, code) -> 'parked' | 'retry' | 'fatal'`：
  `out-of-priority` 且票不在名单 → `parked`；票状态非 queued/inbox → `fatal(放弃)`；其余 → `retry`。
- 数据：`state\lane-parked.jsonl` 每行 `{ts,ticket,code,reason}`（去重，同票只记一次）。

## 2. 做什么
1. `lane-runner.mjs` 里加 `classifyDispatchFailure`，按结论分流；
2. `parked` 的票**移出候选集**（本轮不再尝试），**不计失败次数**；
3. `fatal` 的票从候选集剔除并写 `state\lane-dropped.jsonl`；
4. 报警只在 `retry` 连续 ≥3 次时发；
5. 夹具类票（标题含"夹具/测试/fixture"）**不报警**，只记 parked。

## 3. 验收与判据
- ① 造一张名单外票 → 一次 `parked` 记录、**0 次报警**（贴）；
- ② 把已 drop 的 TPR-003 放进候选 → 直接 `fatal`、不再重试（贴）；
- ③ 真不可达的名单内票 → 3 次后报警（贴）；
- ④ `lane-parked.jsonl` 同票只有一行（贴计数）。
