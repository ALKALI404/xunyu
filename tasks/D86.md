# 工单 D86 · 修 handoff.mjs 模板与文件名规范（派 04）

> 派单 2026-10-29 09:42 本体｜00 在 D84 里踩到两处：模板过期、文件名格式冲突

## 1. 两个问题（00 实测）

1. `handoff.mjs new` 的**接班包模板过期**：里面让新人「提醒主人归档旧会话」，还指向根目录 `handoff.mjs`（早已是转发壳）——应改为：**读完交接稿→复述职责与手头单→不催主人归档（归档已由 00 自动完成）**；
2. **文件名规范冲突**：任务书常写 `交接-20261029-0935.md`，而工具强制 `交接-YYYY-MM-DD-HHMM.md`，导致改名返工——要么工具兼容两种写法并给出规范化后的实际路径，要么在文档模板里写死格式。

## 2. 做什么

1. 更新接班包模板（`handoff.mjs` 里那段首条消息）：
   - 删掉"提醒主人归档"；
   - 明确"归档由 00 完成，你不要碰"；
   - 加一条"先读 `docs\规则速查.md` 与本次交接稿四块"；
2. 文件名：`new` 接受 `交接-YYYYMMDD-HHMM.md` 与 `交接-YYYY-MM-DD-HHMM.md` 两种输入，**统一规范化为后者**，并在 stdout 打印实际生成路径；
3. 顺手在 `docs\交接流程.md` 里写明唯一格式。

## 3. 什么算过

- 跑一次 `handoff.mjs new`（用测试会话或 `--dry-run`），接班包内容里**没有**"提醒主人归档"，且含"读规则速查"；
- 传 `交接-20261029-0935.md` 作为输入 → 实际生成/记录为 `交接-2026-10-29-0935.md`，stdout 有提示（贴）；
- `docs\交接流程.md` 里有格式规定。

## 4. 边界

- 改 `scripts\handoff.mjs` 与 `docs\交接流程.md`；
- **不**改换代流程本身、不动 roster 逻辑。
