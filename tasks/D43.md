# 工单 D43 · 工作台加「项目」视图（派 06）

> 派单 2026-10-28 19:08 本体｜主人要求：除了「谁排了什么任务」，还要展示**项目层**
> 前置：W-081（D42 项目台账 `state\projects.json`）——数据没建好不许开工

## 1. 做什么

工作台加一个**「项目」区**（放在看板之上，作为第一屏）：

1. **项目列表**：每个项目一行/一张卡——项目名、状态（`在做/要做/暂停/已完成`）、一句话摘要、**项目文档本地链接**（`file:///E:/DSH_workspace/docs/projects/xxx.md`，点了能用默认编辑器打开）；
2. **进度条**：项目完成度 = 该项目所有子功能里「已完成单数 / 总单数」；子功能完成度同理，数据来自 `state\projects.json` × `worklist` 现算（不许把进度写死在 json 里）；
3. **正在做**：显示当前 `doing` 的子功能与它的具体单号（例：`工作台 · UI 规格 v1 改版 · D41 doing · 06`）；
4. **要做**：`planned` 项目与未开工子功能，按项目分组；
5. 点项目卡可展开看子功能清单与各自票号状态。
6. **分区（2026-10-28 主人补）**：把「已完成」从在做的里面拆出去，**单独一栏放最下面**：
   - 上面三区：`在做` → `要做` → `暂停`（按此顺序）；
   - 底下单独一栏 **`已完成`**，默认**折叠**，标题显示数量（例：`已完成 · 3`），点开才列出；
   - **已完成的项目不参与上方排序**，也不占上方首屏空间；
   - 项目状态从 `projects.json` 的 `state` 读，`done` 一律进底栏。

## 2. 什么算过

- 页面能列出 `projects.json` 里全部项目，状态与 json 一致；
- 文档链接可点且路径正确（贴 `href` 原文）；
- 进度数字与手算一致（挑一个项目，把它的 done/total 手工算一遍对照）；
- 「正在做」区显示的是当前 worklist 里真实 `doing` 的单（杀掉一个单，数字会变）；
- 改前/改后截图各一张。
