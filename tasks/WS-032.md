## 接口契约

```
GET /api/persona
  → { ok, primary:{path, mtime, chars, sha8, title}, all:[{path,mtime,chars,sha8}] }

GET /api/memory
  → { ok, longTerm:{path,chars,mtime,chapters},
      distill:{latestDate,count},
      notebooks:{qq:{lines,lastAt}, window:{lines,lastAt}} }
```

**字段规则**：
- `sha8` = 文件内容 sha256 前 8 位（**人设变更可追溯**，不泄露内容）；
- **只回路径与统计，不回正文**（页面给“打开”链接）；
- **读不到就 `ok:false` + 人话原因**（如「roles\鲟鱼.md 不存在」）。
