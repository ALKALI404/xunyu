## 接口契约

**接口未变**：只改 CSS/主题令牌与布局类名，不改任何 HTTP 路由、不改 JS 导出的函数签名、不改消息结构。

UI 侧的自定义属性（CSS 变量）**必须与窗口壳同源**，命名沿用既有的：
```
--xg-glass-bg / --xg-glass-border / --xg-glass-blur / --xg-glass-shadow
--xg-token-bg / --xg-token-fg / --xg-token-accent
```
**唯一允许的新增**：若窗口壳里缺某个令牌，只允许在 `workdesk` 自己的样式表里定义同名变量并写注释指向窗口壳，**不许改窗口壳的样式文件**。

## 0.5 预期结果

工作台与企微桥接窗口看起来是同一套皮（玻璃质感、圆角、阴影一致），且窄屏 280px 不塌。

## 1. 做什么

把工作台 UI 的液态玻璃样式重排为「令牌同源」：从窗口壳复制的值改为引用同一组 CSS 变量，修正圆角/阴影/模糊半径的不一致，窄屏（280px）回归。

## 2. 预期结果

- 两个界面的玻璃质感肉眼一致（贴对比截图）；
- 280px 宽度下元素不重叠、文字不溢出；
- 不引入新的 JS 依赖、不改布局骨架。

## 3. 验收与判据

- ① **令牌同源可验证**：在浏览器 devtools 里读 `getComputedStyle(document.documentElement).getPropertyValue('--xg-glass-bg')` 与窗口壳里的同名变量，**值相同**（贴两处取值）；
- ② **视觉对比**：贴「工作台」与「企微桥接窗口」两张同尺寸截图，玻璃背景/圆角/阴影一致；
- ③ **窄屏回归（反例）**：窗口缩到 **280px** 宽，贴图证明**无横向滚动条、无文字溢出**（改前应有问题，改后修好）；
- ④ **无回归**：工作台三个主视图（会话/抽屉/项目）各点一次，无白屏、无 console error。
