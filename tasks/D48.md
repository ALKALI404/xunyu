# 工单 D48 · 窗口加「工作区」模块（三模块导航 + 分类 + 子菜单 + 返回）（派 06）

> 派单 2026-10-28 19:45 本体｜依据 `docs\UI规格-v1.md` v1.2

## 1. 做什么

窗口顶层导航从两模块变**三模块**：`聊天` / `工作台` / **`工作区`**（原「工具箱」并入工作区，不再单独存在）。

1. **工作区母菜单**：分类卡片（监控/数据/开发/运维/其他），每张显示 `分类名 + 工具数`；
2. **子菜单**：点分类进入，列出 `图标 + 名称 + 一句话说明 + 启动按钮`；
3. **返回**：子菜单顶部固定 `← 返回` + 面包屑（`工作区 / 监控`），`Esc` 同样返回；
4. **启动白名单**：只认注册表里的入口。`kind:'url'` 用 iframe 内嵌本地页面；`kind:'exe'` 由宿主壳启动并**二次确认**；不许执行任意命令行；
5. **注册接口** `workspace.register({category, id, label, desc, launch})`；
6. **本次范围**：空壳 + 分类 + 子菜单 + 返回 + 注册接口 + **注册 1 个真实入口**（分类「数据」→「花费看板」→ `http://127.0.0.1:9340/`）验证链路；空分类显示「暂无工具」。
