## 1. 已探明的现状（别重复踩）

- VM：`xunyu@192.168.123.118`（SSH 密钥已通、管理员）；
- 企微 5.0.13 已登录，进程 `WXWork.exe`；
- **SSH 是 session 0，截图/输入必须在交互会话**：用计划任务 `-LogonType Interactive` 跑脚本（模板见 `C:\Temp\show3.ps1`）；
- **已知怪现象**：同一段 `EnumWindows` 枚举，`show3.ps1` 曾成功列出窗口（hwnd 460100/918982，标题「企业微信」），**后续脚本一律返回 0 个窗口** → **本单第一件事就是查清这个根因**（怀疑：企微落托盘后窗口被销毁、进程重启换了 hwnd、或一次性 task 与常驻 session 的窗口站不同）；
- 已知可行：`ForceForeground`（AttachThreadInput）成功过、点击坐标生效过。

## 2. 做什么

1. **窗口定位**：按 `GetClassName` + `FindWindow`/`EnumWindows` 双路，找不到就**在交互会话里拉起 WXWork.exe** 再试；把企微主窗口类名固化进配置；
2. **会话定位**：**用搜索框**（不点左侧坐标）；搜索失败要有兜底（直接按会话名匹配不到就报错，不许发错人）；
3. **发送**：**剪贴板 + Ctrl+V**（不要逐字注入，中文尤其不稳）→ 回车；
4. **校验**：发送前后各截一张图，**两图 sha256 必须不同**；再截一次确认消息出现在气泡区；
5. **编排**：宿主侧 `scripts\vm-sender.mjs`（Node 调 ssh + 计划任务），VM 侧脚本放 `scripts\vm\`，两边同源可复现；
6. **outbox 骨架**：`state\wecom-outbox.jsonl`，字段 `{id, conv, text, state, attempts, evidence, ts}`。
