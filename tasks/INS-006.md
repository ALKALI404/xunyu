## 2. 预期结果

## 3. 验收与判据

```powershell
$d = (Invoke-WebRequest 'http://127.0.0.1:9343/api/data' -UseBasicParsing).Content | ConvertFrom-Json
$d.people | Where-Object { $_.id -in '人-0004','人-0007' } | ForEach-Object { "{0}: {1}" -f $_.name, $_.relations.spouse[0].personId }
$d.households | ForEach-Object { "{0} {1}: {2}" -f $_.id,$_.name,(($_.members|%{$_.personId+':'+$_.relation}) -join '、') }
```
期望：`许驰: 人-0007`、`彭艳: 人-0004`；家-0002 四人、无家-0003。
