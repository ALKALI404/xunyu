## 1. 布局（先做，做完先交一次截图）

1. **默认只有聊天**：左右栏都不渲染（不是 `display:none` 而是不插入 DOM，避免占位）；
2. **左栏 = 抽屉**：
   - 顶栏按钮「≡ 会话」（在状态点右边）→ 从左滑出，宽 280px，**带半透明遮罩**；
   - 点遮罩 / Esc / 再次点按钮 → 收起；
   - 抽屉顶部右侧一个**图钉**：钉住 = 变成常驻列（270px），不钉 = 抽屉；状态记 `localStorage.xy.sidePinned`；
3. **右栏 = 浮层**：
   - 点工号/会话 → 右侧滑出浮层卡片（宽 340px），**必须有 × **，点遮罩或 Esc 也关；
   - 不允许"常驻占列"（除非以后单独提需求）；
4. **聊天区** `max-width:900px` 居中，左右留白；窄于 900 时自适应铺满；
5. 不显示两栏时：只剩 顶栏 + 消息 + 输入框，**不允许任何边框/空白占位**。

## 2. 玻璃分层（第二步）

1. **三级底色**：
   - L0 背景：`#F7F5F2 → #EFEDE9` 极淡渐变（页面根）；
   - L1 外壳（顶栏/抽屉/浮层）：`rgba(255,255,255,.72)` + `backdrop-filter: blur(24px) saturate(160%)`；
   - L2 **正文卡片**：`#FFFFFF` 纯白 + 1px 边 `#E6E1D8` + 阴影 `0 8px 24px rgba(15,23,42,.06)`；
2. **消息气泡**：白底、`border-radius:12px`、内边距 10×14、字号 13/行高 1.6；
3. **圆角**：外壳 16 / 卡片 12 / 胶囊 999；**动效 200–260ms** `cubic-bezier(.22,.61,.36,1)`；
4. **判据**：放大截图，**正文后面任何字都不可辨认**；同屏模糊层 ≤3；首屏 <1.5s；「设置」里玻璃开关可关（关=纯色）。
