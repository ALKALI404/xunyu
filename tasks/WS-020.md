## 一、能，但先划清边界（这三样打包不进去）

| 组件 | 能不能进我们的安装包 | 理由 |
|---|---|---|
| **鲟鱼侧服务**（工作台 9340 / 引擎 9351 / 学习区 9350 / 保险 9343 / relay 9334 / 守护 supervisor） | ✅ **能**（都是我们自己的 Node） | 自带 node 运行时即可 |
| **微信桥**（Python + UIA） | ✅ **能**（嵌 Python 3.12 + 我们的 bridge 代码） | 但它要**外部的微信客户端**在跑 |
| **QQ 桥** | ✅ 能 | 依赖外部 **SnowLuma** 进程 |
| **DSH 本体** | ❌ **不能**（第三方桌面应用） | **只能声明依赖**：装鲟鱼前先装 DSH |
| **微信 / QQ 客户端** | ❌ 不能 | 用户自己的软件 |
| **VB-CABLE 虚拟声卡** | ⚠️ 可选组件 | **语音功能才需要，默认不装** |

## 二、推荐方案：**Launcher 外壳 + Inno Setup 安装包**

```
鲟鱼 Launcher（单实例 + 托盘）
├ 组件注册表 services.json（复用 WS-016）
├ 启动顺序：bridge → 各服务 → 工作台打开
├ 诊断页：直接用工作台的「总控台」（WS-019）
├ 日志：统一 logs\ + 一键打包导出（排障用）
└ 崩溃：拉起失败的组件高亮，不整包崩
```

**打包工具对比**

| 工具 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **Inno Setup** | 成熟、中文路径稳、支持服务/快捷方式/静默安装 | 界面朴素 | ✅ **首选** |
| NSIS | 体积小 | 中文脚本坑多 | 备选 |
| MSIX | 微软官方 | **UIA/注入类会被限制**，不适合我们 | ❌ |
| Tauri/Electron 壳 | 界面好看 | 再背一个 Chromium | ⚠️ 只有想要"漂亮启动器"时才用 |

**体积预估**：Node 运行时 ~50 MB + Python 3.12 ~90 MB + 我们代码 ~5 MB ≈ **150–200 MB**。

## 三、升级策略（**别用它的更新器**）

- **我们的更新**：**只走"下载新版安装包 → 覆盖安装"**，`data\` 与配置目录**不动**；
- **安装包内不带自动检查**（**魔改第一项就是删这个**），**更新由主人手动触发**（工作台「检查更新」按钮 → 你去下）；
- **版本号落在** `E:\DeepFish\Xunyu\VERSION`，安装包与运行时都读它。
