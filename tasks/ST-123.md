## 接口契约

每次 review 追加 `复习\reviews.jsonl`（`{cardId,rating,ts,elapsedMs}`）；`GET /api/review/stats?days=30` 返回每日复习数、正确率、Again 次数；页面底部一行数字。

## 1. 做什么

每次 review 追加 `复习\reviews.jsonl`（`{cardId,rating,ts,elapsedMs}`）；`GET /api/review/stats?days=30` 返回每日复习数、正确率、Again 次数；页面底部一行数字。

## 2. 预期结果

能看到"本周复习 42 次 / 正确率 81% / Again 7 次"。

## 3. 可验方式

跑 20 次 review → stats 各项求和 = 20；反例：`days=-1` → 400；无记录时返回 0 而不是报错。

## 4. 边界

不改卡片调度；不做图表库（只数字）。

## 5. 回滚

新文件，删 `reviews.jsonl` 即回滚。
