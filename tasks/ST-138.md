# ST-138 · 书架接口 + 自助上传课本（P1 接口与函数）

> 建单 2026-11-07 15:00｜目标 **04（代码）**｜项目 study / feature st-shelf
> 主人原话：「做一个书架区按学科放课本……另外支持自助上传课本」

## 一、接口契约

**① 书架（按学科分组，带难度与封面信息）**
```
GET /shelf → {
  ok,
  subjects: [{
    id, name,
    books: [{ id, title, level:"入门|进阶|硬", lang:"zh|en", pages, sizeMB,
              has:true|false, path?, sourceUrl?, addedAt }],
    courses: [{ title, level, source:"bilibili|youtube", url, by, hours, note }]
  }]
}
```
- **`has:false`** = 清单里有、但本地没有文件（点开要显示"未下载"而不是报错）；
- **`books` 按 level 排序（入门→进阶→硬）**；
- **数据源**：`索引\books.jsonl`（本地书）+ `索引\books-wanted.jsonl`（想读清单）+ `索引\courses.jsonl`（公开课，ST-137 产出）。

**② 自助上传课本**
```
POST /shelf/upload  { subject, title, level?, filename, contentBase64 }
  → { ok, id, path, bytes, sha256 }
```
**规矩（红线）**：
1. **只接受 PDF**（魔数 `%PDF`），**≤ 200 MB**；
2. **落盘路径固定**：`学科\<学科>\课本\<书名>\<文件名>.pdf`——**`<书名>` 必须 sanitize**（去 `\ / : * ? " < > |`，去 `..`）；
3. **重名不覆盖**：自动加 `-2`、`-3`；
4. **写完必须回读校验**（大小一致 + 前 4 字节是 `%PDF`）；
5. **同时更新 `索引\books.jsonl`**（一行一本，写前 `.bak-st138`）；
6. **不许接受 URL 下载**（只接受上传的文件体，**避免 SSRF**）。

**③ 删除（只删索引，不删文件）**
```
POST /shelf/remove { id } → { ok, note:"仅从书架移除，文件保留" }
```

## 二、纯函数要求（按开发规范 §三）

`sanitizeName()`、`nextFreeName()`、`isPdfHead()`、`sortBooksByLevel()` **都写成纯函数 + 单测**（正例 + 反例各一）。

## 三、可验方式

- ① `GET /shelf` 返回七学科，books 按难度排序（贴 JSON 片段）；
- ② 传一个 1 页 PDF（自己造个小 pdf）→ `ok:true`，落盘，**回读大小一致**（贴）；
- ③ 传一个 `.txt` 伪装成 pdf → **400 拒绝**（贴）；
- ④ 传 201 MB（可用稀疏文件模拟）→ **413 拒绝**（贴）；
- ⑤ 同名再传一次 → 落成 `-2`（贴目录列表）；
- ⑥ `索引\books.jsonl` 多了一行且能 parse（贴）；
- ⑦ 路径注入：`title="../../etc/passwd"` → **被 sanitize**，落盘仍在 `学科\` 下（贴路径）。

## 四、边界

- **不动现有 `/book/*`（阅读用）**；
- **不下载网上的书**（只接受主人自己上传）；
- **不删文件**。
