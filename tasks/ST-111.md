## 接口契约

**现有行为**（要改的）：`/feynman/say` 返回里带 `role:"examiner"` 的气泡，页面已用 `<details class="fznote">` 折叠，**但仍在对话流里出现**（L982–L988）。

**改成**：
- **对话进行中**：**考官气泡完全不渲染**（连折叠块都不出现），**只在顶栏显示一个中性提示**：「⚖️ 考官在旁听（结束时统一给评语）」——**不带任何评语内容**；
- **点「结束并判定」后**：在对话流**下方**追加一个「考官全程评语」区：
  ```
  ⚖️ 考官全程评语（共 3 轮）
  ├ 第 1 轮：术语「极限」没解释；只讲了机制，没点出"它是变化率"
  ├ 第 2 轮：追问三连（极限是什么/两点怎么选/例子呢）没人接
  └ 第 3 轮：略
  ```
- **每轮评语 + 一句建议**（建议由引擎已有的 `judge.summary` 拆分；**没有就只显示评语，不硬编建议**）。

## 0.5 预期结果

和小白聊的时候，**屏幕上只有你和小白**，不被打断；点结束后，**一次性看到考官每轮说了什么 + 总建议**。

## 1. 做什么

1. `web/index.html`：`renderBubble` 里对 `role==='examiner'` **在对话态直接返回空字符串**；
2. 顶栏加一行静态提示（不带内容）；
3. `end` 之后渲染「考官全程评语」区（按 `round` 排序，折叠展开都行，默认展开）；
4. 历史回看（`?id=`）保持原样：**旧记录照常显示批注**（既然已结束，就该能看）。

## 2. 可验方式

- ① 对话中截图：**只有你和小白两条气泡，没有任何考官文字**（顶栏有"考官在旁听"提示）；
- ② 结束判定后截图：**下方出现「考官全程评语」+ 每轮条目 + 总建议**；
- ③ 历史回看一场旧对话：**批注正常显示**（截图）；
- ④ 贴改动前后同一场对话的两张对比图。

## 3. 边界

只改学习区 `web/index.html`；**不改引擎（`/feynman/*` 返回值不动）**——**前端过滤即可**。
