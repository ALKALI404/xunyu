## 接口契约

```
POST /assistant/chat  {text, context?} → {reply, links:[{type,label,sub,url}], actions?:[{label,url}]}
GET  /file?path=...   → markdown 渲染页
```

**卡片字段固定**：`{type:"quiz"|"note"|"mindmap"|"discussion", label, sub, url}`。

## 版面

```
右下角悬浮球（48px，图标 🐟）→ 点击展开成 360×520 的对话窗
窗内：消息流（你右 / 助手左）+ 底部输入框 + [发送]
助手消息下方：链接卡（最多 3 张，纵向排列，卡片带图标+标题+一句 sub）
顶栏两个 icon：[清空] [收起]
```

**硬要求**：
1. **默认收起**，不遮学科卡；
2. **链接卡不用裸 URL**，必须是卡片（点整张卡跳转）；
3. `type` 决定图标：📝 测试 / 📄 笔记 / 🗺 导图 / 💬 讨论；
4. **回复 ≤120 字时正常显示；超过要折叠**（"展开全文"）；
5. **不许把"暂无数据"画成空白**——助手说没有，就显示一句"它说没有"；
6. 移动端：对话框变全屏抽屉。

## 0.5 预期结果

网页右下角点开就能问；问「想复习熵」得到两张卡，点开进定义卡或讨论回看。

## 1. 做什么

1. `web/index.html` 加悬浮对话组件（原生 JS，**不引框架**）；
2. 渲染 `links` 为卡片、`actions` 为按钮；
3. `/file` 打开新标签页渲染 markdown；
4. 记住最近 20 条对话（localStorage，刷新不丢）。

## 2. 可验方式

- ① 收起态截图（右下角悬浮球，不挡学科卡）；
- ② 展开态截图（对话窗 + 输入框）；
- ③ 问「想复习熵」→ 两张卡截图（含图标/sub）；
- ④ 点卡片 → 打开笔记/讨论（截图）；
- ⑤ 移动端窄屏（375px）截图（全屏抽屉）。

## 3. 边界

只改学习区页面；**不改保险页**。
