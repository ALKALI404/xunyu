## 接口契约

**① 适配层（新服务，`127.1.1.6:9353`）**

```
POST /v1/chat/completions        ← whale_girl 调这个（OpenAI 格式）
  body: { model, messages:[{role,content}], stream?:false }
  → { id, object:"chat.completion", choices:[{message:{role:"assistant",content}}], usage:{...} }

GET  /v1/models
  → { data:[{id:"pengyan-assistant"}] }     ← 让 whale_girl 的下拉里有东西可选
GET  /health
  → { ok, session: "session-2a2bc8b5…", bridge: "ok|fail" }
```

**② 桥调用（已有，别改它）**
```
POST /api/dsh/say   { key, sessionId, text }        ← 把用户消息投进 P01
GET  /api/dsh/wait?key=&sessionId=&after=&timeoutMs=  ← 取回复（可能多条，拼成一段）
```
**注意**：桥回 **200 + `{ok:false,error:"会话令牌不匹配"}` 这种软失败**——**必须判 `ok`，不能只看状态码**（今晚中继就栽在这）。

**③ 文件收发（同一张票，一起做）**
```
POST /v1/files/receive   multipart  ← 微信来的文件（保单/条款/截图）
  → 存 `E:\DSH-WeChat\PengYan_Assistant\收件箱\wx-<时间>-<原名>`
  → 按扩展名分流：.pdf/.jpg/.png → 丢进现有 OCR/parse 队列；其他 → 只存档并回报
  → 返回 { ok, savedAs, kind, next: "ocr|parse|archive" }

POST /v1/files/send      { conversationId, filePath }
  → 调 whale_girl 的发送文件能力（若它没有，就见 §三 兜底）
```
