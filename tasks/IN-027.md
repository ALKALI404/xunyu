## 接口契约

新建 `脚本\household-rules.mjs`，导出四个纯函数：

1. `resolveHousehold(person, people, households) -> {householdId|null, reason}`
   - 有配偶 → **归入配偶的家庭**（不单独建）；
   - 已有 `primaryHouseholdId` → 保持；
   - 只是被保险人 + 仅为子女 + 无配偶无子女 → **归入父母家**；
   - 都没有 → `null` + `reason:"no-anchor"`。
2. `planMerge(h1, h2, people) -> {keepId, mergedId, headPersonId, headReason}`
   - **户主优先男方**；性别未知/同性 → 保单多的一方 → 建档早的一方；
   - `headReason` 写清依据（gender/policyCount/createdAt/assumed）。
3. `planSplit(h, people) -> [{name, headPersonId, members}]` —— 离婚解耦后各自建卡。
4. `applyDecease(person, household) -> {personPatch, householdPatch}`
   - `status:"deceased"`；**卡不删**；备注「原户主已亡故」；**户主迁移为配偶**。

**硬性**：
- 纯函数，**不读不写文件**（数据由调用方传入）；
- **不许假设性别**：性别未知时按规则降级，并返回 `headReason:"assumed"`；
- **幂等**：同输入两次调用结果一致。
