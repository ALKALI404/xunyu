## 接口契约

- 输入：`档案\原件\` 或 `收件箱\` 里的条款 PDF/DOCX。
- 输出：`档案\条款\<文件hash>.json`：
  ```json
  {
    "source": "文件hash 或 保单号",
    "extractedAt": "2026-11-05",
    "articles": [
      { "no": "第三条", "title": "保险责任", "paras": [
          { "i": 1, "text": "……", "page": 12 },
          { "i": 2, "text": "……", "page": 12 }
      ]}
    ]
  }
  ```
- 切分：**以「第X条」为锚点**（中文数字与阿拉伯数字都认）；条标题取该条首段前 20 字；段号从 1 起。
- 页码：抽得到就写，抽不到写 `null`（**不许编**）。
- 查询：`GET /api/clause?q=<关键词>` 返回命中片段，**必须带 `no` / `para` / 原文**。

## 0.5 预期结果

给一份真条款 PDF，能生成索引并按「第X条 / 第Y段」定位原文；搜"免责"返回带条段号的原句。

## 1. 做什么

1. 写 `脚本\clause-index.mjs`；
2. 认中文数字条号（第一条…第一百条）、"第 3 条"带空格、跨页条款；
3. 索引落 `档案\条款\`，`索引\files.jsonl` 对应行补 `clauseIndex` 字段；
4. `窗口\server.mjs` 加 `GET /api/clause`。

## 2. 可验方式

- ① 用一份真条款 PDF 跑一遍，贴 JSON 前 20 行；
- ② 贴「第三条几段、第 2 段原文前 50 字」；
- ③ `GET /api/clause?q=免责` 贴返回；
- ④ 用没有"第X条"的 PDF，贴结果（应报"未识别到条款结构"，**不许编造**）。
