## 接口契约

- `node scripts\findings-sync.mjs [--dry-run] -> {added, skipped}`。
- 输入 `state\findings-*.jsonl`（`{ts,project,feature,kind,text,src}`）；输出写 `projects.json` 的 `findings` 与文档标记区间。

## 1. 做什么

1. **数据格式**（已存在 8 条样例 `state\findings-2026-10-29.jsonl`）：
   `{ts, project, feature, kind, text, src}`；kind ∈ boundary/demo/credential/pitfall/risk/decision；
2. `scripts\findings-sync.mjs`：
   - 读 `state\findings-*.jsonl`（支持多文件）；
   - **按 project 分组、按 ts 倒序、去重（text+project 相同视为一条）**；
   - 写 `projects.json`（改前备份 `.bak-<时间>`）；
   - 渲染 markdown 到标记区间内；
   - `--dry-run` 只打印差异不写盘；
3. **校验**：跑完 `node scripts\worklist.mjs list` 仍正常（JSON 没写坏），不一致就回滚备份；
4. 挂进 `WS-010` 调度器（若还没做，先留 CLI，等调度器上线再接）。
