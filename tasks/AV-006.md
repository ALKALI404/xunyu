## 0.5 预期结果

**窗口打开第一眼就是"半透明玻璃"质感**（背景透出、面板有模糊与顶部高光），同时**功能一个不少、首屏不卡**。
可观察：改前/改后同尺寸截图对比能看出玻璃感；首屏 <1.5s；聊天/工作台/工具区三个面板都能正常打开。
## 1. 目标

把 `E:\DeepFish\avatar\window\web\index.html` 的视觉换成**液态玻璃**质感：**背景透、面板半透明模糊、边缘有高光、层次靠光影不靠边框**。
**功能与布局一律不动**（B8 已经定了一屏 ≤3 面板）。

## 2. 液态玻璃的四条要素（照这个做，别自由发挥）

1. **背景**：一层柔和的渐变底（暖白 → 浅灰 → 极淡蓝），**不允许纯色大块**；
2. **玻璃面板**：
   - `background: rgba(255,255,255,0.55)`（深色区用 `rgba(30,30,32,0.55)`）
   - `backdrop-filter: blur(30px) saturate(180%)`
   - `border: 1px solid rgba(255,255,255,0.65)`（深色区 `rgba(255,255,255,0.18)`）
   - **顶部 1px 高光**：`box-shadow: inset 0 1px 0 rgba(255,255,255,0.85)`
   - **柔和外阴影**：`0 8px 32px rgba(15,23,42,0.10)`（不要硬阴影）
3. **圆角**：面板 **20px**，小控件 **12px**，胶囊按钮 **999px**；
4. **动效**：`200–260ms cubic-bezier(.22,.61,.36,1)`；hover 只做**轻微提亮 + 上浮 1px**，不许放大缩放。

## 3. 令牌化（硬要求）

所有颜色/圆角/模糊值写进 CSS 变量，**不许在样式里出现裸 hex**（沿用 `docs\UI规格-v1.md` 的口径）。
新增令牌建议：`--glass-bg`、`--glass-bg-dark`、`--glass-border`、`--glass-blur`、`--glass-shadow`、`--radius-panel`、`--ease-glass`。

## 4. 性能红线（WebView2 里 blur 很贵）

- **同时可见的模糊层 ≤3**（与"一屏 ≤3 面板"一致）；
- 列表滚动区域**内部不加 backdrop-filter**（只在外层容器加）；
- 页面首屏渲染后 **<1.5 秒**（贴 Performance 面板截图或 `performance.timing` 数字）；
- 低配模式：`prefers-reduced-transparency` 或手动开关 → 关掉 blur 退回纯色。

## 5. 验收与判据

- 改前/改后**截图各一张**（同一窗口尺寸、同一页面）；
- 面板上出现"玻璃感"三要素：**模糊、顶部高光、柔和外阴影**（放大截图能看见 1px 高光边）；
- 全文搜 `#[0-9a-fA-F]{3,6}` 在**样式块里为 0 处**（全走令牌，贴 grep 结果）；
- 同时可见模糊层数 ≤3（数面板，贴）；
- 首屏数字 <1.5s（贴）；
- 关掉 blur 的降级开关可用（贴截图）。
- **不破坏功能**：聊天能发、工作台能开、工具区能开（各贴一张）。
