## 接口契约

```
GET  /analysis/overview       → {subjects:[{id,name,type,learned,total,mastery,understanding,benchmark?,note?}]}
GET  /analysis/subject?id=    → {chapters:[{no,title,status,understanding,wrongCount,discussions}]}
GET  /analysis/flashcard?due= → {card:{id,front,back,kind,source}, dueAt}
POST /analysis/flashcard/answer {cardId, correct} → {ok, nextDue, streak}
```

**算法（写死，不许自由发挥）**：
- **学了多少** = 已读完章 / 总章；
- **掌握多少** = 章节掌握度均值（0.4×讨论 + 0.3×(1-错题率) + 0.3×笔记完整度）；
- **理解程度** = 上面结果映射 1–5 档；
- **没数据 → `note:"暂无数据"`，不许返回 0**（0 和"没学"是两回事）。

**职业技能（`type:"skill"`）**：
- 读 `索引\subjects.jsonl` 的 `benchmark` 字段（levels/current/target/basis/verifiedAt/by）；
- **`basis` 缺 → 返回 `note:"未设定基准"`**，**不许编行业线**；
- 档位只能人工改，**程序不许自动调**；改动写 `索引\benchmark-log.jsonl`。

**随机闪卡**：
- 抽取源：`题库\*\*.json` 里 `kind:"boundary"|"judge"` 的题 + `卡片\` 闪卡；
- **优先到期的**（1/3/7/15 天），没到期随机一条；
- **答错自动写进错题集**（与章页同一本 `错题\wrong.jsonl`）。

## 0.5 预期结果
