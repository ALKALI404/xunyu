## 接口契约

```
GET /quiz/outline?bookId=<书> → {
  bookId, chapters:[{ no, title, page, status:"done|learning|locked",
    progress:{answered,total}, sections:[{no,title,page,questions,status}] }]
}
GET /quiz?bookId=&chapter=2&section=2.3   → 该小节题（section 省略=整章）
```

**`status` 判定（写死，页面不许自己算）**：
- `done`：本章测验正确率 ≥80%，**且**本章错题已复盘（或为 0）；
- `learning`：本章有作答但未达标，**或**上一章已 done；
- `locked`：上一章未 done。

**兼容**：老结构 `chapters["1"].questions`（章级混合题）继续有效；新题优先放 `sections`。
