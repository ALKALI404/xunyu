## 6. 追加（主人 2026-11-06 20:10）：条款搜索跟在「每张保单」上，不放列表底部

**主人原话**：「条款搜索栏跟着每个保单走，不是放在个人卡片所有保单的最底下，提供打开条款目录原始页面搜索相关条款当条具体信息两种，搜索结果定位单条条款明细」

### 6.1 位置

**每张保单卡片内部**，条款块下面放一个搜索框（**不是**放在"这个人所有保单"列表的底部）：

```
┌ 单-0001 · 太平久久保意外伤害（2016版）         ⏳ 待人工校验 ┐
│ 📄 本单条款   [预览] [下载]                                  │
│ 🔍 在本单条款里搜：__________  [搜]                          │
│    或者 →  [打开条款原始目录页]                              │
└──────────────────────────────────────────────────────────┘
```

### 6.2 两种入口（都要有）

| 入口 | 行为 |
|---|---|
| **① 在条款文本里搜** | 搜到**具体条/段**，结果定位到「第 X 条 第 Y 段」并高亮命中词 |
| **② 打开条款原始目录页** | 打开 `档案\条款库\<公司>\<文件>.pdf`（或该条款的"目录页"），**自己翻** |

### 6.3 搜索结果要求

- **每条结果必须是单条条款明细**（条号 + 段号 + 原文片段 + 页码）；
- **点结果 → 滚动定位到那一段**（不是跳到文件开头）；
- **没命中 → 显示"本单条款里没有这个词"**，并给「去原始页自己找」的按钮。

### 6.4 验收补充

- ① 太平那张单：在卡片里搜「保险责任」→ 出「第四条」，点开定位到第 4 条（截图）；
- ② 搜一个没有的词 → 显示"没有这个词"（截图）；
- ③ 点「打开条款原始目录页」→ PDF 打开（截图）。
