## 接口契约

**① 可重开（同一题不限次数）**

```
POST /feynman/start {bookId, questionId, restart?:true}
  → 新建一场（新 discussionId），**旧场不动、照常归档**
```
- **同一 `questionId` 允许存在多场讨论**（历史都留，索引里按时间倒序）；
- **不许复用旧话术状态**：每场新拉专员（已定），**旧场不续**；
- 归档文件名已含时间戳，**天然不冲突**。

**② 小白提问不许重复**

`start` 时构造「已问过清单」并注入专员提示词：

```
本轮要求：
- 下面是这道题历史上小白问过的问题（最多 10 条，最近的优先）：
  1) 一个点没有长度，怎么算变得多快？
  2) 极限这个词你没解释过，它是什么？
  3) 生活例子你还没给，能给一个吗？
- 你必须换一个**不同的角度**提问：换对象（换概念/换例子）、换层次（问定义→问边界）、换形式（反问/极端情形）。
- **不许原句重复，也不许换个词问同一个意思。**
- 如果确实没有新角度，就问"上一次那个例子，换个场景还成立吗"这类迁移式问题。
```

**数据来源**：`讨论\index.jsonl` + `讨论\<书>\*.md`（或 `_state\fd-*.json` 里的 `bubbles`）——**按 `questionId` 筛出历史 `role=="xiaobai"` 的文本，取最近 10 条**。

**③ 反重复校验（硬要求）**

- 新一场的第一条小白问题，**与历史问题的相似度不得高于 0.8**（简单做法：**去掉标点后比较字符重合率**，或**判断是否包含历史问题的核心短语**）；
- **超阈值就重生成一次**；第二次仍超 → **放行但记 `repeatWarn:true`**（**不许卡住用户**）。

## 0.5 预期结果

同一道「导数」题连开三场，**每场小白第一问都不一样**：
- 第 1 场：一个点没有长度，怎么算变快
- 第 2 场：那"变化率"和"平均速度"到底差在哪
- 第 3 场：如果曲线是折线（不光滑），导数还存在吗

## 1. 做什么

1. `feynman.mjs`：`start` 支持 `restart`（默认行为本来就新建，不用改太多）；
2. 加 `collectPastQuestions(bookId, questionId, limit=10)`；
3. 提示词模板里注入上面那段（模板文件放 `脚本\feynman-prompts.md`，**可改不改代码**）；
4. 加相似度校验 + 一次重生成 + `repeatWarn`；
5. 归档时把 `xiaobaiQuestions[]` 写进 `index.jsonl`（供后续查重）。

## 2. 可验方式

- ① 同一题连开两场，贴两场的**第一条小白问题**（必须不同）；
- ② 贴注入的历史清单（证明真的取到了）；
- ③ 贴 `repeatWarn` 触发的那次（若出现）；
- ④ 贴 `index.jsonl` 新增行（含 `xiaobaiQuestions`）。

## 3. 边界

只改费曼引擎与提示词；**不改题库、不改页面**（重开按钮见 ST-111）。
