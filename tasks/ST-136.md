# ST-136 · 学习区页面：加「打开课本」入口 + 标题/参数跟随视图

> 建单 2026-11-07 14:55｜目标 **06（界面与交互）**｜项目 study / feature st-book
> 主人口诉：「学习区的电子课本做好没有，没找到书也没找到进入目录，回到首页后页签还在逻辑哲学论」

## 一、两个问题（本体已确认）

**① 后端好了，前端没入口**
```
GET /book/list           → 200
GET /book/file?id=logic-intro → 200（PDF 能出）
```
**但页面里搜不到 `/book/`、`打开课本`、`PDF` 任何字样** —— **阅读器只做了后端，页面没接。**

**② 回首页后标题还是书名**
URL 里的 `book=` / `chapter=` / `section=` **回首页时没清**，`document.title` 一直显示「学习区·逻辑哲学论」。

## 接口契约（后端已有，别新造）

```
GET /book/list                 → { ok, books:[{id,title,pages,sizeMB}] }
GET /book/file?id=<bookId>     → application/pdf（支持 Range）
```

## 0.5 预期结果

**答题页的课本卡上有「打开课本」按钮**，点了在新标签页打开 PDF（能翻页、能 `#page=N` 跳页）；**回首页时 URL 干净、标题变「学习区·概览」。**

## 1. 做什么

1. **答题页课本卡**加按钮：`<a target="_blank" href="/book/file?id=<book.id>">打开课本</a>`
   - **`book.id` 优先**（`logic-intro`），没有才退回 `book.title`；
   - 若当前在看第 N 章，**链接带 `#page=<该章起始页>`**（页码从 `/quiz/outline` 的 chapter.page 取，没有就不带）。
2. **首页清理**：点「主页」或切到 `view=home` 时，
   - **URL 里删掉 `book/chapter/section/id/subject`**；
   - **`document.title` 改成「学习区·概览」**（其它视图同理：答题/错题/分析/复习）。
3. **别把 PDF 内嵌进页面**（新标签页打开，浏览器原生阅读器够用）。

## 2. 可验方式

- ① 答题页课本卡出现「打开课本」（截图）；
- ② 点它 → 新标签页出 PDF（截图，能看到第 1 页）；
- ③ 在第 2 章点它 → **URL 带 `#page=` 且落在第 2 章页**（截图 + 贴 URL）；
- ④ 回首页 → **URL 干净**（贴 URL）、**标题是「学习区·概览」**（贴 title）；
- ⑤ 切到「错题」→ 标题变「学习区·错题」（截图）。

## 3. 边界

只改 `web\index.html`；**不改后端**（`/book/*` 已有）。
