# ST-142 · 作答历史：每次作答都留档、能回看（P1 接口）

> 建单 2026-11-07 22:35｜目标 **04（代码）**｜项目 study / feature st-quiz-nav
> 主人口诉：「答题之后回答没有记录在本地，以逻辑学 1-1 为例子我进入答题做过题的位置是空的，应该是**已回答 + 过往答案 + 分析 + 再次作答**，保留每一次的作答结果」

## 一、现状（我查过）

**作答其实是记了的**：`章节\第01章…\练习\grade-log.jsonl` **87 行**，每行有 `questionId / answer / verdict / hit / at`。

**问题是拿不出来**：
- `GET /quiz?...` 返回的题目只有 `id/kind/stem/keyPoints/source/chapter/section/sectionTitle/feynmanSteps` —— **不带任何历史**；
- **没有 `/quiz/history` 路由**；
- 页面因此每次都像“第一次做”。

## 接口契约

**① 单题历史**
```
GET /quiz/history?bookId=&chapter=&questionId=
  → { ok, questionId, attempts:[{ at, answer, verdict:"pass|half|fail", hit:[kpId], missing:[…], usedHint, engine }],
      latest:{...}, best:"pass|half|fail|null", count }
```
- **按时间升序**；`attempts` 最多返回最近 20 次（超出给 `truncated:true`）；
- **`answer` 原文返回**（这是主人要看的东西）；
- **不改任何判定**。

**② 题目列表带上「做没做过」**
```
GET /quiz?bookId=&chapter=&section=
  → questions[i] 增加：
     previous: { count, lastVerdict, lastAt, best } | null
```
**注意**：**不要把全部历史塞进列表**（列表只给摘要，历史走 ①）。

**③ 小节汇总**
```
GET /quiz/section/summary?bookId=&chapter=&section=
  → { ok, section, answered, correct, attempts, firstAt, lastAt,
      state:"todo|in_progress|passed|rework" }
```
`state` 口径：
- `todo`：一次没做
- `in_progress`：做过但没 pass
- `passed`：**至少一次 pass** 且没有"pass 之后又 fail"（后者算 rework）
- `rework`：**最近一次是 fail/half**，但历史上 pass 过 → 显示「待重做」

## 0.5 预期结果

进 1.1 → **看到"已回答 2 次"**，点开能看到**每次的原话答案、判定、漏了哪些要点**；**能再答一次，历史多一条，旧的还在**。

## 1. 做什么

1. `复习\attempts.mjs`（新）：**纯函数** `readAttempts(jsonlPath, questionId)` / `summarize(attempts)` / `sectionState(attemptsByQ)`；
2. `/quiz/history`、`/quiz/section/summary` 两条路由；
3. `/quiz` 的每题加 `previous` 摘要；
4. **`grade-log.jsonl` 已经是现成数据源**，不要另建一套存储（**别搞双写**）。

## 2. 可验方式

- ① `GET /quiz/history?bookId=logic-intro&chapter=1&questionId=q-ch01-11-01` → 返回 **≥2 条**历史（我库里就有 2 条），贴 JSON；
- ② 我答一次新的 → 历史 **+1**，且**旧记录还在**（贴前后 count）；
- ③ `GET /quiz?section=1.1` 每题带 `previous.lastVerdict/count`（贴）；
- ④ `GET /quiz/section/summary?section=1.1` → `state=in_progress`（因为都是 half），贴；
- ⑤ 单测：至少 3 例（空历史 / 单条 / 多条含 rework）。

## 3. 边界

- **只读 grade-log，不改写入逻辑**（判分与记录保持原样）；
- **不改题库**；
- 历史接口 **不返回 keyPoints 全文**（只给命中的 id）。

## 4. 回滚

新增 `复习\attempts.mjs` + 两条路由；`grader-service.mjs.bak-st142`。
