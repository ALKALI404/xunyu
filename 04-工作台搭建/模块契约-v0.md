# 模块契约 v0（2026-10-28）

> 一句话：**每个模块都能被问三件事——你活着吗（health）、你会什么（capabilities）、刚才那次调用卡在哪（trace）。**
> 这份是**唯一口径**；实现可以有差异，字段名不许各自发明。

## 一、`/health`（GET，必须存在，不需要鉴权）

```json
{
  "ok": true,
  "module": "relay",
  "version": "2026-10-28",
  "port": 9334,
  "uptimeMs": 123456,
  "ts": 1793170000000,
  "checks": { "bridge": { "ok": true }, "bindings": { "ok": true, "detail": "2/2" } }
}
```

- `ok` 为假时**必须**带上 `error: { layer, code, detail }`，`layer ∈ contract | module | transport`。
- **向后兼容**：老字段（如 relay 现在的 `targets`、body 的 `adapter`）不许删，只能加。

## 二、`/capabilities`（GET，不需要鉴权）

```json
{
  "ok": true,
  "module": "body",
  "capabilities": [
    { "cap": "body.say", "kind": "action", "note": "说一句话，可指定情绪" },
    { "cap": "body.state", "kind": "query", "note": "当前动画/情绪状态" }
  ]
}
```

- `cap` 命名：`<模块>.<动词>`，全小写、点分。**同一个能力只允许一个模块声明**（多写就算撞车，doctor 会报）。
- `kind`：`action`（有副作用）/ `query`（只读）。

## 三、trace（每个模块写同一个文件）

路径：`<工作区>\logs\trace.jsonl`（追加写，一行一条，不许格式化多行）

```json
{"t":1793170000123,"trace":"tr-7f3a","module":"relay","cap":"relay.push","ms":12,"ok":true}
{"t":1793170000456,"trace":"tr-7f3a","module":"bridge","cap":"qq.send.text","ms":812,"ok":false,
 "layer":"module","code":"onebot-timeout","detail":"messageId 为空"}
```

- 一次请求跨模块用**同一个 `trace`**；跨进程靠请求头/参数透传（不在本版强制）。
- 只记**一次调用一条**，不记明细日志；明细仍写各自日志文件。
- 文件超 50MB 自动轮转成 `trace-YYYYMMDD.jsonl`。

## 四、错误三分层（排障只用这三个词）

| layer | 意思 | 谁该被叫醒 |
|---|---|---|
| `contract` | 参数/格式不对，模块本身没坏 | 调用方 |
| `module` | 模块内部出错（超时、依赖失败） | 该模块负责人 |
| `transport` | 端口没开、连接被拒、进程死了 | 03·维护 |

## 五、本阶段不做

- 不做 manifest 目录树、不做动态加载、不改 `bridge.js`。
- 不动任何既有端点行为；只**加**字段、**加**端点、**加** trace 文件。
