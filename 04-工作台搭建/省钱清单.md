# 省钱清单（2026-10-27 定，主人拍板）

> 一句话：**钱花在「没命中缓存的输入」和「我自己写出来的字」上；缓存命中的上下文再长，也几乎不要钱。**

## 一、账（主人 22:2x 那张截图，我核过）

| 项 | 数 | 说明 |
|---|---|---|
| 总 tokens | 11.85 亿 | 其中命中率 **99.6%** |
| 未命中 | ≈ **474 万** | 单价是命中的十倍以上 |
| 输出 | ≈ **157 万** | 我吐出来的每一个字都算钱 |
| 账单 | **¥38.49** | 基本就是这两块拼出来的；命中那 11.8 亿是零头 |

**结论：`上下文总长度` 不是账单，`每次新增的未缓存 token + 输出长度` 才是。**

## 二、三条杠杆

1. **大输出不进上下文**
   工具返回、日志、整份 JSON、大文件——先落盘再切片，只看要的那几行。
   工具：`node scripts\peek.mjs --run "<命令>" --grep "<正则>" --head N`（落盘 + 切片，别让整份东西涌进来）。

2. **别动前缀**
   改早期内容、切换模型、重开会话，都会让缓存整段作废：等于把便宜的东西按贵价再买一遍。
   要做就一次做对；改主意就往后加，别回头改前面。

3. **少写废话**
   输出占账单近一半。结论一句，铺垫删掉，不写「首先其次最后」。

## 三、纪律（派单 / 汇报时照做）

- **证据给指针，不给全文**：「日志第 3 行」「pid 35616」「18:25:06 回来」。
- **一条命令干多件事**，别用 5 次小命令喂 5 次上下文。
- **长文档写盘**，回话只报「写了什么 + 在哪」。

## 四、不算省的（别拿这个当幌子）

- **不省验证**：少验一次，返工的代价远高于那点 token。
- **不省思考等级**：主人 2026-10-27 明确——思考等级不降。
- **不省原文**：记忆存「我为什么这么想」，原件留盘，别贴进对话。
